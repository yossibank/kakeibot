# 概要

> [!NOTE]
> kakeibot の狙い、守ること、最初のリリースの機能、この先の段階と収益化が分かる。
> 作る順番は [roadmap](roadmap.md) にある。

見返すのが楽しい家計簿。テーマ（`ThemePalette`）を自分で作れる。広告なし。

| 項目 | 内容 |
| --- | --- |
| 名前 | かけいぼっと（英語の表記は Kakeibot）。ストアの表示名は「家計簿 かけいぼっと - レシート読取・着せ替え」 |
| 対応 | iOS 18 以上（iPhone のみ、縦向き）・Android 8 以上 |
| 作る人 | 1 人。自分でも毎日使う（iPhone） |

## 📏 守ること

作るときに、次の決まりを守る。

> [!IMPORTANT]
> - 家計簿のデータを、外部の AI や自分たちのサーバーに送らない。置くのは端末と、使う人の iCloud だけにする
> - 最初は、作ったテーマを共有する機能を作らない

## 😣 解決したい不満

| 不満 | 対応する機能 |
| --- | --- |
| 使った金額が見えにくく、見直しにくい | 「今月あといくら」、振り返り |
| 絵文字やアイコンを自分で作れない | 自作のアイコン |
| デザインが簡素 | テーマ |
| 入力が面倒 | 速い入力、固定費（`Recurring`）の自動記録 |
| 音の出る広告 | 広告なし |
| 機種変更でデータが消える | 端末間の同期、OS のバックアップ、書き出し・読み込み |

## ✨ 最初のリリースの機能

AI は使わない。通信は、iCloud の同期と共有だけに使う。

| 機能 | 中身 |
| --- | --- |
| 速い入力 | 自分で作るテンプレート（`EntryTemplate`）で 1〜2 タップ。電卓、支出・収入・振替、振替の手数料、日付、メモ、カテゴリのタグ |
| 自分で作るアイコン | 絵柄・絵文字・短い文字と色で、カテゴリのアイコンとカレンダーのスタンプ（`CalendarStamp`）を作る |
| 財布（`Wallet`）の分け | 種類ごとに分け、画面では「口座」と呼ぶ。種類は [decisions/wallets.md の「財布の種類」](decisions/wallets.md#財布の種類)にある |
| 財布の編集 | 自分で足し、名前・アイコン・最初の残高を直せる。残高を出し、チャージと引き落としは振替にする |
| 予算 | 月全体とカテゴリごと。「今月あといくら使えるか」 |
| 固定費・繰り返し | 毎月・毎年の自動記録と、更新前の通知 |
| 振り返り | 支出と収入の月・週・年の合計、カテゴリと財布ごとの内訳、前の期間との比較、予算の消化、借入の返済と投資の積立 |
| 期間の区切り | 月の始まりを給料日に、週の始まりを月曜に。月の始まりが休日なら、前か次の平日にずらす |
| テーマ | 用意したテーマから選ぶ。文字・行の間隔・角・スタンプの形・背景・タブの名前・振動・飾りは、テーマとは別に選ぶ |
| テーマを作る（Pro） | 色を選び、読みにくい組み合わせは保存させない |
| 字体（Pro） | 明朝とゴシックは無料。丸ゴシック・手書き・ドット・ポップは Pro |
| ごほうび貯金（`RewardRule`・`RewardGoal`・`RewardLog`） | 自分で作った決まりの達成で仮想の貯金箱に貯まる。目標の物を買ったら記録する |
| 記録忘れの通知 | 決めた時刻までに記録も「支出なし」の印もない日に知らせる |
| ウィジェット | あといくら（残り・残りの日数・今日と今週の支出・次の固定費）と、すぐ記録。すぐ記録はテンプレートを押すとその場で記録する |
| ほかのウィジェット | ロック画面と、コントロールの「記録する」。今あるウィジェットは無料 |
| お知らせ | 更新で足した機能を、ホームのベルから絵のカードで知らせる |
| 広告なし・バックアップ | 広告を出さない。OS のバックアップと、書き出し・読み込み |
| 記録の一括削除 | 設定のデータから、記録・評価額・ごほうびの記録・スタンプ・支出なしの日をまとめて消す。財布・カテゴリ・設定と、共有中の財布の記録は残す |
| 端末間の同期（Pro） | 自分の iPhone どうしで、記録と設定を iCloud で同期する |
| 家族との共有（Pro） | それぞれが自分の家計簿をつけ、共有した財布の記録を相手と一緒につける。誘われる側は Pro が無くても使える |
| Pro の課金 | 買い切り（¥600）で買う。Apple のファミリー共有で家族も使える |

## 💰 この先の段階と収益化

最初のリリースの後に、足していく機能と収益の形を並べる。

| 段階 | 機能 | 収益 |
| --- | --- | --- |
| 最初のリリース | 上の表 | 無料。Pro（買い切り ¥600）：端末間の同期、家族との共有、テーマを作る、明朝とゴシックのほかの字体 |
| 次の更新 | 予算の繰越、記録の品目、レシートの読み取り（端末の中の文字認識と Foundation Models で品目まで読む）。iPhone Duo を開いた時の配置（左のサイドバー、振り返りと資産の 2 列） | Pro に、詳しい振り返り、テーマとアイコンの追加、自分の書体の読み込みを足す。レシートの読み取り（無料は 3 回）・Pro のウィジェット・データの書き出しも足す |
| その次 | Foundation Models で記録を読み、振り返りの言葉を出す（下の注） | AI の機能を Pro に含める |

「その次」は iOS で先に出す。Foundation Models の機能は、iOS 26 以上で動く。Apple Intelligence の対応機種に限る。

端末間の同期と家族との共有は、iCloud（CloudKit）で作る。サーバーは持たず、記録は使う人の iCloud に置く。iOS だけで動き、Android は対象にしない。

同期と共有の決定は [decisions/sync.md](decisions/sync.md) にある。
