# 概要

見返すのが楽しい家計簿。テーマを自分で作れる。広告なし。

| 項目 | 内容 |
| --- | --- |
| 名前 | かけいぼっと（英語の表記は Kakeibot）。ストアの表示名は「かけいぼっと - 自由な家計簿・小遣い帳」 |
| 対応 | iOS 18 以上（iPhone のみ、縦向き）・Android 8 以上 |
| 作る人 | 1 人。自分でも毎日使う（iPhone） |

## 守ること

作るときに、次の決まりを守る。

> [!IMPORTANT]
> - 家計簿のデータを、外部の AI や自分たちのサーバーに送らない。置くのは端末と、使う人の iCloud だけにする
> - 最初は、作ったテーマを共有する機能を作らない
> - クレジットは、期限なしのアプリ内課金で売る
> - 既存の作品・ブランド・実在の人物の名前を、AI へのプロンプトで止める

## 解決したい不満

| 不満 | 対応する機能 |
| --- | --- |
| 使った金額が見えにくく、見直しにくい | 「今月あといくら」、振り返り |
| 絵文字やアイコンを自分で作れない | 自作のアイコン |
| デザインが簡素 | テーマ |
| 入力が面倒 | 速い入力、固定費の自動記録 |
| 音の出る広告 | 広告なし |
| 機種変更でデータが消える | 端末間の同期、OS のバックアップ、書き出し・読み込み |

## 最初のリリースの機能

AI は使わない。通信は、iCloud の同期と共有だけに使う。

| 機能 | 中身 |
| --- | --- |
| 速い入力 | 自分で作るテンプレートで 1〜2 タップ。電卓、支出・収入・振替、日付、メモ、カテゴリのタグ |
| 自分で作るアイコン | 絵柄・絵文字・短い文字と色で、カテゴリのアイコンとカレンダーのスタンプを作る |
| 財布の分け | 種類ごとに分ける（種類は [decisions.md の「財布の種類」](decisions.md#財布の種類)）。画面では「口座」と呼ぶ。自分で足し、名前・アイコン・最初の残高を直せる。残高を出す。チャージと引き落としは振替 |
| 予算 | 月全体とカテゴリごと。「今月あといくら使えるか」 |
| 固定費・繰り返し | 毎月・毎年の自動記録と、更新前の通知 |
| 振り返り | 支出と収入の月・週・年の合計、カテゴリと財布ごとの内訳、前の期間との比較、予算の消化 |
| 期間の区切り | 月の始まりを給料日に、週の始まりを月曜に |
| テーマ（手作業） | 色。読みにくい組み合わせは保存させない。文字の大きさ・字体・角の丸みは、テーマとは別に選ぶ |
| ごほうび貯金 | 自分で作った決まりの達成で仮想の貯金箱に貯まる。目標の物を買ったら記録する |
| 記録忘れの通知 | 決めた時刻までに記録も「支出なし」の印もない日に知らせる |
| ウィジェット | あといくら、すぐ記録（テンプレートを押すとその場で記録）、ロック画面、コントロールの「記録する」。どれも無料 |
| 広告なし・バックアップ | 広告を出さない。OS のバックアップと、書き出し・読み込み |
| 端末間の同期（Pro） | 自分の iPhone どうしで、記録と設定を iCloud で同期する |
| 家族との共有（Pro） | それぞれが自分の家計簿をつけ、選んだ記録を相手と共有する |
| Pro の課金 | サブスクと買い切りから選んで買う |

## この先の段階と収益化

最初のリリースの後に、足していく機能と収益の形を並べる。

| 段階 | 機能 | 収益 |
| --- | --- | --- |
| 最初のリリース | 上の表 | 無料。Pro（サブスクと買い切り）：端末間の同期、家族との共有 |
| 次の更新 | レシートの読み取り（端末の中の文字認識） | Pro に、テーマとアイコンの追加、詳しい振り返り、データの書き出しを足す |
| その次 | AI でテーマを作る（下の注） | AI で作るテーマを Pro に含める |
| さらに先 | クラウドの AI | クラウドの AI は、期限なしのアプリ内課金のクレジット |

「その次」は iOS で先に出す。テーマは Foundation Models で言葉から作る。iOS 26 以上の対応機種だけで動く。

端末間の同期と家族との共有は、iCloud（CloudKit）で作る。サーバーは持たず、記録は使う人の iCloud に置く。iOS だけで動き、Android は対象にしない。

## 未決

まだ決まっていないことを、次に挙げる。

- Pro の値段と、サブスクの期間（月・年）
- 家族との共有で、誘われる側にも Pro が要るか
- Android の Pro の中身
- アプリアイコンの色違いを Pro に含めるか
- Pro の「データの書き出し」と、最初のリリースの書き出し・読み込みとの違い
- 今の家計簿からのデータの乗り換え
- Google Play での名前と商標の確認
