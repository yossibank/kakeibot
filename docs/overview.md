# 概要

見返すのが楽しい家計簿。テーマと、家計簿の相棒のキャラクターを自分で作れる。広告なし。

| 項目 | 内容 |
| --- | --- |
| 名前 | Kakeibot（カケイボット）。ストアの表示名の案は「カケイボット - 自分好みに作れる家計簿」 |
| 対応 | iOS 18 以上（iPhone のみ）・Android 8 以上 |
| 作る人 | 1 人。自分でも毎日使う（iPhone） |

## 守ること

作るときに、次の決まりを守る。

> [!IMPORTANT]
> - 家計簿のデータを、外部の AI やサーバーに送らない
> - 最初は、作ったテーマやキャラクターを共有する機能を作らない
> - クレジットは、期限なしのアプリ内課金で売る
> - 既存の作品・ブランド・実在の人物の名前を、AI へのプロンプトで止める

## 解決したい不満

| 不満 | 対応する機能 |
| --- | --- |
| 使った金額が見えにくく、見直しにくい | 「今月あといくら」、振り返り |
| 絵文字やアイコンを自分で作れない | 自作のアイコン |
| デザインが簡素 | テーマ、キャラクター |
| 入力が面倒 | 速い入力、固定費の自動記録 |
| 音の出る広告 | 広告なし |
| 機種変更でデータが消える | OS のバックアップ、書き出し・読み込み |

## 最初のリリースの機能

AI も通信も使わない。

| 機能 | 中身 |
| --- | --- |
| 速い入力 | よく使うカテゴリ・金額・財布を 1〜2 タップで。支出・収入・振替、日付、メモ |
| 自分で作るアイコン | 絵文字・色・短い文字で、カテゴリのアイコンとカレンダーのスタンプを作る |
| 財布の分け | 種類ごとに分ける（種類は [decisions.md の「財布の種類」](decisions.md#財布の種類)）。残高を出す。チャージと引き落としは振替 |
| 予算 | 月全体とカテゴリごと。「今月あといくら使えるか」 |
| 固定費・繰り返し | 毎月・毎年の自動記録と、更新前の通知 |
| 振り返り | 月・週の合計、カテゴリと財布ごとの内訳、前の期間との比較、予算の消化、「今月の自分」カード |
| 期間の区切り | 月の始まりを給料日に、週の始まりを月曜に |
| テーマ（手作業） | 色・角の丸み・フォント。読みにくい組み合わせは保存させない |
| キャラクター（手作業） | 用意したキャラクターから選んで名前を付ける。予算の残りやごほうびの達成で一言 |
| ごほうび貯金 | 自分で作った決まりの達成で仮想の貯金箱に貯まる。目標の物を買ったら記録する |
| 記録忘れの通知 | 決めた時刻までに記録も「支出なし」の印もない日に知らせる |
| ウィジェット | 「今月あといくら」と今日の支出 |
| 広告なし・バックアップ | 端末の中だけで動く。OS のバックアップと、書き出し・読み込み |

## この先の段階と収益化

| 段階 | 機能 | 収益 |
| --- | --- | --- |
| 最初のリリース | 上の表 | 無料 |
| 次の更新 | レシートの読み取り（端末の中の文字認識） | Pro（サブスクか買い切り）：テーマとアイコンの追加、詳しい振り返り、データの書き出し |
| その次 | iOS 先行。Foundation Models で言葉からテーマを、Image Playground でキャラクターを作る（iOS 26 以上・対応機種のみ） | AI で作るテーマとキャラクターを Pro に含める |
| さらに先 | クラウドの AI、家族との共有、端末間の同期 | クラウドの AI は、期限なしのアプリ内課金のクレジット |

## 未決

まだ決まっていないことを、次に挙げる。

- Pro の値段と形
- Pro の「データの書き出し」と、最初のリリースの書き出し・読み込みとの違い
- 最初に用意するキャラクターの素材
- 今の家計簿からのデータの乗り換え
- Google Play での名前と商標の確認
