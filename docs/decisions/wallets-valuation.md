# 投資の評価額

> [!NOTE]
> 投資の口座の評価額の持ち方と、振替で口座の額をどう見せるかの決定が分かる。
> 言葉の対応は [glossary](../glossary.md) にある。

## 評価額の入れ方

**決定：投資の口座の編集に「今の評価額」の行を置く。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 値動きが振り返りの収入や支出に混ざらない。過去の月の純資産も、その時点の額のまま残る |
| ❌ 却下 | ~~差額を収入か支出として記録する~~ 値動きが振り返りの収入や支出に混ざる |
| ❌ 却下 | ~~最初の残高を書き換える~~ 過去の月の純資産が、その時点の額のまま残らない |
| ❌ 却下 | ~~最新の評価額だけを口座に持つ~~ 過去の月の純資産が、その時点の額のまま残らない |

> [!IMPORTANT]
> - 値動きの分は、収入や支出の記録を作らない。
> - 前の評価額は消さないので、動きのグラフの過去の点は変わらない。

### 評価額からの残高

入れた額は、その日の評価額として [valuation](../data.md#valuation) に置き、残高をその額に合わせる。

$$\text{残高} = \text{評価額} + \text{評価額より後の記録の足し引き}$$

評価額を入れた日と同じ日の記録は、評価額より後に作ったものだけを、評価額に足し引きする。

### これまでの評価額

| 状態 | 見た目 | 操作 |
| :---: | --- | --- |
| 評価額がある | 編集の画面の「これまでの評価額」に新しい順に並べる | 横に払うと消す |
| 消した直後 | 前の評価額から数え直し、「取り消す」の知らせを出す | 押すと戻す |

### 振替の口座のカード

入力シートの振替では、口座の下に「チャージ・カードの引き落とし・口座どうしの移動」と例を出す。口座のカードには、見出しを左、額を右にそろえた 2 行を出す。

| 行 | 借入 | 投資 | ほか |
| :---: | --- | --- | --- |
| 1 行目（今の額） | 今の残り | 今の評価額 | 残高 |
| 2 行目（額を入れた後、振替先の呼び方） | 返済後 | 積立後 | 振替後 |

振替先が借入なら、下に「残り ¥100,000 をまとめて返す」のボタンを出し、押すと残りの額を入れる。
