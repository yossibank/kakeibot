# カードの締め日と引き落とし

> [!NOTE]
> カードの利用分の振替、請求を次に回すこと、これからの引き落としの決定が分かる。
> 固定費の決定は [recurring](recurring.md)、予算の決定は [budget](budget.md)、言葉の対応は [glossary](../glossary.md) にある。

## 利用分の振替

**決定：引き落とし日に、その回の締め日までの 1 か月の利用分を額にして、振替を作る。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 固定費の休日の扱い・知らせ・今月の固定費をそのまま使える。カードを使うほど額が変わっても、手で直さなくてよい |
| ❌ 却下 | ~~口座（`Wallet`）の設定に締め日を置く~~ 固定費の休日の扱い・知らせ・今月の固定費を使えない |
| ❌ 却下 | ~~毎月の額を手で入れる~~ カードを使うほど額が変わり、手で直すことになる |

> [!IMPORTANT]
> - 翌々月払いのカードは、まだ扱わない。
> - 利用分が 0 円なら作らない。
> - 手で直した振替は変えない。

### 締め日と引き落としを決める所

- 振替先がカードの固定費は、「金額の決め方」で決まった額か利用分かを選ぶ。
- 利用分を選ぶと、締め日を 1〜31 日（31 は末日）から選ぶ。
- カードの口座の編集にも「締め日と引き落とし」の行を置き、その固定費の編集を開く。
- まだ無ければ、そのカードへの振替を、末日締め・27 日払いの利用分として作り始める。
- カードを足して保存すると、借入の返済と同じく、締め日と引き落としも決めるかを聞く。

### 利用分の期間

利用分の期間は、休日でずらす前の予定日から決める。

| 引き落とし日と締め日 | 締める月 |
| :---: | --- |
| 引き落とし日が締め日より後 | 予定日と同じ月 |
| 引き落とし日が締め日と同じか前 | 前の月 |

締める月は、設定した引き落とし日と締め日で決める。丸めは月を決めた後に 1 回だけ行う。

期間は、前の月の締め日の翌日から、締め日までにする。短い月は末日に丸め、期間は隙間なく重ならずに続く。

### 利用分の額

$$\text{利用分} = \text{カードで払った支出} + \text{カードから出た振替} - \text{カードに入った収入}$$

どれも、その期間の物を数える。カードでの積立も、利用分に入る。カードに入る振替（引き落としなど）は数えない。

### 計算し直す時

手で直していない振替は、`updatedAt` が `createdAt` と同じものを指す。

| 状態 | 振替 |
| --- | --- |
| 自動で作って手で直していない振替で、その期間の利用が変わった | 計算し直し、0 円になれば消す |
| 手で直した振替 | 変えない |
| 振替が無い回で、書き込みの前の額が 0 円、後の額が 0 円より大きい | 作る |
| 振替が無い回で、前の額が 0 円より大きい | 人が消したものとして作らない |
| 記録を戻す時に、同じ固定費の同じ回の振替がもうある | それを消して元の振替を戻す |
| 固定費の削除を取り消した | 計算し直さない。削除の時に計算し直していないので、削除の前と同じに戻す |
| 固定費の締め日や引き落とし先を変えた | 作った振替は計算し直さない |
| カードの引き落としを別のカードから払い、作った振替の額が変わった | 払う側のカードの振替も計算し直す |

### 一覧と知らせ

- 固定費の一覧の行は、名前と金額・繰り返し・口座と次の日の 3 行にする。
- 締め日は「15 日締め・次は 10/26」のように次の日と並べる。
- 知らせは額を入れず、「10/26 に引き落としがあります」と出す。

## 請求を次に回す

**決定：カード会社の確定が遅れた記録は、後の引き落としに回せる。**

> [!IMPORTANT]
> - 決めるボタンは置かない。選んだ回は、そのまま記録に入る。
> - 回した記録は、その回（休日でずらす前の予定日の月）の引き落としに入れ、元の期間からは外す。
> - 支払い元や日付を変えると、いつもどおりに戻す。

### 入力シートの請求の行

| 状態 | 見た目 | 操作 |
| --- | --- | --- |
| 支払い元でカードを選んだ | 口座の中身のタイルの下に「12/26 に引き落とし　変える」の 1 行を出す。「いつもどおり」にしておく | 行を押すと、その下に「請求」の 3 枚のめくりカレンダーを開く。もう一度押すと閉じる |
| 回した記録を開いた | めくりカレンダーを開いておく | |
| 回すテンプレートを使った | めくりカレンダーを開いておく | |
| 回した | 行の日付の横に「次に回す」「2 回先」の札を添える | |

- めくりカレンダーには「いつもどおり」「次に回す」「2 回先」を並べる。
- 「いつもどおり」は、固定費の始まりより前でも、使った日が入る期間の回にする。
- めくりカレンダーの下に、選んだ回の利用の期間と引き落としの日を 1 文で出す。
- 入力シートの支払い元の欄には、見出しの代わりに`12/26払い`と出す。

### 記録の行と、これからの引き落とし

- 記録の行では、口座の名前に`（12/26払い）`のように、その回の実際の引き落とし日を添える。非表示の固定費と、終わりの日を過ぎた固定費は使わない。残りが 1 件に決まらない時は`（12月払い）`と添える。
- 「これからの引き落とし」には「前から 1 件・後へ 1 件」のように回した件数を添え、押すと回した記録を並べる。
- 記録を押すと、その記録を開く。

## テンプレートと固定費の請求

**決定：テンプレートと固定費は、請求を何回あとに回すかを持ち、記録を作るたびにその回の請求に入れる。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 毎回確定が遅れるサブスクなどを、記録のたびに回し直さずに済む |
| ❌ 却下 | ~~請求の月をそのまま持つ~~ 使う日で回が変わるので、テンプレートと固定費では決められない |
| 関連 | [data.md の template](../data.md#template) |

> [!IMPORTANT]
> - 入力盤の口座の中身でカードを選ぶと、中身を替えずに請求の行を出す。
> - 固定費では、次の記録が入る回を`12/26払い`のように添える。テンプレートは、使った日から見た回を文で添える。
> - 支払い元を変えると、いつもどおりに戻す。入力シートでテンプレートを使うと、その回を選んだ状態にする。

## これからの引き落とし

**決定：まだ来ない引き落としを、引き落とし日の月ごとのページに分け、次の回とその次の回まで見込みの額を出す。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 締め日を過ぎて額が決まった回と、締め日の前でまだ増える回を分けて見られる。次の月の分も前もって見える |
| ❌ 却下 | ~~カードごとに次の 1 回だけを出す~~ 次の月が見えない |

> [!IMPORTANT]
> - 振替先がカードの固定費ごとに、明日より後の次の回とその次の回の、引き落とし日と見込みの額を出す。
> - 締め日が今日か今日より後の回は、額がまだ決まっていない「見込み」の回とし、締め日を過ぎた回は「確定」とする。
> - 額が 0 円の回は、見込みでも確定でもページに入れない。0 円の回しか無い月は、ページを作らない。

### 使う所

今月の固定費・記録のカレンダー・固定費の一覧・資産のタブで使う。ホームと資産のタブには「これからの引き落とし」を出す。

### ページとタブ

回は、引き落とし日の月（休日でずらす前の予定日の月）でページに分ける。ページは、次の回がある月とその翌月の 2 つまでにする。

| 状態 | 見た目 | 操作 |
| --- | --- | --- |
| ページが 2 つ | 見出しの下に、ページごとのタブを等幅で横に並べる | 押すか左右に払う操作で切り替える |
| ページが 1 つ | タブを出さず、見出しの右に `11月払い ¥74,000` と添える | |
| 選んだタブ | アクセントから濃いアクセントへの斜めのグラデーションに柔らかい影を付ける | |
| 選んでいないタブ | 地の色に細い線を引く | |

タブには `11月払い`・そのページの合計・「2 件 · 1 件は見込み」の 3 行を出す。すべて見込みなら「2 件 · すべて見込み」、見込みが無ければ「2 件」とする。

回の並びは、ページを横に並べて指に合わせて動かす。カードの高さは、ページの間の位置に合わせて 2 つの高さの間で変える。

### 見込みと確定

| 状態 | 見た目 |
| :---: | --- |
| 見込み | 額の下に小さな輪と「見込み · 11/15 締め」をアクセントの色で出し、額もアクセントの色にする。足りない額は出さない |
| 確定 | 額の下にアクセントの色の丸に入れたチェックと「確定」を出す |

輪は、利用期間の始まりから締め日までの日数のうち、今日までに進んだ割合を弧で描く。締め日の無い回は満ちた輪にする。

$$\text{輪の割合} = \frac{\text{利用期間の始まりから今日までに進んだ日数}}{\text{利用期間の始まりから締め日までの日数}}$$

### 行

行は 1 つの部品で描き、ホームは短い版、資産は詳しい版にする。行を押すと、その固定費の編集を開く。

- 日付はめくりカレンダーの形にし、短い版では小さくする。
- あと何日かは「今日」「明日」「あと 21 日」と、アクセントの色で出す。
- 足りなければ「残高が ¥1,200 足りません」と、薔薇色で出す。

| 版 | 見た目 |
| :---: | --- |
| 短い版 | 名前の下に「銀行から · あと 21 日」を添え、額と状態を右に置く。収まらなければ額を名前の行に、状態を「銀行から」の下に回す |
| 詳しい版 | 利用分の期間と、引き落とされる割合の細い線を出す。線の下に、引き落とし元の口座の名前とあと何日かを添える |
| 詳しい版の 2 行目 | 「¥459,600 → ¥408,800」か、足りない額を出す |

詳しい版の期間は「10/16〜11/15 の利用分」と出す。収まらなければ「10/16〜11/15」、さらに「11/15 締め」と縮める。額の下に状態が収まらなければ、状態を利用期間の下に回す。

### 引き落とし元の残高の見込み

$$\text{残高の見込み} = \text{引き落とし日の前日までの残高} - \text{同じ口座から先に引き落とされる回の額}$$

引き落とし日の前日までの残高は、その日までの記録と残高の調整で数える。未来の日付の記録も入れる。

### カードの口座の欄と知らせ

- カードの口座の欄には、未払いの額の下に回ごとの小さな予定表を並べる。決まりは[手元のお金と純資産](net-worth.md#手元のお金と純資産)にある。
- 引き落としの知らせは、その日に口座が足りなくなる見込みなら、「銀行が ¥12,000 足りません」と添える。
- 知らせの見込みは、カードごとに次の回だけを、知らせを組み直す時の記録で決める。
