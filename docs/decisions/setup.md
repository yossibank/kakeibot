# 最初の設定とホーム

> [!NOTE]
> 最初の設定、ホーム、設定の置き場所の決定が分かる。
> 言葉の対応は [glossary](../glossary.md) にある。

## 最初の設定

最初の設定は、始め方・準備のカード・自分好みにカスタマイズのカード・金の光を決める。

### 始め方

**決定：最初の起動では、ようこそのページで始め方を選んでもらい、始め方ごとに続くページを変える。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 早く始めたい人を待たせず、決めたい人は最初に決められる。後回しにした設定も、ホームから拾える |
| 却下 | 全員に同じページを出す、始め方を選ばせずにページを増やす、始め方ごとに専用の画面を作る |

> [!IMPORTANT]
> - 題は画面の中ほどに置き、始め方のボタンは下にまとめる。
> - 勧める「予算を決めて始める」だけを塗ったボタンにし、ほかの 2 つは 1 枚のカードに行で並べる。
> - 「ほかに決めること」には、記録の準備と自分好みにの 2 つのまとまりを並べる。
> - 記録の準備は、口座（`Wallet`）と今の残高・使うカテゴリ・固定費（`Recurring`）にする。
> - 記録の準備には、テンプレート（`EntryTemplate`）と記録忘れの通知も入れる。
> - 自分好みには、起動時に開く画面・テーマ（`ThemePalette`）・アプリアイコン・文字・形と動きにする。
> - 行を押すと設定と同じ画面を開き、閉じると戻る。
> - 決めたことがデータで分かる行には、印を付ける。
> - どのページも、選ぶとすぐ保存し、あとで設定から変えられる。
> - ページは左右に払っても送れる。
> - ページは、記録や振り返りと同じく、消してから反対側から入れる。
> - 最後のページは、「はじめる」を押したときだけ終える。
> - ようこそより後のページでは、「設定を飛ばして始める」で残りのページを飛ばして終えられる。
> - ページの点は、ようこそを除いた続くページの数だけ出す。

始め方ごとに、続くページは次のとおり。

| 始め方 | 続くページ |
| --- | --- |
| 決めずに始める | なし。押すとすぐ終える |
| 予算を決めて始める | 月と週の始まり、月の予算 |
| しっかり決めて始める | 月と週の始まり、月の予算、ほかに決めること |

### 準備のカード

**決定：ホームの見出しの直後に、月の予算・口座の今の残高・固定費のうち、まだ決めていないものをカードで並べる。**

> [!IMPORTANT]
> - 行を押すと、設定と同じ画面をシートで開く。
> - すべて決めるか、カードを閉じると出さない。
> - カードは、ほかの中身と一緒に出す。
> - 起動画面は、準備の状態を読み終えるまで待つ。

### 自分好みにカスタマイズのカード

**決定：初めの並びでは、準備のカードの次、予算のダイヤルの前に、自分好みにカスタマイズのカードを出す。**

> [!IMPORTANT]
> - 自分好みにと同じ項目を、今の値を添えたタイルで横に並べ、払って送る。
> - タイルを押すと、設定と同じ画面をシートで開く。
> - カードとタイルから開いた画面は、左上を「×」にする。
> - 値が変わったタイルは、シートを閉じたときに、縁を少し光らせる。
> - カードを閉じると、ホームに出すもので非表示にしたのと同じにする。

### 金の光

**決定：入力シートを一度も開いていない間は、入力の ＋ の輪に沿って金の光を回す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 記録は一番大事な操作なので、最初に目を引く。設定へは準備とカスタマイズのカードで案内できる |
| 却下 | 設定のボタンにも金の点を出す |

開いたかどうかは、DB の設定に置く。

## 起動時に開く画面

**決定：ホーム・記録・振り返り・資産・入力シートから選ぶ。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 記録をすぐ入れたい人は、1 回押す手間が減る |
| 却下 | 端末の UserDefaults に置く |

> [!IMPORTANT]
> - 既定はホームにする。
> - タブの画面なら、そのタブから始める。
> - 入力シートなら、ホームの上に入力シートを開く。
> - DB の設定に置き、書き出しにも入れる。
> - 設定では、別の画面で選ぶ。
> - 下のタブの並びの見本を出し、選んだ画面の所を光らせる。

## ホームに出すもの

ホームに出すものは、並べ替えと非表示にする操作と、選ぶ画面を決める。

### 並べ替えと非表示

**決定：設定の「ホームと通知」の「ホームに出すもの」では、ホームの次のものを並べ替え、非表示にできる。**

| 項目 | 内容 |
| --- | --- |
| 理由 | ホームが空になる形を作らない。カスタマイズは一度決めるとあまり触らないので、閉じても後から戻せればよい |
| 却下 | すべて非表示にできる、月の表示も動かせる、閉じた準備のカードをこの画面で戻す、カスタマイズのカードをいつも出す |

並べ替え、非表示にできるものは、次のとおり。

- 予算のダイヤル
- 自分好みにカスタマイズのカード
- テンプレート
- 最近の記録
- これからの引き落とし
- 押したスタンプ

> [!IMPORTANT]
> - 初めの並びは、カスタマイズのカード・予算のダイヤル・テンプレート・最近の記録とし、保存した並びは書き換えない。
> - これからの引き落としと押したスタンプは、初めは非表示にする。
> - 月の表示とベル・歯車の行は、いつも一番上に置く。
> - 準備のカードは並べ替えに入れず、月の表示の直後に置く。
> - 閉じたら、この画面からも戻さない。
> - すべては非表示にできず、最後の 1 つは枠へ運べない。
> - これからの引き落としは、資産と同じく引き落とし日の月のページに分けて日付の順に並べ、行は短い版にする。
> - 行を押すと、その固定費を開く。
> - 押したスタンプのカードは、ホームの期間に押した `CalendarStamp` を種類ごとに数えて並べる。
> - スタンプを押すと、振り返りと同じく押した日を一覧で出し、日を押すと記録のタブでその日を開く。

### 選ぶ画面

**決定：選ぶ画面では、ホームと同じ縦の順に行を並べ、行の左にそのカードを縮めた見本を描く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 行の順がホームの縦の順と同じなので、並びを読み違えない。非表示にするのは口座やカテゴリと同じく下の枠へ運ぶ |
| 却下 | カテゴリや口座と同じ 2 列のタイルの板、ホームの見本と出す・非表示にするの行を別に並べる |

行を長押しして上下に動かすと並べ替え、下の点線の枠へ運ぶと非表示にし、枠から上へ戻すと出す。枠の見出しは、空のときは「ここに置くと非表示にできます」、あるときは「非表示のもの（数）」にする。並びと非表示のものは DB の設定に置き、書き出しにも入れる。

## 確かめ用のテストデータ

**決定：DEBUG のビルドだけ、設定の「開発」に「テストデータを入れる」を置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 振り返り・カレンダー・予算を、何か月分もの記録で手早く確かめられる。リリースのビルドには入らない |
| 却下 | 手で入れる、書き出しのファイルを読み込む、端末を振ると開くメニュー |

> [!IMPORTANT]
> - 今日までの 120 日分の記録（支出・収入・振替）と、支出なしの印も足す。口座のカード・投資・借入、予算、テンプレートも足す。
> - 固定費は、スマホ・給料・カードの引き落とし・家賃・借入の返済を足す。
> - 額は日付から決め、毎回同じ形にする。

## 設定の置き場所

**決定：選んだ値・並べ順・一度出したヒントは、DB の `setting` に置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 置き場所が 1 つになり、書き出しにも入る |
| 却下 | 端末の UserDefaults に置く |

UserDefaults には置かない。

## 設定の表の key

**決定：`setting` の `key` は、表の CHECK で縛らない。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 設定を足すたびに表を作り直さずに済む |
| 却下 | 足すたびに CHECK を作り直す |

決まった名前はアプリの型で持つ。

## 最初の財布とカテゴリ

**決定：DB を開いたときに、決まった財布とカテゴリを入れる。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 編集の画面より先に、毎日の記録を始められる。テンプレートの使い方も、最初から見て分かる |
| 却下 | 最初の設定で選ばせる、空のまま始める |
| 関連 | 中身は [data.md の「最初に入るデータ」](../data.md#-最初に入るデータ)にある |

最初の設定を開いたときに、金額を空にした支出のテンプレートも入れる。

## 新しい記録の口座

**決定：新しく記録するときの口座は、並べた先頭の口座にする。**

| 項目 | 内容 |
| --- | --- |
| 理由 | カテゴリを押し替えても口座が動かず、どの口座で始まるかが分かりやすい。並べ替えで先頭を選べる |
| 却下 | カテゴリで最後に入れた記録の口座にする、カテゴリに既定の口座を持たせる、最後に使った口座だけを使う |

カテゴリや種類を変えても、口座は変えない。
