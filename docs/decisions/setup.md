# 最初の設定とホーム

> [!NOTE]
> 最初の設定、ホーム、設定の置き場所の決定が分かる。
> 言葉の対応は [glossary](../glossary.md) にある。

## 最初の設定

最初の設定は、始め方・準備のカード・自分好みにカスタマイズのカード・金の光と点を決める。

### 始め方

**決定：最初の起動では、ようこそのページで始め方を選んでもらい、始め方ごとに続くページを変える。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 早く始めたい人を待たせず、決めたい人は最初に決められる。後回しにした設定も、ホームから拾える |
| 却下 | 全員に同じページを出す、始め方を選ばせずにページを増やす、始め方ごとに専用の画面を作る |

決まり：

- 題は画面の中ほどに置き、始め方のボタンは下にまとめる。
- 「ほかに決めること」には、記録の準備と自分好みにの 2 つのまとまりを並べる。
- 記録の準備は、口座と今の残高・使うカテゴリ・固定費・テンプレート・記録忘れの通知にする。
- 自分好みには、起動時に開く画面・テーマ・アプリアイコン・文字と角の丸みにする。
- 行を押すと設定と同じ画面を開き、閉じると戻る。
- 決めたことがデータで分かる行には、印を付ける。
- どのページも、選ぶとすぐ保存し、あとで設定から変えられる。
- ページは左右に払っても送れる。
- ページは、記録や振り返りと同じく、消してから反対側から入れる。
- 最後のページは、「はじめる」を押したときだけ終える。
- ようこそより後のページでは、スキップもできる。

始め方ごとに、続くページは次のとおり。

| 始め方 | 続くページ |
| --- | --- |
| すぐ始める | なし。押すとすぐ終える |
| 予算だけ決めて始める | 月と週の始まり、月の予算 |
| しっかり決めて始める | 月と週の始まり、月の予算、ほかに決めること |

### 準備のカード

**決定：ホームのダイヤルの下に、月の予算・口座の今の残高・固定費のうち、まだ決めていないものをカードで並べる。**

決まり：

- 行を押すと、設定と同じ画面をシートで開く。
- すべて決めるか、カードを閉じると出さない。
- カードは、ほかの中身と一緒に出す。
- 起動画面は、準備の状態を読み終えるまで待つ。

### 自分好みにカスタマイズのカード

**決定：準備のカードの下に、自分好みにカスタマイズのカードを出す。**

決まり：

- 自分好みにと同じ項目を、今の値を添えたタイルで横に並べ、払って送る。
- タイルを押すと、設定と同じ画面をシートで開く。
- カードとタイルから開いた画面は、左上を「×」にする。
- 値が変わったタイルは、シートを閉じたときに、縁を少し光らせる。
- カードを閉じると、ホームに出すもので隠したのと同じにする。

### 金の光と点

**決定：入力シートを一度も開いていない間は、入力の ＋ の輪に沿って金の光を回す。設定を一度も開いていない間は、ホームの設定のボタンの右上に金の点を出す。**

決まり：

- 開いたかどうかは、DB の設定に置く。

## 起動時に開く画面

**決定：ホーム・記録・振り返り・資産・入力シートから選ぶ。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 記録をすぐ入れたい人は、1 回押す手間が減る |
| 却下 | 端末の UserDefaults に置く |

決まり：

- 既定はホームにする。
- タブの画面なら、そのタブから始める。
- 入力シートなら、ホームの上に入力シートを開く。
- DB の設定に置き、書き出しにも入れる。
- 設定では、別の画面で選ぶ。
- 下のタブの並びの見本を出し、選んだ画面の所を光らせる。

## ホームに出すもの

ホームに出すものは、並べ替えと隠す操作と、選ぶ画面を決める。

### 並べ替えと隠す

**決定：設定の「使い方」の「ホームに出すもの」では、ホームの次のものを並べ替え、隠せる。**

| 項目 | 内容 |
| --- | --- |
| 理由 | ホームが空になる形を作らない。カスタマイズは一度決めるとあまり触らないので、閉じても後から戻せればよい |
| 却下 | すべて隠せる、月の表示も動かせる、閉じた準備のカードをこの画面で戻す、カスタマイズのカードをいつも出す |

並べ替え、隠せるものは、次のとおり。

- 自分好みにカスタマイズのカード
- 予算のダイヤル
- テンプレート
- 最近の記録
- これからの引き落とし
- 今月のスタンプ

決まり：

- これからの引き落としと今月のスタンプは、初めは隠す。
- 月の表示と歯車の行は、いつも一番上に置く。
- 準備のカードは並べ替えに入れず、その下に置く。
- 閉じたら、この画面からも戻さない。
- すべては隠せず、最後の 1 つは枠へ運べない。
- これからの引き落としは、資産と同じくカードの次の引き落としを日付の順に並べ、残高が足りないときは足りない額を添える。
- 行を押すと、その固定費を開く。
- 今月のスタンプは、ホームの期間に押したスタンプを数えて並べる。

### 選ぶ画面

**決定：選ぶ画面では、ホームと同じ縦の順に行を並べ、行の左にそのカードの骨組みを小さく描く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 行の順がホームの縦の順と同じなので、並びを読み違えない。隠すのは口座やカテゴリと同じく下の枠へ運ぶ |
| 却下 | カテゴリや口座と同じ 2 列のタイルの板、ホームの見本と出す・隠すの行を別に並べる |

決まり：

- 行を長押しして上下に動かすと並べ替え、下の点線の枠へ運ぶと隠し、枠から上へ戻すと出す。
- 並びと隠すものは DB の設定に置き、書き出しにも入れる。

## 確かめ用のテストデータ

**決定：DEBUG のビルドだけ、設定の「開発」に「テストデータを入れる」を置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 振り返り・カレンダー・予算を、何か月分もの記録で手早く確かめられる。リリースのビルドには入らない |
| 却下 | 手で入れる、書き出しのファイルを読み込む、端末を振ると開くメニュー |

決まり：

- 今日までの 120 日分の記録（支出・収入・振替）、支出なしの印、口座のカード・投資・借入、予算、テンプレートも足す。
- 固定費は、スマホ・給料・カードの引き落とし・家賃・借入の返済を足す。
- 額は日付から決め、毎回同じ形にする。

## 設定の置き場所

**決定：選んだ値・並べ順・一度出したヒントは、DB の `setting` に置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 置き場所が 1 つになり、書き出しにも入る |
| 却下 | 端末の UserDefaults に置く |

決まり：

- UserDefaults には置かない。

## 設定の表の key

**決定：`setting` の `key` は、表の CHECK で縛らない。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 設定を足すたびに表を作り直さずに済む |
| 却下 | 足すたびに CHECK を作り直す |

決まり：

- 決まった名前はアプリの型で持つ。

## 最初の財布とカテゴリ

**決定：DB を開いたときに、決まった財布とカテゴリを入れる。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 編集の画面より先に、毎日の記録を始められる。テンプレートの使い方も、最初から見て分かる |
| 却下 | 最初の設定で選ばせる、空のまま始める |
| 関連 | 中身は [data.md の「最初に入るデータ」](../data.md#最初に入るデータ)にある |

決まり：

- 最初の設定を開いたときに、金額を空にした支出のテンプレートも入れる。

## 新しい記録の口座

**決定：新しく記録するときの口座は、並べた先頭の口座にする。**

| 項目 | 内容 |
| --- | --- |
| 理由 | カテゴリを押し替えても口座が動かず、どの口座で始まるかが分かりやすい。並べ替えで先頭を選べる |
| 却下 | カテゴリで最後に入れた記録の口座にする、カテゴリに既定の口座を持たせる、最後に使った口座だけを使う |

決まり：

- カテゴリや種類を変えても、口座は変えない。
