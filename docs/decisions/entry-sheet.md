# 入力シートの見た目

> [!NOTE]
> 記録を入れるシートの見た目と動きをどう決めたかと、その理由が分かる。
> 言葉の対応は [glossary](../glossary.md) にある。

## 入力シートの形

**決定：種類の切り替えの下に、上に紙のカード、下に入力盤を並べる。2 つを囲む板は置かず、テーマの色だけで描く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | カードと入力盤が重ならず、シート全体が 1 つのまとまりに見える |
| 理由 | 選んだ行に金の線が付き、いま何を入れているかが分かる |
| 理由 | 開いた直後に、カテゴリと最近の記録から始められる |
| 却下 | カードの下に切符と付箋を並べ、入力盤をカードに重ねる |
| 却下 | 2 つを 1 枚の板で囲む。板の面と線が、紙のカードの枠と二重になる |
| 却下 | 半円のダイヤル、項目の帯、見た目を設定で選ぶ、円のダイヤル、財布・日付・メモのチップ |

> [!IMPORTANT]
> - 色は、テーマの色の役だけを使う。入力盤は `panel` に `accent` をわずかに混ぜた色、強調は `accent` で塗る。
> - 紙のカードと入力盤の後ろは、シートの背景のままにする。
> - シートは送らず、紙のカードを決まった高さにする。残りの高さは、入力盤が全部使う。
> - 入力盤の中身だけは、カードの請求などで入りきらない時に、その中身を送る。
> - シートは高さを止めず、いっぱいに出す。縦に余る端末では、入力盤を下まで伸ばす。
> - 余った高さで、カードや入力盤の中身を大きくしない。どの端末でも同じ大きさで出す。

## 種類の切り替え

**決定：支出・収入・振替は、種類ごとに独立したキー（`EntryTypeSwitch`）にし、選んだ種類を金の面にする。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 厚みのあるキーの形にすると、押せることが形で分かる |
| 却下 | 幅いっぱいのカプセルの器とつまみが滑る切り替え、字と下線だけの切り替え |
| 却下 | フォルダのつまみ、印付きの 3 枚のカード、明朝の見出しと下線、金貨のメダル |

> [!IMPORTANT]
> - キーは中身の幅にして左に寄せ、右の丸いボタンより低くする。狭い時は幅を縮める。
> - 支出は上向き、収入は下向き、振替は左右の矢印を、名前の前に添える。
> - 選んでいないキーは、線で囲んで下に厚みの段と影を付ける。
> - 選んだキーは、金の面と淡い光にして少し下げ、字を太くする。
> - 右に、既存の記録を直す時は「削除」、いつも「閉じる」の丸いボタンを並べる。

## 最近の記録

**決定：開いた直後は、保存のボタンの代わりに「テンプレート」と「最近の記録」を 1 列ずつ並べる。振替も同じ形で「最近の振替」を出す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 金額が 0 の間は保存できないので、保存のボタンより役に立つ |
| 理由 | 同じ店や同じ買い物を、カテゴリと金額をまとめて入れられる |
| 却下 | 「金額を入れてください」と「続けて」 |

> [!IMPORTANT]
> - 同じ種類の記録を新しい順に 3 件まで並べ、カテゴリ・金額・メモが同じものは 1 件にまとめる。
> - 繰り返しの記録、振替、隠したカテゴリの記録は並べない。
> - テンプレートの列を上に、最近の記録の列を下に置き、列ごとに入りきらない分を横に送る。無い方の列は出さない。
> - 札の 1 行目に名前、2 行目に「カテゴリ・口座の種類」と金額を出す。日付は出さない。
> - 最近の記録の札は、カテゴリの印とメモを名前にする。メモが無ければカテゴリの名前を名前にし、2 行目は口座の種類だけにする。
> - テンプレートの札は、金額を決めていなければ金額の場所に「毎回入れる」と出す。
> - 押すと、口座・カテゴリ・タグ・メモ・金額を入れ、金額の中身に替える。日付は変えない。
> - 振替の「最近の振替」は [entry-transfer](entry-transfer.md#最近の振替) にある。
> - 記録が無ければ、何も出さない。

## 紙のカード

**決定：紙のカードは、金の枠と影のある 1 枚にし、どの端末でも同じ高さで出す。金額と項目を縦の行に並べ、下にメモを置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 行が値の表示と項目の切り替えを兼ねると、同じ項目を 2 か所に出さずに済む |
| 理由 | 行の幅を全部使うと、長い名前が見切れにくい |
| 却下 | 右上に予算や前回の記録の補足と割合の線を出す。金額で大きさが変わる |
| 却下 | カテゴリの印を、カテゴリの色の淡い面で塗る |
| 却下 | 項目を 3 等分の札にして横に並べる、札に厚みを付ける、値を太字にする、金額を 48 で出す |
| 理由 | 枠と影で背景から浮かせると、入れた値が入力盤より先に目に入る |
| 却下 | 金額を左に寄せて右にカテゴリの大きな印を置く、口座と日付を枠のない字で並べる |
| 却下 | 金額の後ろの光、右上の細い円の飾り、レシートの入口をカメラの印にする |
| 却下 | 開いた直後だけ、レシートと声の 2 枚の大きなタイルを出す |
| 却下 | 口座と日付の切符、メモの付箋、項目の帯、補足を消す、入力盤の上に項目のつまみを並べる |
| 却下 | 日付の札を中身の幅にする、端末の高さでカードを詰める |

> [!IMPORTANT]
> - カードは左上から金が淡く差す面にし、金の細い枠と影を付ける。
> - カードと入力盤の間は、20 空ける。
> - 行は上から、項目の 3 行・金額・メモにし、細い線で区切る。項目の行の高さは 44 にする。
> - 支出と収入の項目はカテゴリ・口座・日付、振替の項目は振替・手数料・日付にする。
> - 行は、左に印と小さな見出し、右に値と › を置く。押すと、入力盤をその中身に替える。
> - 値は中くらいの太さの字で 1 行に出す。入りきらなければ縮め、それでも入らなければ末尾を切る。
> - 選んだ行は、左の端に金の線を立て、左から金が淡く差す面にする。見出しと › を金にする。
> - 金の線は 4 の幅で行の高さいっぱいに立て、カードの端に重ねる。いちばん上の行では、カードの角の丸みに沿わせる。
> - 金額は見出しの字体で右に出す。行に入りきらない時だけ縮める。
> - 金額を入れている間だけ、上が明るく下が金になる色の流れで描く。ほかの間は字の色にする。
> - 振替の手数料を入れている間も、金額は振替の金額のままにする。
> - 金額の印は、金の丸に円の印にする。日付の印は日にちの日めくりにし、値に曜日を添える。
> - カテゴリと口座の印は、選んだもののアイコンにする。面を塗らず、その色の枠線で囲む。
> - 口座は、カードの請求を回した時は請求の名前にする。振替の値は「振替元 → 振替先」にする。
> - 手数料の値は、金額か「なし」にする。
> - 次の時は、値を琥珀色にする。日付が今日でない、口座が始めの口座でないか請求を回した、手数料がある。
> - 始めの口座は [setup の「新しい記録の口座」](setup.md#新しい記録の口座)にある。
> - 金額の見出しの右には、計算の式と、声を聞く間の音の波だけを小さく出す。
> - メモは、いちばん下の行に入れる。行の右に、レシートと声の丸いボタンを 32 の大きさで並べる。
> - 無料の間は、レシートのボタンの右上に、残りの回数を金の小さな札で重ねる。0 回は琥珀色にする。Pro では出さない。
> - 丸いボタンは、使えない時と声を聞く間は出さない。
> - 品目がある時は、丸いボタンの左にカプセルを出し、件数と品目の合計を並べる。

## メモの行

**決定：メモは、紙のカードの点線の下に鉛筆の印と並べて出し、押すとキーボードのすぐ上にメモのカードを出す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 1 行に決めると、メモの長さでカードの高さが変わらない |
| 却下 | 少し傾けた付箋、項目の帯の右の端のメモの印、1 行の枠と「全文」、2 行分の高さを取る形 |

メモは 1 行だけ出し、超えた分は省く。

メモが空の時は、薄い字で案内を出す。案内は次のとおり。

| 状態 | 見た目 |
| --- | --- |
| 支出 | 「店名や買ったものをメモ」 |
| 収入 | 「どこから入ったかをメモ」 |
| 振替 | 「何のための移動かをメモ」 |

メモのカードは、テンプレートのメモと同じ組み方で出す。キーボードの余白だけを無視した中身に重ね、画面の下の余白を無視する指定は入力盤の側に付ける。

> [!WARNING]
> メモのカードがキーボードの変換の候補の帯にかぶらないことは、実機で未検証である。

## 入力盤

**決定：下半分は開け閉めしない入力盤にし、押した行やカテゴリの印に合わせて中身だけを替える。**

| 項目 | 内容 |
| --- | --- |
| 理由 | テンキーを開く・閉じる操作が要らない。開いた時に見える物が、今入れる項目の分だけになる |
| 理由 | カテゴリから選ぶと、押す回数を増やさずに金額へ進める |
| 却下 | 口座を選ぶと金額の中身へ進む。選び直すたびに戻る手間がかかる |
| 却下 | 開くと電卓を出す形、金額 → カテゴリ → 確かめるの段に分ける形、電卓を閉じて始めるだけの形 |

> [!IMPORTANT]
> - 入力盤の下に保存のボタンを置く。保存のボタンは [entry-save](entry-save.md) にある。
> - ホームの線がある端末では、入力盤を画面の下から 20 の所まで下げる。
> - 小さい端末で入りきらない中身は、入力盤の中で送る。テンキーは送らず、キーを低くして収める。
> - 後ろの項目へ移るなら右から、前の項目へ移るなら左から中身を入れ替える。
> - 項目の順番は、紙のカードの行と同じにする。金額がいちばん後になる。
> - 新しい記録も編集も、支出と収入はカテゴリ、振替は振替の中身で始める。
> - 種類を切り替えた時と「続けて記録」の後も、始めの中身に戻す。
> - カテゴリを選ぶと金額へ進む。支払い元と入金先は、選んでも中身を替えない。
> - 金額を決めていないテンプレートと、最近の記録を押したときは金額へ進む。
> - カードで請求を選べるときは、口座の中身に請求を並べる。
> - 振替で振替元か振替先の口座を選ぶと、振替の中身へ戻る。
> - 日付の中身は、入る端末では 6 段の月もカレンダーを全部出す。入らない小さい端末では送る。
> - 紙のカードと入力盤の高さは、中身や場面によらず同じにする。
> - 入力盤は、4 つの角を丸めた金の淡い線で囲み、面を背景よりわずかに沈めて内側の上に薄い影を落とす。
> - 濃い灰色や濃い金の面にはしない。ライトのテーマで、白いカードと背景から浮いて見える。
> - 金の枠で浮かせる紙のカードと、見た目を分ける。
> - 日付は選んでも中身を替えない。
> - 金額を入れた後は、カテゴリの中身のタグの下に「＋ 今の入力を保存」を点線で出す。
> - 「金額を入力」の見出しは振替でも出し、テンキーの位置を種類でそろえる。
> - 口座の「追加」は、口座を足すシートを開く。足した口座は、そのまま選ぶ。
> - 口座の「編集」を押すと、タイルの右上の角に鉛筆の丸い印を重ねる。タイルを押すと、その口座を直すシートを開く。
> - 鉛筆をタイルの右に並べない。名前と残高の幅が減り、字が縮む。「完了」で選ぶ形に戻る。
> - 口座の一覧を別のシートで開いてから編集に切り替える形にはしない。直すまでの手数が増える。

入力盤の中身は、次のとおり。

| 中身 | 見た目 |
| --- | --- |
| カテゴリ | 5 列 3 段のカテゴリ・タグ・2 行のテンプレートを並べる |
| 振替 | 縦に並べた振替元と振替先のカードと、よく使う組み合わせ。決まりは [entry-transfer](entry-transfer.md) にある |
| 金額 | 上の端に「金額を入力」と、品目を使う時は金のピル「品目に分ける」を置く。下にテンキーを置き、声を聞く間は声のカードに替える |
| 手数料 | 上の端に手数料の候補。下にテンキーを置く |
| 口座 | 口座を 2 列のタイルで並べ、右上に「追加」と「編集」を置く |
| 日付 | 上の端に「今日」・「昨日」・「おととい」。下に詰めたカレンダーを置く |

## テンキー

> [!IMPORTANT]
> - 金額を入れる欄は、入力シートのほかでも同じ電卓のテンキーを下から出す
> - 上の段に ⌫・税込 8%・税込 10%・÷、下の段に 00・0・000・＝ を置く
> - ⌫ を長押しすると、震わせて全部を消す
> - 引き出しで出すテンキーでは、見出しに `✓` を出さない
> - 引き出しのテンキーの ＝ は、計算の途中でなければ塗りのない閉じるキー（キーボードと下向きの矢印）にする
> - 入力シートの入力盤のテンキーは閉じないので、＝ は計算の途中でなくても ＝ のまま出す
