# 財布と純資産

> [!NOTE]
> 財布の持ち方、消し方、純資産、投資の評価額の決定が分かる。
> 言葉の対応は [glossary](../glossary.md) にある。

## 財布の種類

**決定：現金・銀行・カード・電子マネー・ポイント・その他・投資・借入。**

| 項目 | 内容 |
| --- | --- |
| 理由 | カードの引き落としを銀行からの振替で記録する。「財布」の中に財布と銀行が並ばない |
| 却下 | 銀行なし、まとめて「財布」と呼ぶ |

決まり：

- 借入は、まだ返していない額をマイナスで持つ。
- 資産はカード・借入以外の種類、負債はカードと借入とする。
- 記録・評価額・固定費（その口座を使うもの）がある口座は、資産と負債をまたいで種類を変えられない。保存を押す欄に「記録がある口座は、資産と負債をまたいで種類を変えられません」と出す。
- 評価額がある投資の口座は、投資から種類を変えられない。保存を押す欄に「評価額がある口座は、投資から種類を変えられません」と出す。
- 記録が無い口座は、自由に種類を変えられる。
- 隠した固定費も、口座を使う固定費に数える。
- 保存するときも、データベースで同じ決まりを確かめ、破るなら保存しない。
- 残高の計算で評価額を使うのは、種類が投資の口座だけにする。ほかの種類の口座は、評価額があっても最初の残高と記録から数える。
- 画面では、財布（`Wallet`）をまとめて「口座」と呼ぶ。
- 「財布」は、現金の口座の名前に使う。
- 入力で選ぶ欄は、支出では「支払い元」、収入では「入金先」、振替では「振替元」と「振替先」と呼ぶ。

## 財布の編集

**決定：口座は、設定と資産タブのカードから編集する。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 入力シートで選べる財布がなくならない。カテゴリと同じ操作で迷わない |
| 却下 | 最後の財布も非表示にできる、財布だけ絵柄を決め打ちにする |

決まり：

- 入力シートの支払い元・入金先を選ぶシートからも足せる。
- そのシートの右上の鉛筆を押すと編集の状態になり、強調の色になる。もう一度押すと選ぶ状態に戻る。
- 編集の状態では、各行の右に鉛筆の印を出し、行を押すとその口座の編集画面を開く。選択中の行や、振替でもう片方に選んだ口座の行も押せる。
- 編集の状態では、請求の欄を隠す。編集を閉じると、口座を読み直す。
- 新しく記録するときは、選んでいた口座が非表示や削除で消えたら、残りの先頭の口座に選び直す。支払い元と入金先は、同じ口座にしない。
- 既存の記録の編集では、口座を選び直さない。非表示の口座で付けた記録でも、その口座を選んだままシートに残す。
- 最初の残高は、記録を始める前のいまの残高で、カードは使った額をマイナスで入れる。
- 種類をカード・借入にすると、符号を自動でマイナスにする。
- 自分で符号を選んだ後は変えない。
- 設定の一覧では、カテゴリと同じく、長押しで動かして下の枠に置くと非表示にする。
- 行を横に払うと、非表示と削除のボタンを出す。
- 非表示の口座は一覧の下に並べ、長押しで浮かせ、画面の上の端に出る枠に置くと表示に戻す。
- 表示中の口座が 1 つだけのときは、非表示にできない。
- 残高が 0 でない口座を非表示にするときは、合計から外れることを確かめる。
- アイコンの編集は、カテゴリと同じ部品を使う。

## 口座・カテゴリ・スタンプを消す

口座・カテゴリ・スタンプを消す操作は、「…」のメニューと削除を決める。

### 「…」のメニュー

**決定：編集の右上に「…」の丸いボタンを置き、「非表示にする」と「削除」のメニューを出す。**

決まり：

- 口座・カテゴリ・テンプレート（`EntryTemplate`）・固定費（`Recurring`）の編集に置く。
- スタンプ・ごほうびの編集にも置く。
- 「削除」は薔薇色にする。
- 非表示の間は、メニューを「表示に戻す」にし、ボタンを強調する。
- 口座の一覧では、行を横に払うと 2 つのボタンを出し、最後まで払うと非表示にする。

### 削除

**決定：記録がある口座とカテゴリは消せず、「記録があるので削除できません。非表示にできます」と出す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 間違えて作ったものを消せる。残高や振り返りの記録は壊れない |
| 却下 | 消さずに非表示だけにする、記録ごと消す、記録を別の口座へ移す |

決まり：

- 記録が無ければ、その口座やカテゴリを使う固定費・テンプレート・評価額・予算・タグも一緒に消す。
- スタンプは消しても、カレンダーに押したものは残る。
- 消す前に確かめる。
- 消した直後は、非表示と同じく「取り消す」の知らせを 4 秒出し、押すと一緒に消したものもすべて戻す。
- 資産のタブや入力シートから消したときも、その画面に同じ知らせを出す。
- 非表示の一覧を開いているときは、見出しの右に「まとめて削除」を出す。
- 確かめてから、非表示のものを順に消し、記録があるものは残して残した数を知らせる。
- まとめて消したものも、「取り消す」で一度に戻す。

## 振替元の残高を超える金額

**決定：振替で、金額が振替元の残高を超えたら、振替元のカードの残高と、ダイヤルの振替後の残高を薔薇色にする。**

| 項目 | 内容 |
| --- | --- |
| 理由 | カードや記録の漏れで、残高を超える振替は実際に起こる |
| 却下 | 保存を止める、何も出さない |

決まり：

- カードの高さは変えない。
- 金額が未入力のうちは出さない。
- 保存は止めない。

## 手元のお金と純資産

**決定：資産タブの合計は「手元のお金」と呼ぶ。**

| 項目 | 内容 |
| --- | --- |
| 理由 | カードのマイナスが資産のマイナスに見えない。ホームの「あといくら」とも、家や投資まで含む純資産とも混ざらない |
| 却下 | 「残高の合計」のまま、カードもマイナスで並べる、合計を「純資産」と呼ぶ |

決まり：

- 手持ち（現金・銀行・電子マネー・ポイント・その他）に、カードの残高を足して出す。
- 下に「手持ち ¥489,700・未払い ¥52,000」と内訳を出す。
- カードがプラスなら、未払いの代わりに「返ってくる額」と出す。
- 投資か借入の口座があるときだけ、「純資産」を並べて出す。
- 純資産は、手元のお金に投資と借入の残高を足した額にする。
- カードか借入の口座があれば、純資産の下に、資産と負債の割合を 2 色の棒で出し、両端に額を添える。
- 動きのグラフは手元のお金で描く。
- 純資産を出すときは、純資産の線を点線で重ね、下に線の見本を添える。
- 月ごとの点は、その月の最終日の時点の額にする。
- しまった財布は入れない。
- 口座の欄は、「資産」（手持ち・投資）と「負債」（カードの未払い・借入）に分け、どちらも同じ形にする。
- 見出しには、丸いアイコン・名前・口座の数を並べ、その下に合計を大きく出す。
- 口座は 1 枚のカードに行で並べ、手持ち・投資・カードの未払い・借入の小見出しと小計で区切る。
- 行には、振り返りと同じ色のアイコンと名前・額を出す。
- 負債の額は「−¥52,000」とマイナスで出す。
- カードは「未払い」として「11/27 に引き落とし・あと 32 日」と添え、プラスなら「返ってくる額」と出す。
- 借入は「残り」とし、最初に借りた額があれば、返した割合を細い棒と「24%」で出す。
- 無ければ棒を出さない。
- 借入の欄には、「あと 4 回・2027/1 まで」と返し終える見込みを添える。
- 見込みは、借入へ振り替える固定費を明日から順に引いて決める。
- 利息は入れない。
- 返済が無ければ「返済は未設定」、残りが 0 以下なら「返し終わりました」と出す。
- 100 年たっても返し終わらなければ「返し終わる時期は未定」と出す。
- 借入の口座の編集にも「毎月の返済」の行を置き、その固定費の編集を開く。
- まだ無ければ、銀行からの振替を「（名前）の返済」として、27 日払いで作り始める。
- 額は自分で入れる。
- 借入の口座を新しく足したときは、「毎月の返済も決めますか」と聞く。
- 借入の口座の編集には、「毎月の返済」の下に「最初に借りた額」の行も置き、投資の「今の評価額」と同じテンキーで入れる。
- 0 円は未入力とする。
- 額があれば、行の額の下に「¥72,000 返済済み（24%）」と添える。
- 最初の残高は記録を始めた時点の残りで、最初に借りた額は返した割合のためだけに使う。

## 投資の評価額

**決定：投資の口座の編集に「今の評価額」の行を置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 値動きが振り返りの収入や支出に混ざらない。過去の月の純資産も、その時点の額のまま残る |
| 却下 | 差額を収入か支出として記録する、最初の残高を書き換える、最新の評価額だけを口座に持つ |

決まり：

- 入れた額は、その日の評価額として [valuation](../data.md#valuation) に置き、残高をその額に合わせる。
- 値動きの分は、収入や支出の記録を作らない。
- 前の評価額は消さないので、動きのグラフの過去の点は変わらない。
- 評価額を入れた日と同じ日の記録は、評価額より後に作ったものだけを、評価額に足し引きする。
- 入れた評価額は、編集の画面の「これまでの評価額」に新しい順に並べ、横に払うと消す。
- 消すと、前の評価額から数え直す。
- 入力シートの振替では、口座の下に「チャージ・カードの引き落とし・口座どうしの移動」と例を出す。
- 口座のカードには、見出しを左、額を右にそろえた 2 行を出す。
- 1 行目は今の額で、借入なら「今の残り」、投資なら「今の評価額」、ほかは「残高」と呼ぶ。
- 額を入れると、2 行目に振替の後の額を、振替先が借入なら「返済後」、投資なら「積立後」、ほかは「振替後」として出す。
- 振替先が借入なら、下に「残り ¥100,000 をまとめて返す」のボタンを出し、押すと残りの額を入れる。
