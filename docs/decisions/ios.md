# iOS の構成

> [!NOTE]
> iOS のパッケージ、DB、画面の作り、Pro・通知・ウィジェットなどの決定が分かる。
> 言葉の対応は [glossary](../glossary.md) にある。

## パッケージ

**決定：KakeibotKit（iOS・macOS）と KakeibotApp（iOS 専用）の 2 つ。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 1 つにすると、iOS 専用のターゲットのせいで Core の `swift test` が失敗する。`--filter` で絞っても全ターゲットがビルドされる（Swift 6.4 で確認済み） |
| 却下 | 1 つのパッケージにターゲットを分けて入れる |

## 入口のターゲットの名前

**決定：アプリの入口は `AppFeature`、ウィジェットの入口は `AppWidget` にする。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 名前の順で 2 つが隣に並ぶ。WidgetKit の `Widget` と名前がぶつからない |
| 却下 | `WidgetFeature`、`Widget` |

## 画面の作り

**決定：SwiftUI ＋ `@Observable`、処理のある画面だけモデル。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 計算は Core にあり、テストもされる |
| 却下 | TCA、全画面に ViewModel |

## Features

1 つのターゲット。画面は `Screens/`、複数の画面で使う部品は `Shared/` に分ける。

| 理由 | 選ばなかった案 |
| --- | --- |
| 1 人では、ターゲットを分ける管理の手間が勝つ | 機能ごとにターゲットを分ける |
| フォルダの名前で、画面か部品かを見分けられる | 画面と同じ高さに Common や Parts を置く |

## 部品の置き場所

**決定：画面をまたいで使う表示だけの部品は DesignSystem に置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | DesignSystem は Core と Store を知らない。設定だけの部品を公開の部品に混ぜない |
| 却下 | すべての部品を DesignSystem に置く |

決まり：

- データや Core の型を使う部品と、設定の画面だけで使う部品は Features の `Shared/` に置く。

## カテゴリの型の名前

**決定：`EntryCategory`。**

| 項目 | 内容 |
| --- | --- |
| 理由 | Foundation を読み込むと、Objective-C の `Category` と名前がぶつかり、毎回 `Core.Category` と書くことになる |
| 却下 | `Category`、`SpendingCategory` |

決まり：

- 表の名前と書き出しのキーは `category` のまま。

## 依存を渡す方法

**決定：モデルを作るときに引数で渡す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | `@State` でモデルを作る時点で Environment を読めない |
| 却下 | Environment、部品をまとめた型 |

決まり：

- Environment で渡すのはテーマだけ。

## DB

**決定：GRDB の DatabasePool を App Group に置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | SQL で集計と移行を書ける。ウィジェットからも読める |
| 却下 | SwiftData、SQLDelight |

## DB の変更を画面に届ける

**決定：`ValueObservation`。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 依存を増やさない |
| 却下 | GRDBQuery、SQLiteData |

## 書き出しの形式

**決定：Core に置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | DB なしで往復を試せる。Android に移せる |
| 却下 | Store に置く |

## バックアップ

**決定：設定の「データとアプリ」の「バックアップ」から、全データを JSON のファイルに書き出す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 無料で、サーバーを使わずに、機種変更でも自分でデータを戻せる |
| 却下 | iCloud の同期だけに任せる、今のデータに足して読み込む |
| 関連 | 形式の決まりは [export-format](../../spec/export-format.md) にある |

決まり：

- ファイルの名前は `kakeibot-年-月-日.json` にし、保存先は使う人がファイルの画面で選ぶ。
- 読み込むときは、書き出した日と記録・口座の数を出して確かめてから、全部置き換える。
- 同じ画面から、記録を表計算用の CSV（`kakeibot-年-月-日.csv`）にも書き出せる。
- CSV は読み込みには使わない。

## Pro の中身と売り方

**決定：Pro は、サブスクと買い切りの両方で売る。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 家族との共有と機種をまたぐ同期は、お金を払う理由になりやすい。サブスクを嫌う人も買える |
| 却下 | 同期と共有を無料にする、サブスクだけ、買い切りだけ、リリースの後に足す |
| 関連 | 同期と共有の形は [overview](../overview.md) にある |

決まり：

- 端末間の同期と家族との共有を Pro に含め、どちらも最初のリリースから出す。
- 毎日の入力、予算、振り返り、バックアップは無料のまま使える。

## ライセンスの表示

**決定：ライセンスは、iPhone の設定アプリの「アプリ」→「かけいぼっと」に出す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 読む人の少ない画面をアプリに持たずに、ライセンスの文を同梱できる |
| 却下 | アプリの中に一覧を置く、ライセンスを手で書いて並べる |

決まり：

- 使っている部品と同梱のフォントを並べ、本文と配布元を出す。
- 一覧は LicensePlist で作り、`Settings.bundle` に入れる。
- 部品は Package.resolved から集める。
- フォントは配布元と一緒に `license_plist.yml` に書き足す。
- 部品やフォントを足したら作り直す。
- 設定の「データとアプリ」には、バージョンを `1.0.0` の形で出す。
- ビルド番号は出さない。

## 通知

**決定：予約されているべき通知は Core で計算し、Notifications は差だけを OS に反映する。**

| 項目 | 内容 |
| --- | --- |
| 理由 | fixtures で試せる |
| 却下 | Notifications が DB を読む |

決まり：

- 記録忘れの通知は、設定の「使い方」から入れると、今日から 7 日分を予約する。
- 最初の時刻は 21:00 にする。
- 時刻は 19〜23 時の候補か、ホイールで選ぶ。
- 文言は曜日ごとに 7 通りにする。
- 画面には、曜日を選んで見られる届く通知の見本と、許可がないときの設定アプリへの案内を出す。
- 開いたときは、今の時刻と許可の状態で出し、動かさない。
- 次に届く固定費の通知も 3 件まで並べる。
- 記録も支出なしの印もある日の分は外す。
- 固定費の通知は、前に知らせる日を決めた固定費だけ、31 日先までの分を予約する。
- 時刻は記録忘れの時刻、決めていなければ 9 時にする。
- 通知の許可は、記録忘れの通知を入れたときか、予約する通知が初めてできたときに求める。
- 記録・印・固定費・時刻が変わるたびと、起動・前面に戻る・日付が変わるときに予約し直す。
- 通知を押すと、記録忘れはその日の入力シートを、固定費はその固定費の編集を開く。
- 開いているシートは閉じてから開く。

## ウィジェット

**決定：ウィジェットは、あといくら（小・中）、すぐ記録（中・大）、ロック画面、コントロールの「記録する」にする。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 毎日目に入ると記録が続き、Pro を買う人も増える。開かずに記録でき、入力の面倒を減らせる |
| 却下 | 一部を Pro にする、入力シートを開いてから記録する、ロック中も金額を出す、金額を決めていないテンプレートを出さない |

決まり：

- ロック画面は、丸・横長・1 行の形を作る。
- どれも無料にする。
- あとで足す発展形のウィジェット（カレンダー、これからの引き落としなど）は、Pro の候補にする。
- すぐ記録は、支出のテンプレートを、ホームと同じ並びで中に 4 つ、大に 6 つ出す。
- 金額を決めたものは押すとその場で記録し、1 分のあいだ「取り消す」を出す。
- 金額を決めていないものは、押すとアプリの起動画面が消えてから、そのテンプレートで入力シートを開く。
- 大には、テンプレートのカテゴリ・財布と、今日の記録を 2 つ添える。
- 金額は、ロックしている間は伏せる。
- 色と字体はアプリで選んだテーマに合わせ、文字の大きさは変えない。
- あといくらには今日の支出を出し、中には今週・今月の支出と次の固定費を添える。
- 押すとホームを開く。

## 入力の入口

**決定：どこからでも開けるシート。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 1 手で記録できる |
| 却下 | 入力用のタブ |

## タブ

ホーム・記録・振り返り・資産の 4 つ。帯は自分で描いて浮かせ、＋ を帯の右に離して置く。iOS 26 以降は Liquid Glass にする。設定はホームの右上の歯車から開く。

| 理由 | 選ばなかった案 |
| --- | --- |
| 中に財布が並ぶタブを「財布」と呼ぶと紛らわしい | カレンダーと財布のタブ、設定のタブ |
| OS のタブでは、＋ を帯の右に離して置けない | OS のタブ、OS のタブに ＋ を重ねる |
