# iOS の構成

> [!NOTE]
> iOS アプリをどう組み立てるかの決定と、その理由が分かる。
> 保存は [storage](storage.md)、Pro は [pro](pro.md)、通知とウィジェットは [notifications](notifications.md) にある。

## パッケージ

**決定：KakeibotKit（iOS・macOS）と KakeibotApp（iOS 専用）の 2 つ。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 1 つにすると、iOS 専用のターゲットのせいで Core の `swift test` が失敗する。`--filter` で絞っても全ターゲットがビルドされる（Swift 6.4 で確認済み） |
| 却下 | 1 つのパッケージにターゲットを分けて入れる |

## 入口のターゲットの名前

**決定：アプリの入口は `AppFeature`、ウィジェットの入口は `AppWidget` にする。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 名前の順で 2 つが隣に並ぶ。WidgetKit の `Widget` と名前がぶつからない |
| 却下 | `WidgetFeature`、`Widget` |

## 画面の作り

**決定：SwiftUI ＋ `@Observable`、処理のある画面だけモデル。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 計算は Core にあり、テストもされる |
| 却下 | TCA、全画面に ViewModel |

## Features

Features は、ターゲットとフォルダを決める。

### ターゲット

**決定：Features は 1 つのターゲットにする。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 1 人では、ターゲットを分ける管理の手間が勝つ |
| 却下 | 機能ごとにターゲットを分ける |

### フォルダ

**決定：画面は `Screens/`、複数の画面で使う部品は `Shared/` に分ける。**

| 項目 | 内容 |
| --- | --- |
| 理由 | フォルダの名前で、画面か部品かを見分けられる |
| 却下 | 画面と同じ高さに Common や Parts を置く |

## 部品の置き場所

**決定：画面をまたいで使う表示だけの部品は DesignSystem に置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | DesignSystem は Core の型を使うが、Store は知らない。設定だけの部品を公開の部品に混ぜない |
| 却下 | すべての部品を DesignSystem に置く |

> [!IMPORTANT]
> データや Core の型を使う部品と、設定の画面だけで使う部品は Features の `Shared/` に置く。

## カテゴリの型の名前

**決定：`EntryCategory`。**

| 項目 | 内容 |
| --- | --- |
| 理由 | Foundation を読み込むと、Objective-C の `Category` と名前がぶつかる。毎回 `Core.Category` と書くことになる |
| 却下 | `Category`、`SpendingCategory` |

> [!IMPORTANT]
> 表の名前と書き出しのキーは `category` のまま。

## 依存を渡す方法

**決定：モデルを作るときに引数で渡す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | `@State` でモデルを作る時点で Environment を読めない |
| 却下 | Environment、部品をまとめた型 |

> [!IMPORTANT]
> Environment で渡すのは、テーマ・文字の倍率・設定の見出しの状態と、外の仕組みの窓口だけにする。窓口は、iCloud の `SyncCloud` と通知の許可の `NotificationPermission` である。ビューがモデルを作るときに、引数で渡す。

## ライセンスの表示

**決定：ライセンスは、iPhone の設定アプリの「アプリ」→「かけいぼっと」に出す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 読む人の少ない画面をアプリに持たずに、ライセンスの文を同梱できる |
| 却下 | アプリの中に一覧を置く、ライセンスを手で書いて並べる |

> [!IMPORTANT]
> - 使っている部品と同梱のフォントを並べ、本文と配布元を出す。
> - 一覧は LicensePlist で作り、`Settings.bundle` に入れる。
> - 部品は Package.resolved から集める。
> - フォントは配布元と一緒に `license_plist.yml` に書き足す。
> - 部品やフォントを足したら作り直す。
> - 設定の一覧のいちばん下に、バージョンを「かけいぼっと 1.0.0」の形で小さく出す。
> - ビルド番号は出さない。

## 入力の入口

**決定：どこからでも開けるシート。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 1 手で記録できる |
| 却下 | 入力用のタブ |

## タブ

タブは、数と帯を決める。

### タブの数

**決定：タブは、ホーム・記録・振り返り・資産の 4 つにする。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 中に財布が並ぶタブを「財布」と呼ぶと紛らわしい |
| 却下 | カレンダーと財布のタブ、設定のタブ |

> [!IMPORTANT]
> 設定はホームの右上の歯車から開き、その左のベルからお知らせを開く。

### 帯

**決定：帯は自分で描いて浮かせ、＋ を帯の右に離して置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | OS のタブでは、＋ を帯の右に離して置けない |
| 却下 | OS のタブ、OS のタブに ＋ を重ねる |

> [!IMPORTANT]
> iOS 26 以降は Liquid Glass にする。
