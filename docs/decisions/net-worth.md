# 純資産

> [!NOTE]
> 手元のお金と純資産の決定が分かる。財布は [wallets](wallets.md) にある。
> 投資の評価額は [wallets-valuation](wallets-valuation.md) にある。
> 言葉の対応は [glossary](../glossary.md) にある。

## 手元のお金と純資産

**決定：資産タブの合計は「手元のお金」と呼ぶ。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | カードのマイナスが資産のマイナスに見えない。ホームの「あといくら」とも、家や投資まで含む純資産とも混ざらない |
| ❌ 却下 | ~~「残高の合計」のまま~~ カードもマイナスで並び、使える額に見えない |
| ❌ 却下 | ~~合計を「純資産」と呼ぶ~~ 家や投資まで含む額と混ざる |

$$\text{手元のお金} = \text{手持ち} + \text{カードの残高}$$

$$\text{純資産} = \text{手元のお金} + \text{投資の残高} + \text{借入の残高}$$

> [!IMPORTANT]
> - 純資産は、投資か借入の口座がある時だけ出す。
> - しまった財布は入れない。

### 手元のお金

- 手持ちは、現金・銀行・電子マネー・ポイント・その他の口座である。
- 下に「手持ち ¥489,700・未払い ¥52,000」と内訳を出す。
- カードがプラスなら、未払いの代わりに「返ってくる額」と出す。

### 純資産と推移

- 純資産には「投資と借入を含む」と添える。
- カードか借入の口座があれば、純資産の下に、資産と負債の割合を 2 色の棒で出し、両端に額を添える。
- 純資産の行と動きのグラフは別のカードに出し、手元のお金のカードの次に置く。見出しは「純資産と推移」とし、純資産を出さない時は「推移」とする。
- 動きのグラフは手元のお金で描く。純資産を出す時は、純資産の線を落ち着いた色の実線で重ね、下に線の見本を添える。
- 月ごとの点は、その月の最終日の時点で数えた額にする。

### 資産と負債の欄

口座の欄は、「資産」（手持ち・投資）と「負債」（カードの未払い・借入）に分け、どちらも同じ形にする。見出しは「手元のお金」と同じくカードの中に置き、名前と口座の数を並べ、その下に合計を大きく出す。

| 状態 | 見た目 | 操作 |
| --- | --- | --- |
| 口座がある | 同じカードに行で並べ、手持ち・投資・カードの未払い・借入の小見出しと小計で区切る | 最後の行の「＋ 新しい口座を追加」で、口座の編集シートを開く |
| 組の口座が 1 つだけ | 小計を出さない | |
| 口座が無い | 資産と負債のカードを出し、「口座を追加すると、ここに並びます」と添える | |
| 手持ちの口座がマイナス | 行の下に淡い薔薇色の札を出し、「手持ちがマイナスです」とずれの説明を添える | 金のカプセルの「残高を合わせる」で、今の残高を入れるシートを開く |

- 小計は、資産も負債も同じ小さい字で右上に出す。
- 「＋ 新しい口座を追加」の行の下には、資産は「現金・銀行・投資など」、負債は「カード・借入」と添える。資産からは現金、負債からはカードを選んで開く。
- 「残高を合わせる」は右に置き、入らなければ下に幅いっぱいで置く。
- 残高を入れるシートは、差を今日の[残高の調整](records.md#残高の調整)として入れる。伝票の形で、残高・手元の額・調整を点線で並べる。スワイプでは確かめずに閉じる。
- 行には、振り返りと同じ色のアイコンと名前・額を出す。名前は 1 行で省き、額は省かず縮める。
- 負債の額は「−¥52,000」とマイナスで出す。

### カードの未払いの予定表

カードは「未払い」として、名前と額の行の下に、[これからの引き落とし](cards.md#これからの引き落とし)の回ごとの小さな予定表を並べる。プラスなら「返ってくる額」と出す。

| 状態 | 見た目 |
| :---: | --- |
| 確定の回 | 塗った丸とアクセントの色の「確定」を出す |
| 見込みの回 | 縁だけの丸と「見込み · 11/30 締め」を出し、額を控えめな色にする |
| 0 円の回 | 出さない |
| 回が無い | 予定表を出さない |
| 回が 1 つで、その額が未払いの額と同じ | 予定表の額を出さない。同じ額が 2 度並ぶため |

- 予定表の行は、丸・`11/27払い`・状態・額を並べ、丸どうしを淡い縦の線でつなぐ。日付の幅はそろえる。
- 状態が収まらなければ「見込み」に縮め、それでも収まらなければ日付と額の下に回す。
- 行の › は、予定表を含めた行の高さの真ん中に置き、アイコンは上の段にそろえる。

### 未払いの記録の一覧

「カードの未払い」の区切りの最後に、全カードの件数で「未払いの記録を見る（N 件）」を 1 つだけ置く。

- 押すと、まだ引き落とされていない記録をカードごとの名前と額の見出しで分ける。その下を、予定表の回ごとの分とその後の分に分けて並べる。
- 回ごとの分は、予定表と同じ丸・「`11/27払い · 6 件`」・額の見出しで区切る。見込みの回は、見出しに「見込み」を添えて額を控えめな色にする。記録の無い回は出さない。
- 一覧の上には、題・合計の額・「楽天カード · 8 件」を縦に並べる。カードが 2 枚以上なら「カード 2 枚 · 13 件」とする。
- 回した記録の一覧も同じ形にし、「カード · 2 件 · 11/26（木）に引き落とし」とする。

### 借入の残りと返し終える見込み

借入は「残り」とし、最初に借りた額があれば、返した割合を細い棒と「24% 返した」で出す。無ければ棒を出さない。

借入の欄には、棒の下に「あと 4 回・2027/1 まで」と返し終える見込みを、アクセントの淡い地の札で添える。見込みは、借入へ振り替える固定費を明日から順に引いて決める。利息は入れない。

| 状態 | 見た目 |
| --- | --- |
| 返済が無い | 「返済は未設定」 |
| 残りが 0 以下 | 「返し終わりました」 |
| 100 年たっても返し終わらない | 「返し終わる時期は未定」 |

利息のある借入は、利息を含めて返す総額を残りとして持つ。利率は持たない。返し始める前の利息で計算と返還表が合わないため、返還表や残高を正とする。

### 毎月の返済の回数

借入へ振り替える固定費は、毎回の額だけ入れればよい。端数は最後の回に足す。

$$\text{回数} = \left\lfloor \frac{\text{残高}}{\text{額}} \right\rfloor$$

回数を手で入れると、最後の回は次の額にする。額の 2 倍以上か 0 以下になる時は、毎回と同じ額にする。

$$\text{最後の回} = \text{残高} - \text{額} \times (\text{回数} - 1)$$

下のカードに返す総額・終わりの月・最後の回を出す。残高とずれた時はずれを出し、「合わせる」で自動に戻す。

### 借入の口座の編集

- 借入の口座の編集にも「毎月の返済」の行を置き、その固定費の編集を開く。
- まだ無ければ、銀行からの振替を「（名前）の返済」として、27 日払いで作り始める。額は自分で入れる。
- 借入の口座を新しく足した時は、「毎月の返済も決めますか」と聞く。
- 「毎月の返済」の下に「最初に借りた額」の行も置き、投資の「今の評価額」と同じテンキーで入れる。0 円は未入力とする。
- 額があれば、行の額の下に「¥72,000 返済済み（24%）」と添える。新しく足す時は、最初の残高を入れるまで添えない。
- 最初の残高は記録を始めた時点の残りで、最初に借りた額は返した割合のためだけに使う。

## 月末の見込み

**決定：手元のお金の下に「今月これから」として、今の期間の終わりまでの出入りと、「月末の見込み」の額を添える。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 今月お金が足りるのかと、これからどれだけ引かれるのかが見通せる。固定費のこれからの回も、記録を作らずに足せる |
| ❌ 却下 | ~~期限を切らずに予定をすべて足す~~ 固定費が先まで続き、切らないと足せない |
| 関連 | [今の残高](periods.md#今の残高) |

> [!IMPORTANT]
> - 手元のお金の額と、[今の残高](periods.md#今の残高)の決まりは変えない。
> - 足すのは、今の期間の終わりまでの、予定の記録と固定費のこれからの回にする。期間は、月の始まりの設定に合わせる。
> - これからの引き落としのカードには、固定費と予定を混ぜない。見込みと確定の表示が読みにくくなるためである。

### 足すもの

$$\text{月末の見込み} = \text{手元のお金} + \text{予定の記録の増減} + \text{固定費のこれからの回の増減}$$

- 予定の記録は、日付が明日以降の記録のうち、手持ちとカードの口座の残高を変えるものにする。しまった財布は入れない。
- 固定費のこれからの回は、まだ記録を作っていない回を、登録した額で足す。記録は作らない。
- 手持ちとカードの間の振替は、手元のお金の中の移動なので足さない。カードの引き落としもこれに当たる。投資・借入との振替は足し、振替の手数料も足す。

### 今月これから

まとまりは、アクセントの淡い地に細い線の縁を付ける。中には、カレンダーの印と「今月これから」・内訳の行・細い線・「月末の見込み」と額と › を並べる。

内訳の行は、「入る」に増える分を、「出る」に固定費と予定の記録を分けて出す。「入る」には、額のいちばん大きい名前と「ほか 1 件」を添える。

| 状態 | 見た目 |
| --- | --- |
| 足すものが無く、月末より先の予定の記録も無い | 出さない |
| 途中の残高が今と月末のどちらよりも少なくなる日がある | 「いちばん少ない日 11/17 ¥359,700」と添える |
| 途中でマイナスになる | 「11/27 に ¥12,000 足りなくなります」と薔薇色で添える |
| 月末の見込みがマイナス | 額も薔薇色にする |
| 添える日が無く、月末より先の予定の記録がある | 「月末より先の予定 1 件 −¥12,500」と添える |

### 今月これからの出入りのシート

押すと「今月これからの出入り」のシートを開き、日付の順に行を並べる。

- 行には、日付・名前・「あと N 日 · 口座」・増減・その日の「残り」を出す。
- 口座の名前は、入りきらない時に末尾から省く。固定費の回には、繰り返しの印を付ける。
- 行を押すと、予定の記録は記録の編集を、固定費の回は固定費の編集を開く。
- 増える額はアクセント、減る額は濃いアクセントの色で、符号を付けて出す。
- 一覧の下に「¥437,700 →」「月末の見込み ¥623,200」を並べる。
- その下に、「月末より先の予定」の記録を分けて並べる。
