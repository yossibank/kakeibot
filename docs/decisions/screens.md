# 操作

> [!NOTE]
> 編集、保存、記録の操作、検索、絞り込みの決定が分かる。
> 言葉の対応は [glossary](../glossary.md) にある。

## カテゴリの編集

**決定：一覧は、4 列のマスで並べ、長押しで並べ替える。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 入力シートでの並びがそのまま見え、選ぶものがすべて見える。長押しを知らなくても編集に行ける。並びが勝手に動くのを嫌う人は、並べた順のままにできる |
| 却下 | 行のリスト、ダイヤルの見本と下から出す引き出し、長押しだけで編集を開く、既定でよく使う順にする |

決まり：

- 枠に入ったか出たかは、広げる前の枠で決める。
- 一覧を自動で送る帯は、枠のすぐ上に置く。
- 非表示の一覧は、初めは開いておき、たたむと次も閉じたまま出す。
- 編集は、見本と名前を並べ、見本を押すと、色と絵柄を選ぶ引き出しを、見本の下から画面の下までの高さで開く。
- 開いている間は、見本を暗くせず、縁を金の太い線にする。
- アイコンの色は、振り返りのグラフの色に使う。
- 入力シートでは、選んだカテゴリのマスを少し大きくし、アイコンを一回り上げて薄く光らせる。
- カテゴリのマスの最後に「追加」を置き、同じ編集を開く。
- 保存したカテゴリを選んだ状態で戻る。
- 「追加」の次のマスには「編集」を置き、カテゴリの一覧をシートで開く。
- ページの点は、ページが 2 つ以上のときだけ出す。
- 選んだカテゴリにタグがあれば、タグの紐の ＋ の次に「編集」の札を下げ、そのカテゴリの編集を開く。
- マスを長押しすると、そのマスを浮かせて上に小さなカードを出す。
- カードから、そのカテゴリを編集するか非表示にする。

カテゴリの一覧は、次のように変わる。

| 状態 | 見た目 | 操作 |
| --- | --- | --- |
| 動かしている間 | 画面の下の端に枠が出る。動かしているマスは、枠より手前に描く | 枠に置くと、非表示にする |
| 指が枠に入って少し待つ | 枠を弾ませて広げ、文字を上に寄せて、小さくしたマスを枠の中に収める | |
| 非表示のカテゴリ | 一覧の下に並べる | 押すと編集を開き、長押しで浮かせ、画面の上の端に出る枠に置くと表示に戻す |

## 入力の途中で閉じる

**決定：入力したシートは、下へのスワイプでは閉じない。**

| 項目 | 内容 |
| --- | --- |
| 理由 | うっかり閉じて、入力をやり直さずに済む |
| 却下 | 何もしない、入力を下書きに残す |

決まり：

- スワイプや閉じるボタンで閉じようとしたら、保存せずに閉じるかを確かめる。

## 設定の中で開く編集

**決定：設定の一覧から開く口座・カテゴリ・スタンプ・テンプレート・固定費の編集は、シートを重ねず画面送りで開く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | シートが何枚も重ならず、今どこにいるかが分かる |
| 却下 | 編集をいつもシートで開く |

決まり：

- 左上は「＜」にする。
- 入力したら、戻るスワイプでも保存せずに閉じるかを確かめる。
- ホーム・資産・入力シートから開くときは、シートのまま開く。

## 保存のボタン

**決定：入力シートも、テンプレート・口座・カテゴリの編集も、下の大きなボタンで保存する。**

| 項目 | 内容 |
| --- | --- |
| 理由 | どのシートも同じ場所で保存でき、片手で届く。押せない理由がボタンで分かる |
| 却下 | 編集のシートだけ右上で保存する、キーボードの間はボタンを隠す |

決まり：

- 足りないものがあれば押せなくし、ボタンに「名前を入れてください」のように出す。
- 新しく作るときは「追加する」、直すときは「変更を保存」と出す。
- 入力シートで新しく記録するときは「食費 ¥1,280 を記録する」のようにカテゴリと金額を出す。
- 入りきらないときは、カテゴリの名前の末尾を切る。
- 下の行に「今日・財布から」のように日付と口座を添える。
- 収入は「銀行へ」にし、振替は下の行を出さない。
- テンキーを開いている間は、テンキーの下に同じボタンを出す。
- キーボードの間は、キーボードの上に出す。
- 入力シートの右上には、消す丸いボタンを置き、下に「削除」と小さく添える。

## 続けて記録する

**決定：新しく記録する入力シートでは、保存のボタンの右に「続ける」を置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | レシートを何枚も入れるときに、シートを開き直さずに済む |
| 却下 | 保存したらいつも開いたままにする、設定で切り替える、保存のボタンの下に文字のボタンを置く |

決まり：

- 押すと保存してシートを閉じず、シートの下に記録の知らせを出す。
- 知らせから取り消せる。
- 金額・メモ・タグを空にし、日付・種類・口座・カテゴリは残して、テンキーを出す。
- 直すときは「続ける」を出さない。

## 記録を変えた後の知らせ

**決定：記録を入れる・直す・消すと、タブの帯の上に知らせを出す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | どの操作も同じ決まりになる。保存した記録が今の画面に見えなくても、入ったと分かる。取り消せるので、消す前の確認が要らない |
| 却下 | テンプレートで 1 回で記録したときだけ出す、新しく入れたときだけ出す |

決まり：

- 知らせから取り消せる。
- 入力シートでも、ホームのテンプレートでも、振替でも同じにする。
- 知らせは 4 秒たつか、取り消す以外のどこかを押すと消える。
- 取り消したら「取り消しました」を 2 秒出す。
- 消す前には確かめない。

## 記録を消す操作

**決定：一覧の行は、横に払うとゴミ箱のボタンを出す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | iOS の標準のアプリと同じ動きと言葉で、迷わない |
| 却下 | ボタンに「消す」「削除」と書く、払い切っても削除しない |

決まり：

- 払い切ると、そのまま削除する。
- 知らせの言葉は「削除しました」にする。
- 記録は、カレンダーと一覧を切り替えて見る。
- 既定はカレンダーにする。
- 切り替えると、振り返りの区切りと同じく中身をすべらせる。
- 選んだほうを DB の設定に置き、次に開いたときも使う。
- カレンダーは、月の始まりで決まる期間の日を、週の始まりから並べる。
- マスには、その日の支出の合計と、その下に収入の合計を出す。
- 色と符号は、記録の行の金額と同じにする。
- 日は、休日でずらした後の日にする。
- 支出なしの印は、その日の記録の下のボタンで付け外しする。
- 付けられるのは、今日までで支出の無い日だけにする。
- 記録は、見出し・合計・カレンダーの上で左に払うと次の月、右に払うと前の月に送る。
- 記録の行の上では月を送らない。
- 合計と日ごとのカードは、払っている間は指について動き、離すとそのまま払った向きへすべる。
- 短く払ったときは元に戻す。
- 見出しの年月は、数字が上下にすべる。
- 行は左に払うと行のボタンを出す。

カレンダーの日は、次のように変わる。

| 状態 | 見た目 | 操作 |
| --- | --- | --- |
| 最初 | 今日を出す | |
| 支出なしの日 | 葉の印を出す | |
| 日を押した | カレンダーの下にその日の記録と「この日に入力」のボタンを出す | ボタンを押すと、その日付で入力シートを開く |
| 今日より先の日 | その日に来る固定費の印を薄く出す | 押すと、「予定の固定費」として名前と金額を並べ、行を押すとその固定費の編集を開く |

## 記録をまとめて直す

**決定：記録の一覧と検索の結果に「選択」を置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | カテゴリを分け直したときに、1 件ずつ開いて直さずに済む。検索で集めた記録を、そのまま直せる |
| 却下 | カレンダーの日の一覧でも選ぶ、行の長押しで選び始める |

決まり：

- カテゴリは、選んだ記録がすべて支出か、すべて収入のときだけ変えられる。
- 変えるとタグを外す。
- 口座は、振替が入っていないときだけ変えられる。
- 変えると、カードの請求を回した月を外す。
- 削除は確かめない。
- 月を送る、カレンダーに切り替える、検索を開く・閉じると、選ぶのをやめる。

選ぶ操作は、次のように進む。

| 状態 | 見た目 | 操作 |
| --- | --- | --- |
| 選ぶ前 | ボタンは絞り込み・検索と同じ丸にし、丸の下に名前を添える | 押すと行の左に丸を出し、押した行を選ぶ |
| 選ぶ間 | 丸を塗り、名前を「完了」にする。下に選んだ件数と「カテゴリ」「口座」「削除」の帯を出す | |
| 済んだ後 | 選ぶのをやめ、「2 件のカテゴリを変えました」のような知らせを出す | 知らせから、まとめて取り消せる |

## 記録の検索

**決定：カレンダーと一覧の切り替えの右に、絞り込みと虫めがねのボタンを置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 月を送らずに、あの支払いがいつだったかを見つけられる |
| 却下 | 今の月だけを探す、見出しの「記録」の横に虫めがねを置く |

決まり：

- 虫めがねから、すべての月の記録を探す。
- 空白で区切った言葉が、すべて当てはまる記録を日ごとに並べる。
- 言葉は、メモ・カテゴリ・タグ・口座の名前に含まれるか、金額と同じ数なら当てはまる。
- 金額には `¥` やカンマを付けてもよい。
- 大文字と小文字、全角と半角は区別しない。
- 結果の上に、件数・期間・支出と収入の合計を出す。
- 「閉じる」で月の一覧に戻る。
- 探した言葉は、確定したときと、結果がある状態で閉じたときに覚える。
- 新しい順に 5 つまで DB の設定に置き、言葉が空のときに並べる。
- 押すとその言葉で探す。

## 記録の絞り込み

**決定：記録の絞り込みのボタンから、シートを開いて選ぶ。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 食費と趣味だけ、カードの分だけ、昼ごはんだけ、のように見たいものだけを並べ、合計もそれに合わせて分かる。シートが長くならず、選ぶものを探しやすい |
| 却下 | 検索の結果だけを絞る、振り返りにも効かせる、支出・収入・口座を 1 つのシートに縦に並べる、絞り込みを DB に置いて次に開いたときも使う |

決まり：

- シートの上で支出・収入・口座・タグを切り替え、選んだほうのカテゴリ・口座・タグを並べる。
- タグは、カテゴリの名前の下に、入力シートと同じく紐に下げて並べる。
- 1 本に収まらなければ、紐を足して次の行に送る。
- カテゴリを選んでいるときは、そのカテゴリのタグだけを出す。
- 選んでいないカテゴリのタグは、選びから外す。
- 切り替えの文字には、選んでいる数を添える。
- 見出しの右に「すべて外す」を出す。
- カテゴリを選ぶと、そのカテゴリの記録だけを残し、カテゴリの無い振替は外す。
- 口座を選ぶと、その口座から出たか、その口座に入った記録だけを残す。
- タグを選ぶと、そのタグの記録だけを残す。
- いくつかを選んだら、すべてに当てはまる記録を残す。
- 絞り込みは、月の一覧・カレンダー・月の合計・検索の結果に効かせる。
- 振り返りには効かせない。
- 選んでいる間は、ボタンを塗り、下に選んだ名前と × を出す。
- 絞り込みはアプリを閉じるまで覚え、DB には置かない。

## 設定の一覧の説明

**決定：設定の一覧の上に、使い方の説明を短い文で 1 行ずつ、絵と並べてカードで出す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 最初は操作が分かり、覚えた後は一覧を広く使える |
| 却下 | いつも出す、長い 1 文で出す |

決まり：

- 行は折り返さない。
- 右の × で閉じると、その画面では出さず、見出しの右に「？」を出す。
- 「？」を押すと、またカードを出す。
- 閉じたことは DB の設定に置く。

## 非表示と表示に戻す枠

**決定：非表示にする枠は、浮かせている間だけ、下の「〜を追加」のボタンの場所に入れ替えて出す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 一覧が長くても、スクロールせずに枠まで動かせる。枠が一覧に重ならず、並べ替えのスクロールとぶつからない。間違えてもすぐ戻せる |
| 却下 | 一覧の最後に置く、一覧の下の端に重ねる、少し待ってから非表示にする |

決まり：

- ボタンが無い画面は、一覧の下に出す。
- 表示に戻す枠は、画面の上の端に重ねて出す。
- どちらも一覧の中には置かない。
- 非表示にする枠に入ると、枠が薔薇色になる。
- そこで離すと非表示にする。
- 並べ替えで浮かせたまま一覧の上の端か下の端に寄せると、一覧を少しずつスクロールする。
- 非表示にした直後は、「取り消す」の知らせを 4 秒出す。
- 非表示の項目は、見出しに数を出して開いておき、見出しを押すとたたむ。
- 開けたか閉じたかは、画面ごとに DB の設定に置く。
