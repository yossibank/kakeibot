# 操作

> [!NOTE]
> 編集、保存、設定の一覧、非表示の枠の決定が分かる。記録の操作は [records](records.md) にある。
> 言葉の対応は [glossary](../glossary.md) にある。

## カテゴリの編集

**決定：一覧は、4 列のマスで並べ、長押しで並べ替える。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 入力シートでの並びがそのまま見え、選ぶものがすべて見える。長押しを知らなくても編集に行ける |
| 理由 | 並びが勝手に動くのを嫌う人は、並べた順のままにできる |
| 却下 | 行のリスト、ダイヤルの見本と下から出す引き出し、長押しだけで編集を開く、既定でよく使う順にする |

> [!IMPORTANT]
> - 枠に入ったか出たかは、広げる前の枠で決める。
> - 一覧を自動で送る帯は、枠のすぐ上に置く。
> - 編集は、見本と名前を並べる。見本を押すと、色と絵柄を選ぶ引き出しを、見本の下から画面の下までの高さで開く。
> - 開いている間は、見本を暗くせず、縁を金の太い線にする。
> - アイコンの色は、振り返りのグラフの色に使う。
> - 入力シートでは、選んだカテゴリのマスを少し大きくし、アイコンを一回り上げて薄く光らせる。
> - カテゴリのマスの最後に「追加」を置き、同じ編集を開く。
> - 保存したカテゴリを選んだ状態で戻る。
> - 「追加」の次のマスには「編集」を置き、カテゴリの一覧をシートで開く。
> - ページの点は、ページが 2 つ以上のときだけ出す。
> - 選んだカテゴリにタグがあれば、タグの紐の ＋ の次に「編集」の札を下げ、そのカテゴリの編集を開く。
> - マスを長押しすると、そのマスを浮かせて上に小さなカードを出す。
> - カードから、そのカテゴリを編集するか非表示にする。

カテゴリの一覧は、次のように変わる。

| 状態 | 見た目 | 操作 |
| --- | --- | --- |
| 動かしている間 | 画面の下の端に枠が出る。動かしているマスは、枠より手前に描く | 枠に置くと、非表示にする |
| 指が枠に入って少し待つ | 枠を弾ませて広げ、文字を上に寄せて、小さくしたマスを枠の中に収める | |
| 非表示のカテゴリ | 一覧の下に並べる | 押すと編集を開き、長押しで浮かせ、画面の上の端に出る枠に置くと表示に戻す |

## 入力の途中で閉じる

**決定：入力したシートは、下へのスワイプでは閉じない。**

| 項目 | 内容 |
| --- | --- |
| 理由 | うっかり閉じて、入力をやり直さずに済む |
| 却下 | 何もしない、入力を下書きに残す |

> [!IMPORTANT]
> - スワイプや閉じるボタンで閉じようとしたら、保存せずに閉じるかを確かめる。
> - 予算のようにその場で保存するテンキーの引き出しも、額を変えたまま幕・スワイプ・戻るスワイプで閉じようとしたら確かめる。捨てると引き出しだけを閉じる。
> - 変更したまま「非表示」を押したら、保存して非表示にするか、捨てて非表示にするか、戻るかを選ばせる。保存できない下書きでは、保存して非表示にする選択を出さない。

## 設定の中で開く編集

**決定：設定の一覧から開く編集は、シートを重ねず画面送りで開く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | シートが何枚も重ならず、今どこにいるかが分かる |
| 却下 | 編集をいつもシートで開く |

> [!IMPORTANT]
> - 口座・カテゴリ・スタンプ・テンプレート・固定費・ごほうび・テーマの編集に当てはめる。
> - 左上は「＜」にする。
> - 入力したら、戻るスワイプでも保存せずに閉じるかを確かめる。
> - ホーム・資産・入力シートから開くときは、シートのまま開く。
> - 編集の上の見本は、一覧に並ぶカードやマスと同じ部品で描く。

## 保存のボタン

**決定：入力シートも編集も、下の大きなボタンで保存する。**

| 項目 | 内容 |
| --- | --- |
| 理由 | どのシートも同じ場所で保存でき、片手で届く。押せない理由がボタンで分かる |
| 却下 | 編集のシートだけ右上で保存する、キーボードの間はボタンを隠す |

> [!IMPORTANT]
> - 編集は、口座・カテゴリ・スタンプ・テンプレート・固定費・ごほうび・テーマ・目標に当てはめる。
> - 足りないものがあれば押せなくし、ボタンに「名前を入れてください」のように出す。
> - 新しく作るときは「追加する」、直すときは「変更を保存」と出す。
> - 入力シートで新しく記録するときは「食費 ¥1,280 を記録する」のようにカテゴリと金額を出す。
> - 入りきらないときは、カテゴリの名前の末尾を切る。
> - 下の行に「今日・財布から」のように日付と口座（`Wallet`）を添える。
> - 収入は「銀行へ」にする。振替は、手数料があるときだけ「手数料 ¥110 も記録」と出す。
> - テンキーを開いている間は、テンキーの下に同じボタンを出す。
> - その場で保存する口座の評価額と予算は、テンキーの下にそれぞれの保存のボタンを出す。予算のボタンの言葉は [budget の「予算の履歴」](budget.md#予算の履歴) にある。
> - キーボードの間は、キーボードの上に出す。
> - 入力シートは 1 画面に収めるため、メモを入れている間は、キーボードの上にメモのカードだけを出す。保存は、カードを `✓` で閉じてから押す。
> - テンプレートのメモとカテゴリのタグも、入力シートのメモと同じく、キーボードのすぐ上にカードで出す。
> - 入力シートの右上には、消す丸いボタンを置き、下に「削除」と小さく添える。

## 設定の画面の説明

**決定：設定の画面の上に、アイコンと 2 行の見出し、1 行ずつの補足を並べた説明のカードを出す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 何の画面かと操作が最初に分かり、iCloud 同期・バックアップと同じ形で、どの画面も同じ所を読めば分かる |
| 却下 | 画面ごとに説明の形を変える、一覧で操作だけを並べる、長い 1 文で出す |

> [!IMPORTANT]
> - 見出しと補足の行は、折り返さない。
> - 並べ替えや非表示の操作は、補足の行に入れる。
> - 一覧の画面のカードは、右上の × で閉じられる。閉じると、その画面では出さず、見出しの右に「？」を出す。
> - 「？」を押すと、またカードを出す。閉じたことは DB の設定に置く。
> - 閉じられない画面（同期・バックアップ・アプリアイコン・月の始まり・起動時に開く画面・記録忘れの通知）は、いつも出す。
> - 一覧の画面ではカードをスクロールの外に置き、並べ替えの座標に入れない。

## 設定の一覧の追加と空の表示

**決定：追加の場所と、空のときの表示を、一覧の形ごとに 1 つにそろえる。**

| 項目 | 内容 |
| --- | --- |
| 理由 | どの一覧でも同じ場所を押せば足せ、空でも何を足す画面かが分かる |
| 却下 | 一覧ごとに追加の形を変える、空のときに何も出さない |

> [!IMPORTANT]
> - 縦に並ぶ一覧（口座・テンプレート・固定費）は、下の追加のボタンで足す。
> - マスの一覧（カテゴリ・スタンプ・ごほうび）は、並びの最後の点線の「追加」のマスで足す。
> - 出している物が無いときは、一覧の上にアイコンと 1 行の説明を出す。

## 非表示と表示に戻す枠

**決定：非表示にする枠は、浮かせている間だけ、下の「〜を追加」のボタンの場所に入れ替えて出す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 一覧が長くても、スクロールせずに枠まで動かせる。枠が一覧に重ならず、並べ替えのスクロールとぶつからない |
| 理由 | 間違えてもすぐ戻せる |
| 却下 | 一覧の最後に置く、一覧の下の端に重ねる、少し待ってから非表示にする |

> [!IMPORTANT]
> - ボタンが無い画面は、一覧の下に出す。
> - 表示に戻す枠は、画面の上の端に重ねて出す。
> - どちらも一覧の中には置かない。
> - 非表示にする枠に入ると、枠が薔薇色になる。
> - そこで離すと非表示にする。
> - 並べ替えで浮かせたまま一覧の上の端か下の端に寄せると、一覧を少しずつスクロールする。
> - 枠に置いても編集の「…」から非表示にしても、直後に「取り消す」の知らせを 4 秒出す。
> - 非表示の項目は、見出しに数を出して開いておき、見出しを押すとたたむ。
> - 開けたか閉じたかは、画面ごとに DB の設定に置く。
