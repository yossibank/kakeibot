# 作り方

リポジトリ全体と、作業の道具の決定を書く。

## 共通化

Swift で先に作り、fixtures で Kotlin 版とそろえる。

| 理由 | 選ばなかった案 |
| --- | --- |
| Swift が得意で iPhone を毎日使う。iOS をストアに出してから、13 番で Android に取りかかる。AI の段階は Swift 専用 | Kotlin Multiplatform、Compose Multiplatform、Flutter、Swift SDK for Android |

## リポジトリ

1 つにまとめる。

| 理由 | 選ばなかった案 |
| --- | --- |
| fixtures と書き出しの形式を両 OS で共有する | OS ごとに分ける |

## 対応端末

iPhone のみ。

| 理由 | 選ばなかった案 |
| --- | --- |
| iPad 向けの画面の配置とスクリーンショットが要らない。あとから足せる | iPhone と iPad |

## 署名

自動。

| 理由 | 選ばなかった案 |
| --- | --- |
| 1 人・端末 1 台・CI なしなので、端末の追加・更新・提出を Xcode に任せられる | 手動 |

## プロジェクトのファイル

`.xcodeproj` をそのまま管理する。

| 理由 | 選ばなかった案 |
| --- | --- |
| 1 人なので衝突しない。中身はほぼパッケージ側 | XcodeGen、Tuist |

## ワークスペース

プロジェクトと 2 つのパッケージを、`.xcworkspace` で並べる。

| 理由 | 選ばなかった案 |
| --- | --- |
| ナビゲーターでプロジェクトとパッケージが同じ高さに並び、見分けやすい | パッケージのフォルダをプロジェクトの中に入れる |

## 整形

SwiftFormat（Mint で版を固定）。commit の前に pre-commit が整形し、直したら commit を止める。ステージし直すのは人。

| 理由 | 選ばなかった案 |
| --- | --- |
| 自分で整形を走らせずに済む。一部だけステージしたファイルは、pre-commit が整形を取り消すので壊れない | hook は違反を止めるだけで直さない、hook がステージし直して commit まで通す、SwiftLint も入れる |

## 文書の確認

Claude Code のフック（claude-config の `hooks/post-edit-check-docs.py`）で、書き方の決まりを確かめる。

| 理由 | 選ばなかった案 |
| --- | --- |
| 文書を書くのはほぼ Claude なので、書いたその場で直せる。リポジトリごとの準備が要らない | pre-commit で確かめる、自動では確かめない |

## テストの走らせ方

CI は置かない。PR を作る前に、Claude が手元で `make test` を 1 回走らせ、結果を PR の本文に書く。push し直すときは、Swift か fixtures を変えたときだけ走らせ直す。文書だけの PR では走らせない。ビルドは別に走らせず、`make test` のビルドで兼ねる。ビルドとテストの出力は xcbeautify で整える。

| 理由 | 選ばなかった案 |
| --- | --- |
| リポジトリは非公開で、GitHub Actions を使わない。結果の変わらない変更で待たずに済む。同じビルドを 2 回しなくて済む。長いログから失敗を探さずに済む | GitHub Actions で走らせる、手元の Mac を GitHub Actions のランナーにする、push のたびに走らせる、`make test-build` も別に走らせる、xcodebuild の出力をそのまま出す、先にシミュレーターを起動する（起動の途中は `simctl list` と `xcodebuild` が待たされ、かえって遅い） |

## 画面の言語

文字は日本語で書き、iOS の開発言語を `ja` にする。ほかの言語は、出すときに訳を足す。

| 理由 | 選ばなかった案 |
| --- | --- |
| 日本語で使う人に向けたアプリで、日付選択などの OS の部品も日本語で出る | 英語で書いて日本語に訳す |

## 画面の言葉づかい

説明と知らせは「記録しました」「動かせます」のように、柔らかい丁寧な言い方で書く。ボタンは「取り消す」「削除」のように短く書く。

| 理由 | 選ばなかった案 |
| --- | --- |
| 使ってもらうアプリなので、言い切りより柔らかく聞こえる | 「記録した」のような言い切り |
