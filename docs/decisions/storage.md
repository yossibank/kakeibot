# 保存

> [!NOTE]
> DB・マイグレーション・書き出し・バックアップの決定と、その理由が分かる。
> 表の形は [data](../data.md) にある。

## DB

**決定：GRDB の DatabasePool を App Group に置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | SQL で集計と移行を書ける。ウィジェットからも読める |
| 却下 | SwiftData、SQLDelight |

## マイグレーションの値

**決定：マイグレーションの中の値は直書きで固定し、enum に値を足すときは表を作り直すマイグレーションとセットにする。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 今の enum から作ると、公開後に case を足したときに CHECK が食い違う。新しく入れた端末と、古い版から上げた端末で違う |
| 却下 | マイグレーションで enum の `allCases` を使う |

> [!IMPORTANT]
> 固定した値が今の `allCases` と一致するかは、`MigrationFrozenValuesTests` が確かめる。case を足すと落ちる。

## DB の変更を画面に届ける

**決定：`ValueObservation`。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 依存を増やさない |
| 却下 | GRDBQuery、SQLiteData |

## 書き出しの形式

**決定：Core に置く。**

| 項目 | 内容 |
| --- | --- |
| 理由 | DB なしで往復を試せる。Android に移せる |
| 却下 | Store に置く |

## バックアップ

**決定：設定の「データ」の「バックアップ」から、全データを JSON のファイルに書き出す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 無料で、サーバーを使わずに、機種変更でも自分でデータを戻せる |
| 却下 | iCloud の同期だけに任せる、今のデータに足して読み込む |
| 関連 | 形式の決まりは [export-format](../../spec/export-format.md) にある |

> [!IMPORTANT]
> - ファイルの名前は `kakeibot-年-月-日.json` にし、保存先は使う人がファイルの画面で選ぶ。
> - 読み込むときは、書き出した日と記録・口座（`Wallet`）の数を出して確かめてから、全部置き換える。
> - 置き換えと同じ書き込みの中で、いまのデータを JSON にして保存する。
> - 保存先は Application Support で、2 世代まで持つ。
> - 新しい保存を 1 つ目に置けてから、前の 1 つ目を 2 つ目へ送り、前の 2 つ目は消す。
> - 途中で失敗したら、前の 2 つの世代を元に戻し、読み込まずにエラーを出す。
> - 退避は MainActor の外で読んで解く。読めない退避は行に出さず、行と読み込みは同じファイルで引く。
> - 画面は、書き出しの「残す」と、読み込みと退避の「戻す」の節に分ける。同期か共有を使っている間は、「戻す」の行を押せなくし、理由を節の下に出す。
> - 保存したデータごとに、「戻す」の節に「日時 の退避に戻す」を出す。確認を通して、全部置き換える。
> - 同じ画面から、記録を表計算用の CSV（`kakeibot-年-月-日.csv`）にも書き出せる。
> - CSV は読み込みには使わない。
