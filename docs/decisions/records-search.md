# 記録の検索と絞り込み

> [!NOTE]
> 記録を探す・絞る操作をどう決めたかと、その理由が分かる。
> 言葉の対応は [glossary](../glossary.md) にある。

## 記録の検索

**決定：カレンダーと一覧の切り替えの右に、絞り込みと虫めがねのボタンを置く。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 月を送らずに、あの支払いがいつだったかを見つけられる |
| ❌ 却下 | ~~今の月だけを探す~~ 月を送らないと、あの支払いがいつだったかを見つけられない |

> [!IMPORTANT]
> - 虫めがねから、すべての月の記録を探す。
> - 空白で区切った言葉が、すべて当てはまる記録を日ごとに並べる。
> - 言葉は、メモ・カテゴリ・タグ・口座の名前に含まれるか、金額と同じ数なら当てはまる。

### 言葉の当て方

金額には `¥` やカンマを付けてもよい。大文字と小文字、全角と半角は区別しない。

### 結果

- 結果の上に、件数・期間・支出と収入の合計と収支を出す。
- 期間と日の見出しは、今年以外の日だけ年を添える。
- 「閉じる」で月の一覧に戻る。
- ほかのタブから日や今の月を開くと、検索を閉じる。絞り込みは残す。

### 探した言葉の履歴

- 探した言葉は、確定した時と、結果がある状態で閉じた時に覚える。
- 新しい順に 5 つまで DB の設定に置き、言葉が空の時に並べる。
- 押すとその言葉で探す。
- 「履歴を消す」で覚えた言葉を消す。消してから 5 秒は、その場の「取り消す」で戻せる。

### 欄と見つからない時

| 状態 | 見た目 | 操作 |
| :---: | --- | --- |
| 欄 | 添え書きは「メモや金額で探す」にする。探せるものの全部は、言葉が空の時の案内で示す | |
| 当てはまる記録が無い | 「「コーヒー」は見つかりませんでした」と出し、その下に「金額やメモの一部でも探せます」と添える | |
| 絞り込みで結果がすべて隠れた | 「絞り込みを外す(3)」も出す。数は、外すと出る件数にする | 押すと絞り込みを外す |

## 記録の絞り込み

**決定：記録の絞り込みのボタンから、シートを開いて選ぶ。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 食費と趣味だけ・カードの分だけ・昼ごはんだけのように、見たいものだけを並べ、合計もそれに合わせて分かる。シートが長くならず、選ぶものを探しやすい |
| ❌ 却下 | ~~支出・収入・口座を 1 つのシートに縦に並べる~~ シートが長くなり、選ぶものを探しにくい |

> [!IMPORTANT]
> - 絞り込みは、月の一覧・カレンダー・月の合計・検索の結果に効かせる。
> - 振り返りには効かせない。
> - 絞り込みはアプリを閉じるまで覚え、DB には置かない。

### 絞り込みのシート

- シートの上で支出・収入・口座・タグを切り替え、選んだほうのカテゴリ・口座・タグを並べる。
- 切り替えの文字には、選んでいる数を添える。
- 選んでいる間は、シートの下に「絞り込みを外す」を出す。
- シートの下に「12 件を表示」を塗って出し、押すと閉じる。
- 件数は、今の絞り込みと検索で見える記録の数にする。0 件なら「該当なし」にする。
- 「絞り込みを外す」は、どこでも同じ言葉とアクセントの色にする。削除の色は使わない。

### シートのタグ

- タグは、カテゴリの名前の下に、入力シートと同じく紐に下げて並べる。
- 1 本に収まらなければ、紐を足して次の行に送る。
- カテゴリを選んでいる時は、そのカテゴリのタグだけを出す。
- 選んでいないカテゴリのタグは、選びから外す。

### 残す記録

| 選んだもの | 残す記録 |
| :---: | --- |
| カテゴリ | そのカテゴリの記録だけを残し、カテゴリの無い振替は外す |
| 口座 | その口座から出たか、その口座に入った記録だけを残す |
| タグ | そのタグの記録だけを残す |
| いくつか | すべてに当てはまる記録を残す |

選んでいる間は、ボタンを塗り、下に選んだ名前と × を出す。
