# 見た目

> [!NOTE]
> 画面の見た目と動きをどう決めたかと、その理由が分かる。テーマは [themes](themes.md)、入力シートは [entry-sheet](entry-sheet.md) にある。
> 言葉の対応は [glossary](../glossary.md) にある。

## 画面の見た目

**決定：黒に近い紺の地に、金の細い縁のカードを置く。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | ホームの夜のダイヤルとそろう |

> [!IMPORTANT]
> - 押して金額を入れる所、名前などの入力欄、アイコンの見本には、金の縁と影の付いた小さな鉛筆の丸い印を添える。押せることを言葉で添えない。
> - 口座・カテゴリ・テンプレート・固定費・スタンプ・ごほうびの追加と編集は、同じ並びにする。

### 記録の行

- 記録の行は、1 行目にカテゴリと金額、2 行目にタグと口座（`Wallet`）の名前を並べ、メモは 3 行目に出す。
- カテゴリは 2 行まで折り返す。タグと口座の名前が 1 行に収まらない時は、口座の名前を上、タグを下の 2 段にする。
- 同じ日の記録は、支出のカテゴリ・収入のカテゴリの並び順に並べ、カテゴリの無い振替を最後に置く。同じカテゴリの中は新しい順にする。
- メモは左に細い線を添え、2 行まで折り返す。
- 固定費（`Recurring`）の名前も 2 行まで折り返す。

記録の行のメモは、次のように開く。

| 状態 | 見た目 | 操作 |
| --- | --- | --- |
| 収まらない | 最後の行の端を薄くし、下向きの矢印を重ねる | 押すと開く |
| 開いた | 全文と、最後の行の端に上向きの矢印。最後の行に空きが無い時は、矢印を次の行に出す | |

### 鉛筆の印

| 所 | 印 |
| :---: | --- |
| 金額の行 | 右の矢印の代わりに印を出す |
| ほかの中央に置く金額 | 印を金額の右の外に添え、金額だけで中央にそろえる |
| 固定費・テンプレート・ごほうびの決まりの金額 | 欄ごと角の丸い枠で囲む。入れる金額が空か 0 の間は枠を点線にする |
| 固定費・テンプレート・ごほうびの決まりの金額の鉛筆 | 影の無い細い縁の印にして額の右に寄せる |
| アイコンの見本 | 印を右下の角に重ねる |
| 入力欄 | 押すと入力を始め、入力している間は消す |

### 追加と編集の並び

並びは、見え方と添え書き・名前・主な項目の 1 枚のカード・くわしい設定・保存のボタンの順である。無い項目は飛ばす。

- テンプレートのカードは、入力シートの札と同じく、カテゴリの色で囲んだ角の丸い四角の印と細い金の縁にする。
- 引き出しを開いても、保存のボタンは消さない。入力欄に入れている間だけ消す。
- 金額やアイコンを入れる引き出しは、下から出し、四隅を丸めて左右と下に余白を取る。

## 余白の単位

**決定：余白・間隔・角の丸みは、4 の倍数にする。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 画面をまたいで余白のそろいが見え、迷わず選べる |
| ❌ 却下 | ~~決めない~~ 画面をまたいで余白のそろいが見えず、選ぶのに迷う |

> [!IMPORTANT]
> - 2 以下の細かい調整は、そのままでよい
> - 設定の画面どうしでそろえる余白と間隔は、`SettingsSpacing` の定数で持つ
> - 部品の大きさ（`frame`）、ずらし（`offset`）、線の太さは、この決まりに入れない
> - 端末の画面やホームの並びを縮めて描く見本と、タグの札の穴のような小さな絵柄の寸法も、この決まりに入れない

## 文字と形と動き

**決定：文字と見た目は、テーマとは別の設定にし、設定の「文字」と「形と動き」の 2 画面から開く。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 用意したテーマ（`ThemePalette`）とも組み合わせられる。段を少なくし、どの組み合わせでも画面が崩れない |
| 💡 理由 | アプリの中だけで大きさを決め、画面の崩れを確かめられる。同梱は性格の違う書体に絞り、アプリを大きくしすぎない |
| ❌ 却下 | ~~テーマごとに持つ~~ 用意したテーマと組み合わせられない |
| ❌ 却下 | ~~丸みを数字で選ぶ~~ 段が多くなり、組み合わせによっては画面が崩れる |
| ❌ 却下 | ~~丸ゴシックを太さ付きの書体に替える~~ アプリが大きくなる |
| ❌ 却下 | ~~使う人がフォントを読み込む~~ アプリの中で画面の崩れを確かめられない |

> [!IMPORTANT]
> - どのテーマでも選べる。
> - 見本は選ぶとすぐ変わり、記録の 1 日分のカードは記録の一覧と同じ形で描く。
> - 端末の文字の大きさの設定は使わない。

### 見本

- 「文字」は文字の大きさと 2 つの字体を選び、見本にホームの残りとテンプレートのカードを出す。
- 「形と動き」の見本には、選んだ背景の上に、記録の 1 日分のカードと小さくしたタブバーを出す。
- 見本は画面の上に固定し、選ぶ所だけをスクロールする。見本の高さは字体で変えない。
- 選ぶ画面の文字は、開いた時の字体のままにし、選ぶたびに動かさない。

### 文字の大きさ

| 大きさ | 倍率 |
| :---: | ---: |
| 小さめ | 0.9 |
| ふつう | 1 |
| 大きめ | 1.15 |

倍率は、数字で決めた大きさにも掛ける。倍率を掛けた文字は、10pt より小さくしない。

$$\text{文字の大きさ} = \max(10\,\text{pt},\ \text{元の大きさ} \times \text{倍率})$$

- 収まるように縮める金額や名前は、そこからさらに縮める。
- 端末の文字が `.xLarge` 以上で、アプリの文字が「大きめ」でない時だけ、勧めのカードを出す。カードは「文字」の画面の選ぶ所の上に置き、押すとその場で大きめにする。閉じるボタンと既読の保存は持たない。
- 入力シートの紙のカードの金額、タグの札、カテゴリのアイコンは、文字の大きさで変えない。
- 大きくして収まらない所は、切り替えを下の段に回すか、文字を縮めて 1 行に収める。
- 並ぶ名前は、並びの中で一番縮んだ大きさに全部そろえる。下限は 0.8 倍で、それでも入らなければ末尾を切る。並びは、一覧・格子・同じ行の札ごとに分ける。
- 金額・残高・数字、固定の短い文言、1 画面に 1 つの見出しは、そろえずに今までどおり縮める。

### 字体

字体は、見出しと金額、本文の 2 か所で別々に選ぶ。どちらも、明朝・ゴシック・丸ゴシック・手書き・ドット・ポップから選ぶ。

| 欄 | 既定 |
| :---: | --- |
| 見出しと金額 | 明朝 |
| 本文 | ゴシック |

手書き・ドット・ポップの字体は、SIL OFL のフォントをアプリに同梱する。

| 字体 | フォント |
| :---: | --- |
| 手書き | Klee One |
| ドット | DotGothic16 |
| ポップ | Hachi Maru Pop |

- 同梱するフォントは、英数字・記号・かな・JIS 第 1 水準と第 2 水準の漢字だけに絞り、太さは 1 つにする。
- ウィジェットは、アプリに同梱したフォントを読む。
- 本文の字体は、字体を書いていない文字にも効かせる。
- SF Symbols のアイコンは、線の太さを保つため字体を変えない。
- 選んだ文字と見た目は、Environment の `themeStyle` で全体に渡す。シートの中も、出した画面の値を受け継ぐ。

### 形と動き

「形と動き」は、次の表の項目を選ぶ。

| 項目 | 選ぶもの | 描き方 |
| :---: | --- | --- |
| 角の丸み | なし・小さめ・ふつう・大きめ | 画面の角の丸みに、選んだ倍率を掛けて描く。選ぶ所には、それぞれの角の形を描いて並べる |
| 行の間隔 | 詰める・ふつう・ゆったり | 記録の一覧の行の高さと上下の余白を変える |
| スタンプの形 | 丸・角丸・印 | 印は塗らずに二重の輪で描く |
| タブの名前 | | 選ぶ所には、タブバーを小さくして描く |
| 背景 | 無地・罫線・方眼 | 画面の地の上に柄を重ねる。罫線は、ノートのような横線と左の余白の縦線で描く |
| 振動 | 入・切 | 切ると、押した時の振動をすべて止める |
| 飾り | 入・切 | 切ると、光の影とタブの金の輪を消す |

- 背景を選ぶ所には、縦長の小さい画面にカードを 1 枚載せて描く。
- 振動と飾りの入と切は、金の塗りと枠だけで入と切を分けるスイッチで選ぶ。行のどこを押しても切り替わる。
- 設定の一覧の「形と動き」の行には、選んだ角の形・スタンプの形・背景を小さい印で並べる。入らない幅では背景の印を外し、それでも入らなければ印を出さない。
- アプリアイコンの見本と、シートの上の角の丸みは変えない。

## アイコンの絵柄

**決定：決まった絵柄の名前（`glyph`）で持ち、OS ごとに絵に置き換える。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 両 OS で同じデータを使え、シックな線の絵にそろえられる |
| ❌ 却下 | ~~絵文字だけ~~ シックな線の絵にそろえられない |
| ❌ 却下 | ~~SF Symbols の名前をそのまま持つ~~ 両 OS で同じデータを使えない |

> [!IMPORTANT]
> iOS では SF Symbols の細い線の絵にする。

## アプリアイコンと起動画面

**決定：アプリアイコンは、金の目盛りの輪と ¥ の印にする。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | ホームのダイヤルと同じ目盛りの形で、起動から記録まで見た目がつながる |

### アイコンの色

> [!IMPORTANT]
> - 標準はホワイトの地にし、ダークでは黒に近い地に変える。
> - 色違いは、同じ印で色だけを変える。
> - 色違いは、設定の「見た目」で、アイコンと同じ絵と色で描いた見本から選ぶ。並びはテーマと同じにする。
> - テーマを選んだ時、アイコンが違う色なら、同じ名前の色違いにそろえるかを聞く。

### 起動画面

> [!IMPORTANT]
> - iOS 標準の地の真ん中に、金の 1 色の同じ印を置く。地は、ライトで白、ダークで黒になる。
> - 起動の後は、同じ絵の輪に沿って光を 1 周させる。光は、ダークで明るいクリーム色、ライトで濃い金にする。
> - ホームを読み終えたら、輪の内側から選んだテーマの地の色を円の形に広げ、画面を塗り替える。広げた円の中では、印もテーマの色で描く。
> - 塗り替えたら薄く消し、最初の画面を見せる。入力シートは、消し終えてから開く。
> - テーマを出すまでは、画面の明るさを iPhone の設定のままにする。
