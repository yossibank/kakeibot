# 声の入力

> [!NOTE]
> 話した言葉から記録を入れる方法をどう決めたかと、その理由が分かる。入力シートのほかの並びは [entry-sheet](entry-sheet.md) にある。
> 言葉の対応は [glossary](../glossary.md) にある。

## 声で記録する

**決定：入力シートのテンキーの上の端に「声」の札を置き、話した言葉から金額・カテゴリ・口座・日付・メモを読んで、保存する前の入力に入れる。**

| 項目 | 内容 |
| --- | --- |
| 理由 | レシートと同じ場所から始まり、今の入力の流れのまま使える。「続けて記録」と合わせて何件も入れられる |
| 理由 | 聞いている間はダイヤルの目盛りが声に合わせて動くので、ホームと入力シートと同じ見た目のまま、聞いていることが分かる |
| 理由 | 端末の中の音声認識（SpeechAnalyzer）とモデル（Foundation Models）で読み、端末の外には送らない |
| 理由 | 人が確かめてから保存するので、聞き違いのまま記録が増えない |
| 却下 | 声の専用の画面で、大きくしたダイヤルを押している間だけ聞く |
| 却下 | 聞き取った中身を伝票に並べ、1 回の発話から何件もまとめて記録する |
| 却下 | ＋ボタンの長押し、Siri から画面を開かずに記録する、外のサービスで聞き取る |
| 却下 | モデルに金額と日付を書き出させる |

> [!IMPORTANT]
> - 「声」は、テンキーの上の 1 段目の「レシート」の右に、マイクの印と「声」の文字の札で置く。振替と、手数料を入れている間は出さない。端末が日本語の音声認識を使えない時も出さない。
> - 1 段目が幅に収まらない時は、日付の札の暦の印を外す前に、「声」の文字を外して印だけにする。
> - 初めて押した時に、マイクと音声認識の許可を聞く。断られている時は、iPhone の設定を開く案内を出す。
> - 押すと、テンキーの場所に聞くカードを出す。カードには、聞き取った文・読めた項目の札・「やめる」と「話し終えた」のボタンを並べる。
> - 読めた項目の札は、カテゴリ・日付・口座・メモの順に、読めたものから金の縁で出す。まだ読めていない項目は点線にする。
> - 聞いている間は、ダイヤルの目盛りを声の大きさに合わせて伸ばし、大きい所を明るくする。予算の弧は描かない。
> - 聞いている間も、読めた金額とカテゴリをダイヤルの中に出していく。
> - 黙って 1.5 秒たつか、「話し終えた」を押すと聞き終える。「やめる」を押すと、何も入れずにカードを閉じる。
> - Foundation Models の動く端末では、聞き取った文と、カテゴリと口座の一覧をモデルに渡し、どれに当たるかを一覧の番号で答えさせる。
> - 金額と日付は、聞き取った文の文字から決まりで読む。日付は「今日」「昨日」「おととい」「N 日」「N 月 N 日」を読む。
> - ほかの端末と、モデルが答えられなかった時は、カテゴリと口座の名前が文に含まれるかで決める。
> - メモには、金額・日付・口座の言葉を除いた残り（店名や買ったもの）を入れる。
> - 読めた項目だけを入れ、読めなかった項目は今の値のまま残す。1 回で入れる記録は 1 件にする。
> - 読み終えたらテンキーを閉じ、内容の帯の上に「声から N つ入れました」と聞き取った文、「取り消す」を出す。「取り消す」を押すと、声で入れる前の値に戻す。
> - 金額が読めなかった時は、テンキーを開いたままにして、言い直しを促す知らせを出す。
> - 音声と聞き取った文は保存しない。

## 声で入れる回数

**決定：声の入力は、無料でも回数の制限なく使える。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 端末の中だけで動き、使うほど費用がかかるものではない |
| 理由 | 毎日の入力を速くする機能なので、試しやすいほど使い続けてもらえる |
| 却下 | レシートと同じく無料は 3 回まで、Pro だけで使える |
