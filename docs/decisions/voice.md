# 声の入力

> [!NOTE]
> 話した言葉から記録を入れる方法をどう決めたかと、その理由が分かる。入力シートのほかの並びは [entry-sheet](entry-sheet.md) にある。
> 言葉の対応は [glossary](../glossary.md) にある。

## 声で記録する

**決定：入力シートの紙のカードに「声で入れる」を置く。話した言葉から金額・カテゴリ・口座・日付・メモを読んで、保存する前の入力に入れる。**

| 項目 | 内容 |
| --- | --- |
| 理由 | レシートと同じ場所から始まり、今の入力の流れのまま使える。「続けて記録」と合わせて何件も入れられる |
| 理由 | 聞いている間も紙のカードに読めた金額とカテゴリが出るので、聞いていることが分かる |
| 理由 | 端末の中の音声認識（SpeechAnalyzer）とモデル（Foundation Models）で読む。端末の外には送らない |
| 理由 | 人が確かめてから保存するので、聞き違いのまま記録が増えない |
| 却下 | 声の専用の画面で、大きなボタンを押している間だけ聞く |
| 却下 | 聞き取った中身を伝票に並べ、1 回の発話から何件もまとめて記録する |
| 却下 | ＋ボタンの長押し、Siri から画面を開かずに記録する、外のサービスで聞き取る |
| 却下 | モデルに金額と日付を書き出させる |

> [!IMPORTANT]
> - 声で入れる入口は、紙のカードの右上の、レシートの隣の丸いボタンにする。置き方は [entry-sheet の「紙のカード」](entry-sheet.md#紙のカード)にある。
> - 端末が日本語の音声認識を使えない時は出さない。
> - 初めて押した時に、マイクと音声認識の許可を聞く。断られている時は、iPhone の設定を開く案内を出す。
> - 押すと、テンキーの場所に聞くカードを出す。カードには、聞き取った文・読めた項目の札・「やめる」と「話し終えた」のボタンを並べる。
> - 聞き取った文は見切れないようにする。長くなったら字を縮め、それでも入らなければカードの中で送って、最後の言葉を見せる。
> - 聞き始めと聞き終えた時に、軽く 1 回ずつ振動する。
> - 読めた項目の札は、カテゴリ・日付・口座・メモの順に、読めたものから金の縁で出す。まだ読めていない項目は点線にする。
> - 聞いている間は、カードの上に、マイクの音の大きさで動く波を出す。波は真ん中がいちばん新しい音で、外へ流れていく。
> - 波は、中央の線から上下に伸びる金のグラデーションの棒を 31 本並べ、声が大きい棒ほど光らせる。
> - 紙のカードの金額の見出しの右にも、同じ波を小さく出し、読めた金額とカテゴリを出していく。
> - 声が小さくなってから 1 秒たつか、「話し終えた」を押すと聞き終える。黙ったかは、文字が届いた時ではなく音の大きさで決める。
> - 1 秒たった時は、「話し終えた」を押した時と同じく、その場で聞き終えて結果を出す。
> - 「やめる」を押すと、何も入れずにカードを閉じる。
> - 聞き終えるまでの残りは、文言を添えずに「話し終えた」のボタンで見せる。黙るとボタンが左から濃い金で満ち、話すと空に戻る。
> - マイクの入り切りは、画面の動きを止めないように、画面を描くスレッドの外で行う。
> - 聞く時は、カテゴリ・タグ・口座・テンプレートの名前と最近のメモを、音声認識の手がかりに渡す。
> - 一番の聞き取りで金額が読めない時は、言い換えの候補のうち金額が読める文を使う。
> - Foundation Models の動く端末では、聞き取った文と、カテゴリと口座の一覧をモデルに渡す。答えは一覧の名前の中から選ばせる。
> - モデルへの指示には、外れやすい言葉の短い例だけを添える。カテゴリごとの例を並べると、例に無い言い方で外れやすくなる。
> - 場所や払い方の言葉では、カテゴリを決めさせない。
> - モデルには、その人の記録を、メモとカテゴリと口座の組で 8 つまで例として添える。話した文とメモが似た記録を先に置き、残りは新しい順にする。
> - 金額と日付は、聞き取った文の文字から決まりで読む。金額は「円」「えん」「¥」と漢数字を読み、「円」の付いた数が複数あれば最後の数にする。
> - 日付は「今日」「昨日」「おととい」「今朝」「ゆうべ」「N 日前」「N 日」「N 月 N 日」と曜日を読む。曜日は直前のその曜日で、「先週の」が付けば前の週にする。
> - ほかの端末と、モデルが答えられなかった時は、カテゴリと口座の名前が文に含まれるかで決める。
> - メモには、金額・日付・口座の言葉を除いた残り（店名や買ったもの）を入れる。「現金」「クレカ」のような払い方の言葉と、「の支払い」「の料金」「の代金」も除く。
> - 読めた項目だけを入れ、読めなかった項目は今の値のまま残す。1 回で入れる記録は 1 件にする。
> - 読み終えたら、入力盤の上に「声から N つ入れました」と聞き取った文、「取り消す」を出す。「取り消す」を押すと、声で入れる前の値に戻す。
> - 知らせは 4 秒で消す。聞き取った文は切らずに折り返して出す。
> - 声で入れた口座・日付の字とメモの行は、値に薄い下線を引く。その値を変えると下線を消す。
> - 金額が読めなかった時は、入力盤を金額の中身のままにして、言い直しを促す知らせを出す。知らせには聞き取った文を切らずに出し、何も聞き取れなかった時はそう伝える。
> - 音声と聞き取った文は保存しない。

## 声で入れる回数

**決定：声の入力は、無料でも回数の制限なく使える。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 端末の中だけで動き、使うほど費用がかかるものではない |
| 理由 | 毎日の入力を速くする機能なので、試しやすいほど使い続けてもらえる |
| 却下 | レシートと同じく無料は 3 回まで、Pro だけで使える |
