# 固定費・カード・予算

> [!NOTE]
> 固定費、カードの引き落とし、予算、ホームの「あといくら」の決定が分かる。
> 言葉の対応は [glossary](../glossary.md) にある。

## 固定費の記録

**決定：固定費（`Recurring`）は、決まった日に記録を作る。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 先の記録が残高や振り返りに混ざらない。アプリを開かない日が続いても抜けない |
| 却下 | 先の分まで作っておく、開いた日の分だけ作る |

決まり：

- 記録を作るのは今日までで、先の日の分は作らない。
- 作り忘れた日の分は、次に作るときにまとめて作る。
- どの日まで作ったかを `generated_until` に残し、同じ固定費の同じ回の記録は 2 つ作らない。
- 月末を超える日は、その月の最終日にする。
- 設定の一覧で非表示にした固定費は、記録を作らず、知らせない。
- 表示に戻すと、戻した日から作り、非表示の間の分は作らない。
- 非表示の固定費の行には、次の日の代わりに「止めています」と出す。

## 固定費の休日の扱い

**決定：固定費ごとに、休日に当たったときの扱いを「そのまま・前の平日・次の平日」から選ぶ。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 家賃やカードは次の平日、給料は前の平日のように、固定費ごとに違う。銀行の休みに合わせる |
| 却下 | 全体で 1 つの設定にする、土日だけを休日にする |

**決定：同じ回かどうかは、休日でずらす前の予定日の月で決める。**

| 項目 | 内容 |
| --- | --- |
| 理由 | ずらした後の日は月をまたぐことがあり、引き落とし日や休日の扱いを変えても、予定日の月は変わらない |
| 却下 | ずらした後の日で決める（末日に近い予定日が翌月に入り、回がずれる）、日数の幅で判定する（前後 10 日だと、引き落とし日を 5 日から 20 日に変えると同じ月に 2 件でき、12 日に変えると作られない） |

決まり：

- 休日は、土日・祝日・年末年始（12/31〜1/3）にする。
- 新しく作るときは、カテゴリから初めの値を選ぶ。
- 給料と臨時収入は前の平日、住まい・光熱費・通信と振替は次の平日、ほかはそのままにする。
- 自分で選んだあとは、カテゴリを変えても変えない。
- 一覧の行には、「休日は次の平日」のように添える。
- ずらした日を、記録を作る日・知らせる日・一覧の次の日のすべてに使う。
- 始まりと終わりは、ずらした後の日で比べる。
- 同じ回は、休日でずらす前の予定日の月で決める。同じ固定費の記録が、作る日と同じ回にあれば作らない。
- 記録には、ずらす前の予定日を `recurring_date` に、実際の日を `date` に残す。同じ回かどうかは、残した予定日の年月と、作る回の予定日の年月を比べる。
- 引き落とし日や休日の扱いを変えても、残した予定日は変わらず、同じ月に 2 件目を作らない。
- 休日の扱いを途中で変えても、同じ回の記録を 2 つ作らない。

**決定：古い記録の予定日と引き落とし月は、マイグレーションの時点の設定で逆算して書き直す。決まらない行は変えない。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 予定日を残す前の記録は、ずらした後の日しか持たない。列を足さずに、今ある情報から回を決める |
| 却下 | すべての行を書き直す（決まらない行を間違った回にする）、逆算せずに捨てる（設定を変えると回が入れ替わる） |

決まり：

- 固定費の記録の `recurring_date` は、その固定費の設定で、ずらした日がその日になる予定日に書き直す。見つからなければ変えない。
- `bill_month` の記録は、その口座をカードとして引き落とす固定費が 1 つだけのときに、書き直す。ずらした後の日が元の月に入る予定日を前後 1 か月から探し、ちょうど 1 つならその予定日の月にする。0 か 2 つ以上なら変えない。
- 書き直した `recurring_date` が、同じ固定費の別の記録と重なるときは、変えない。

## カードの締め日と引き落とし

カードの締め日と引き落としは、利用分の振替・請求を次に回すこと・これからの引き落とし・固定費の保存と削除を決める。

### 利用分の振替

**決定：引き落とし日に、その回の締め日までの 1 か月の利用分を額にして、振替を作る。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 固定費の休日の扱い・知らせ・今月の固定費をそのまま使える。カードを使うほど額が変わっても、手で直さなくてよい |
| 却下 | 口座（`Wallet`）の設定に締め日を置く、毎月の額を手で入れる |

決まり：

- 振替先がカードの固定費は、「金額の決め方」で決まった額か利用分かを選ぶ。
- 利用分を選ぶと、締め日を 1〜31 日（31 は末日）から選ぶ。
- カードの口座の編集にも「締め日と引き落とし」の行を置き、その固定費の編集を開く。
- まだ無ければ、そのカードへの振替を、末日締め・27 日払いの利用分として作り始める。
- カードを足して保存すると、借入の返済と同じく、締め日と引き落としも決めるかを聞く。
- 翌々月払いのカードは、まだ扱わない。
- 利用分の期間は、休日でずらす前の予定日から決める。
- 締める月は、設定した引き落とし日と締め日で決める。引き落とし日が締め日より後なら予定日と同じ月、同じか前なら前の月に締める。丸めは月を決めた後に 1 回だけ行う。
- 期間は、前の月の締め日の翌日から、締め日までにする。短い月は末日に丸め、期間は隙間なく重ならずに続く。
- 利用分は、その期間にカードで払った支出から、カードに入った収入を引いた額にする。
- 振替は数えない。
- 利用分が 0 円なら作らない。
- 固定費の一覧の行は、名前と金額・繰り返し・口座と次の日の 3 行にする。
- 締め日は「15 日締め・次は 10/26」のように次の日と並べる。
- 知らせは額を入れず、「10/26 に引き落としがあります」と出す。

### 請求を次に回す

**決定：カード会社の確定が遅れた記録は、後の引き落としに回せる。**

決まり：

- 入力シートの支払い元でカードを選ぶと、シートを閉じずに「請求」の 3 枚のめくりカレンダーを出す。
- 「いつもどおり」「次に回す」「2 回先」を並べ、カードを選んだときは「いつもどおり」にしておく。
- 下の「11/27 払いで決める」のボタンでシートを閉じる。
- 請求を出している間は、シートを下の端にそろえて開き、ボタンまで見せる。
- 回した記録は、その回（休日でずらす前の予定日の月）の引き落としに入れ、元の期間からは外す。
- 支払い元や日付を変えると、いつもどおりに戻す。
- 入力シートの支払い元の欄には、見出しの代わりに`12/26払い`と出す。
- 記録の行では、口座の名前に`（12/26払い）`のように、その回の実際の引き落とし日を添える。決まらないときは`（12月払い）`と添える。
- 「これからの引き落とし」には「前から 1 件・後へ 1 件」のように回した件数を添え、押すと回した記録を並べる。
- 記録を押すと、その記録を開く。

### これからの引き落とし

**決定：まだ来ない引き落としは、今日までの記録から見込みの額を出す。**

決まり：

- 今月の固定費・記録のカレンダー・固定費の一覧・資産のタブで使う。
- 資産のタブには「これからの引き落とし」を出す。
- 振替先がカードの固定費ごとに、明日より後の次の引き落とし日と見込みの額、利用分の期間を並べる。
- 日付はめくりカレンダーの形にし、あと何日かを添える。
- 引き落とし元の口座の残高のうち、引き落とされる割合を細い線で出す。
- その下に「銀行 ¥459,600 → ¥408,800」と添える。
- 足りなければ薔薇色にして、足りない額を出す。
- 行を押すと、その固定費の編集を開く。
- カードの口座の欄には、次の引き落としの額を添える。
- 引き落としの知らせは、その日に口座が足りなくなる見込みなら、「銀行が ¥12,000 足りません」と添える。
- 見込みは、知らせを組み直すときの残高で決める。

### 固定費の保存と削除

**決定：保存すると、始まりから今日までの分をすぐ作る。消すと、作った記録は残し、固定費とのつながりだけを外す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 過去から始まる家賃を足しても、すぐ記録がそろう。消しても過去の記録と残高が変わらない |
| 却下 | 次の日付から作る、消すときに記録も消す |

決まり：

- 始まりを前に動かすと、新しい始まりから元の始まりの前日まで（今日を超えない）の分だけを、保存と同じ書き込みの中で作る。同じ回の記録は作らず、手で消した回は戻さない。
- 固定費は、設定の「記録」の「固定費」で足して直す。
- 一覧は長押しで並べ替え、横に払うと非表示と削除のボタンを出し、最後まで払うと止めて非表示にする。
- 編集の右上の「…」からも、非表示と削除を選べる。
- 消す前に確かめ、消した直後は「取り消す」を出す。
- 取り消すと、記録とのつながりも戻す。
- 終わりは、「今日で終える」で今日にできる。
- 上に今月の支出と収入の合計を出す。
- 支出・収入・振替を扱う。
- 振替は、カードの引き落としや積立に使い、振替元と振替先を選ぶ。
- 起動・前面に戻る・日付が変わるときにも、作り残しを作る。
- 固定費で作った記録には、記録の行で名前の横に繰り返しの印を出す。

## 支出なしの日

**決定：印を作る（`no_spend_day`）。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 印がないと、支出のない日にも記録忘れの通知が来る |
| 却下 | 作らない |

## 予算の履歴

**決定：「この月から」の行を足す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 額を変えても過去の月が変わらない。月替わりの写し作業が要らない |
| 却下 | 月ごとに全カテゴリを写す、履歴なし |

決まり：

- 設定の予算で額を変えると、今の期間の月から使う。
- 月全体とカテゴリごとに、テンキーで入れるか、なくす。
- テンキーの ✓ でも保存する。
- 予算の画面では、今の期間に使った額と残りを細い棒で出す。
- 固定費の支出があれば、その合計を目安として出す。

## ホームの「あといくら」

**決定：月全体の予算があれば、ホームのダイヤルに、予算から今の期間の支出を引いた残りを出す。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 開いてすぐ、あといくら使えるかと、1 日の目安が分かる |
| 却下 | 支出だけを出す、カテゴリごとの残りを並べる |

決まり：

- 1 日あたりの額や、今のペースでの見通しは出さない。日によって使う額がばらつき、固定費も決まった日に出ていくので、日割りや見通しの数字は当てにならない。
- 今の期間に固定費の支出があれば、その合計も小さく出す。
- 明日から期間の終わりまでに来る分があれば、「これから」として添え、支払った割合を細い線で出す。
- 押すと、今の期間に来る固定費を、支出・収入・振替とも日付順に並べたシートを開く。
- 上には、これから出ていく額と、支払った額・支出と収入の合計を出す。
- 今日の線で、済んだ分とこれからの分を分ける。
- 済んだかどうかは、その固定費から作られた記録があるかで決め、金額も記録の額を出す。
- 済んだ分は薄くし、今日までで記録が無い分は「記録がありません」と出し、その日の分をその場で記録できる。
- 行を押すと、その固定費の編集を開く。

ダイヤルは、予算の状態で次のように変わる。

| 状態 | 見た目 | 操作 |
| --- | --- | --- |
| 予算あり | 目盛りの弧は使った割合で伸ばす。下に予算を出す | 下の予算を押すと、予算の画面をシートで開く |
| 8 割 | 8 割を使ったら琥珀色にして「予算の 8 割を使いました」と出す | |
| 超過 | 見出しを「予算オーバー」にし、超えた額を薔薇色で出す | |
| 予算なし | 今の期間の支出を出し、予算を決める案内を添える | 案内を押すと、予算の画面をシートで開く |
