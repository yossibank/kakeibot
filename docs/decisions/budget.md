# 予算

> [!NOTE]
> 支出なしの日、予算の履歴と繰越、ホームの「あといくら」の決定が分かる。
> 固定費の決定は [recurring](recurring.md)、カードの締め日と引き落としは [cards](cards.md) にある。
> 言葉の対応は [glossary](../glossary.md) にある。

## 支出なしの日

**決定：印を作る（`no_spend_day`）。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 印がないと、支出のない日にも記録忘れの通知が来る |
| ❌ 却下 | ~~作らない~~ 支出のない日にも記録忘れの通知が来る |

## 予算の履歴

**決定：「この月から」の行を足す。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 額を変えても過去の月が変わらない。月が替わるたびに額を書き写す作業が要らない |
| ❌ 却下 | ~~月ごとに全カテゴリを写す~~ 月が替わるたびに額を書き写す作業が要る |
| ❌ 却下 | ~~履歴なし~~ 額を変えると過去の月も変わる |

> [!IMPORTANT]
> - 設定の予算で額を変えると、今の期間の月から使う。
> - 保存のボタンは「`11月からこの額にする`」のように、額を使い始める月を出す。

### 予算の画面

月全体とカテゴリごとに、テンキーで入れるか、なくす。テンキーを閉じるキーでも保存する。予算の画面では、今の期間に使った額と残りを細い棒で出す。

| 状態 | 見た目 | 操作 |
| --- | --- | --- |
| 予算をなくした直後 | 「食費の予算をなくしました」と「取り消す」の知らせを 4 秒出す | 押すと元の額に戻す |
| 予算のあるカテゴリ | 上に並べる | |
| 予算の無いカテゴリ | 「予算なし」として下にまとめる。アイコン・名前・使った額だけの低い行にし、使った額の多い順に並べる | |
| 予算のあるカテゴリが 1 つも無い | 「カテゴリごと」の見出しも出さない | |

### 目安の札

固定費の支出があれば、その合計を目安として出す。テンキーの上に、押すとその額が入る目安の札を並べる。0 の札と、同じ額の札は出さない。

| 予算 | 札 |
| :---: | --- |
| カテゴリ | 「先月」「3 か月の平均」 |
| 月全体 | 「先月」「3 か月の平均」「固定費」 |

どれもその支出の額にする。平均は、前の 3 か月のうち最初の記録の後に終わる月で割り、100 円単位に切り上げる。

$$\text{3 か月の平均} = 100 \times \left\lceil \frac{\text{前の 3 か月の支出}}{100 \times \text{最初の記録の後に終わる月の数}} \right\rceil$$

その月が 2 つに満たない時は、平均を出さない。最初の設定では、記録が無いので固定費だけになる。

## 予算の繰越

**決定：月全体の予算の残りを、次の期間の予算に足す。**

$$\text{次の期間の繰越} = \text{今の期間の繰越} + \text{今の期間の予算} - \text{今の期間の支出}$$

> [!IMPORTANT]
> - 使いすぎた分は、次の期間の予算から引く。
> - カテゴリごとの予算は、繰り越さない。
> - 繰り越した額は、期限なく積み上がる。

### 積み始めと積み直し

| 状態 | 繰越 | 操作 |
| --- | --- | --- |
| 初め | 繰り越さない。初めの繰越は 0 にし、手では入れない | 設定の予算の画面で、繰り越すかどうかを切り替える |
| 繰り越すにした | 繰り越すにした期間の残りから積み始め、次の期間に足す。今の期間の額は変えない | |
| 月全体の予算が無い期間を挟む | 0 に戻す | |
| 「0 に戻す」を押した | 今の期間から積み直す | 「取り消す」の知らせを 4 秒出す |

ホームの予算の行は「`予算 ¥50,000 ＋ 繰越 ¥8,000`」と並べ、あといくらは繰越を足した額から出す。

## ホームの「あといくら」

**決定：月全体の予算があれば、ホームのダイヤルに、予算から今の期間の支出を引いた残りを出す。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 開いてすぐ、あといくら使えるかが分かる |
| ❌ 却下 | ~~支出だけを出す~~ あといくら使えるかが分からない |

$$\text{あといくら} = \text{予算} + \text{繰越} - \text{今の期間の支出}$$

> [!IMPORTANT]
> - 1 日あたりの額や、今のペースでの見通しは出さない。日によって使う額がばらつき、固定費も決まった日に出ていくので、日割りや見通しの数字は当てにならない。
> - ダイヤルの下の真ん中は、予算があれば今月の支出、なければ昨日の支出にする。予算がない時はダイヤル本体が今月の支出を出すので、同じ数字を 2 か所に出さない。

### ダイヤルの下

- 今の期間に固定費の支出があれば、その合計も小さく出す。
- 明日から期間の終わりまでに来る分があれば、「これから」として添え、支払った割合を細い線で出す。
- 固定費の行が 1 行に入らない幅では、「今月の固定費」を「固定費」に縮め、折り返さない。
- ダイヤルの下の 3 つの額は、いちばん入りにくい額に合わせて、同じ大きさに縮める。

### 固定費のシート

押すと、今の期間に来る固定費を、支出・収入・振替とも日付順に並べたシートを開く。上には、これから出ていく額と、支払った額・支出と収入の合計を出す。今日の線で、済んだ分とこれからの分を分ける。

済んだかどうかは、その固定費から作られた記録があるかで決め、金額も記録の額を出す。行を押すと、その固定費の編集を開く。

| 状態 | 見た目 | 操作 |
| --- | --- | --- |
| 済んだ分 | 薄くする | |
| 今日までで記録が無い分 | 「記録がありません」と出す | その日の分をその場で記録できる |
| 当日の分で、記録も無く、固定費の記録もまだ作られていない（作った日が今日より前） | 「これから」に数える。次の固定費にも選ぶ | |
| 当日の分で、作られた後で記録が無い | 「記録がありません」と出す | |

### ダイヤルの状態

ダイヤルは、予算の状態で次のように変わる。

| 状態 | 見た目 | 操作 |
| --- | --- | --- |
| 予算あり | 目盛りの弧は使った割合で伸ばす。下に予算を出す | 下の予算を押すと、予算の画面をシートで開く |
| 8 割 | 8 割を使ったら琥珀色にして「予算の 8 割を使いました」と出す | |
| 超過 | 見出しを「予算オーバー」にし、超えた額を薔薇色で出す | |
| 予算なし | 今の期間の支出を出し、予算を決める案内を添える | 案内を押すと、予算の画面をシートで開く |
| 記録を読めない | ダイヤルと下の 3 つの額を「—」にし、弧と 8 割の知らせを出さない | 最近の記録の「もう一度読み込む」で読み直す |
