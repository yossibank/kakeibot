# ごほうびとスタンプ

> [!NOTE]
> ごほうび、貯金箱、キャラクター、スタンプの決定が分かる。
> 言葉の対応は [glossary](../glossary.md) にある。

## ごほうびの決まり

**決定：ごほうびの決まりは、設定の「楽しみ」の「ごほうびの決まり」で作る。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 何を頑張ったかと、いくら貯まるかが一目で分かる。並べ替えと非表示を、ほかの一覧と同じ手つきでできる |
| ❌ 却下 | ~~行で並べる~~ カードなら、何を頑張ったかと、いくら貯まるかが一目で分かる |

> [!IMPORTANT]
> - 達成した日に、その額を貯金箱に貯める。
> - 貯めた記録がある決まりは、削除できない。確認で「非表示にする」を選ぶと、貯めた分を残したまま一覧から外せる。

### 決まりの中身と一覧

- 楽しみが無い間は、ホームと通知の「ごほうび貯金を始める」から同じ一覧を開く。
- 決まりには、名前（「自炊した日」など）・貯める額・アイコンを持たせる。
- 額は電卓のテンキーで入れ、0 円は保存させない。
- 一覧は 2 列のカードで並べ、アイコン・名前・1 回で貯める額を出す。
- 右上には、これまで達成した回数と貯めた合計を出し、アイコンの色をうっすら光らせる。
- 並べ替えと非表示は、スタンプの一覧と同じ操作にする。

### 決まりを消す・隠す

| 状態 | 見た目 | 操作 |
| :---: | --- | --- |
| 貯めた記録がある | 削除できない | 確認で「非表示にする」を選ぶ |
| 記録が無い | 削除できる | 「取り消す」で戻せる |
| 非表示の決まり | その日のシートで、達成を表示中の決まりの後に並べる | 押すと外せる。新しく達成は付けられない |

## 貯金箱の残高

**決定：貯金箱の残高は、マイナスにしない。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 残高は、貯めた合計から買った目標の合計を引いて毎回求める。決まりと一緒に記録を消せたり、足りない残高で買えたりすると、マイナスになる |

$$\text{貯金箱の残高} = \text{貯めた合計} - \text{買った目標の合計}$$

> [!IMPORTANT]
> - 残高が目標の額に届かない目標は、「買った」にできない。
> - 貯めた記録がある決まりは削除させず、非表示にする。
> - 達成を外して残高がマイナスになる時は、外させない。

## ごほうびの達成と貯金箱

**決定：達成は、記録で日の見出しに置く贈り物のボタンか、資産の貯金箱の「今日の達成を付ける」から付ける。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | スタンプ（`CalendarStamp`）と同じく、その日を振り返る場所で付けられる。貯金箱を見ている場所からも、今日の分をすぐ付けられる |
| 💡 理由 | 仮想の額を本物の残高と取り違えない |
| ❌ 却下 | ~~口座（`Wallet`）として扱う~~ 仮想の額を本物の残高と取り違える |

> [!IMPORTANT]
> - 1 つの決まりは 1 日に 1 回だけ付けられる。
> - 貯める額は、付けた時の決まりの額を複製し、あとで決まりの額を変えても変わらない。

### 贈り物のボタン

- 贈り物のボタンは、今日までの日にだけ出す。達成した日は、ボタンを塗る。
- 押すとその日の決まりを並べたシートを開き、押すたびに付け外しする。
- シートは中身の高さに合わせて開く。
- 決まりが無い時は、シートから決まりを作れる。決まりがある時も、右上の「＋」から足せる。

### 資産の画面の貯金箱

- 資産の画面の下に「ごほうび貯金箱」を出す。
- 額の下に「我慢できた日に決めた額を貯めていきます」「口座の残高は変わりません」と添える。
- 下に「今日の達成を付ける」を置く。カードを押すと貯金箱の画面を開く。
- 最近の達成を 3 件まで並べる。決まりの名前は 2 行まで出し、日付はその下に添える。

| 状態 | 見た目 | 操作 |
| :---: | --- | --- |
| 目標あり | 目標の名前を 2 行まで出し、進み具合の棒の下に目標の額と「あといくら」を出す | |
| 目標が無い | 点線の「欲しい物を目標にする」を出す | 押すと目標の編集を開く |
| 目標に届いた | カードの縁を光らせて札を出す | |

### 貯金箱の画面

- 上に残高と、いちばん先の目標までの「あといくら」と割合を出す。目標が無ければ、残高の下に資産のカードと同じ 2 行の説明を添える。
- その下に、使い方の 3 つの手順・目標・ごほうびの決まり・買ったもの・月ごとの達成の履歴を並べる。
- 決まりと目標が両方ある時は、使い方の手順を畳み、見出しを押すと開く。
- 決まりの名前は、2 行まで出す。
- 目標が無い時は、点線の「欲しい物を目標にする」を出す。
- ごほうびの決まりは額と並べ、鉛筆の丸いボタンで設定と同じ一覧を画面送りで開く。目標の追加は ＋ の丸いボタンにする。
- 決まりが無い時は、点線の「決まりを追加」を出す。

### 目標と買ったもの

- 目標には欲しい物の名前と額を決め、届いたら「買った」を押す。
- 目標の編集は、決まりの編集と同じ形にする。上に目標のカードの見本を出し、額は行を押して下から出すテンキーで入れる。
- 買うと買った日を記録し、その額を貯金箱から引く。買った直後は「取り消す」を出す。
- 買ったものは「戻す」で目標に戻せる。

## キャラクター

**決定：家計簿の相棒のキャラクターは置かない。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 一言は、ダイヤルや貯金箱で見える予算の残りと達成の数の言い直しになる。素材と画面を持たずに済む |
| ❌ 却下 | ~~用意した動物から選んで名前を付け、場面ごとに一言を出す~~ 一言は、見えている数の言い直しになる |

## スタンプの一覧

**決定：カレンダーに押すスタンプは、設定の「楽しみ」にあるスタンプの一覧で作っておく。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 押すたびに作らずに済む。カテゴリ・口座は作る数が少なく、使い回す場面がない |
| ❌ 却下 | ~~押すたびに作る~~ 作っておけば、押すたびに作らずに済む |
| ❌ 却下 | ~~カテゴリ・口座と共有するアイコンの棚~~ カテゴリ・口座は作る数が少なく、使い回す場面がない |

> [!IMPORTANT]
> - カテゴリ・口座のアイコンとは分ける。
> - 非表示にしたスタンプも、押したものはカレンダーに残る。

### スタンプの並べ替えと非表示

- 楽しみが無い間は、カレンダーのスタンプのシートから作る。
- 一覧は、カテゴリと同じ 4 列のマスで並べ、長押しで並べ替える。
- 下の枠に置くか、編集の画面のボタンで非表示にする。
- 非表示のスタンプは一覧の下に並べ、長押しで浮かせ、画面の上の端に出る枠に置くと表示に戻す。

## カレンダーのスタンプ

**決定：1 日に 1 つ押せる。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | マスが小さく、1 つなら見分けられる。金額を隠さない |
| ❌ 却下 | ~~3 つまで~~ マスが小さく、1 つなら見分けられる |
| ❌ 却下 | ~~いくつでも~~ マスが小さく、1 つなら見分けられる |
| ❌ 却下 | ~~金額の代わりに出す~~ 金額を隠す |

> [!IMPORTANT]
> - 選べるのは、非表示にしていないスタンプだけにする。
> - 押し直すと置き換え、外すこともできる。
> - 金額と支出なしの印はそのまま出す。

### スタンプを押す場所

記録の日の見出し（一覧でもカレンダーの日のカードでも）の右のボタンから、シートでスタンプの一覧を開いて選んで押す。シートは中身の高さに合わせて開き、スタンプが無い時はシートから作れる。右上の「＋」からも足せる。

| 状態 | 見た目 | 操作 |
| :---: | --- | --- |
| ごほうびの達成もスタンプも無い日 | 2 つのボタンを破線の「＋」1 つにまとめる | 押すと、すぐ下の小さなメニューで「スタンプを押す」か「ごほうびを付ける」を選ばせる。下に場所が無い時は上に出す |
| どちらかがある日 | ボタンを分けたまま出す | |
| ごほうびを付けられない明日以降の日 | ボタンを分けたまま出す | |
| スタンプを押した日のマス | アイコンの色で塗った判子にして、日付の右上に重ねる | 押した時は弾ませる |
