# ごほうびとスタンプ

> [!NOTE]
> ごほうび、貯金箱、キャラクター、スタンプの決定が分かる。
> 言葉の対応は [glossary](../glossary.md) にある。

## ごほうびの決まり

**決定：ごほうびの決まりは、設定の「楽しみ」の「ごほうび」で作る。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 何を頑張ったかと、いくら貯まるかが一目で分かる。並べ替えと非表示を、ほかの一覧と同じ手つきでできる |
| 却下 | 行で並べる、額を選ばず一律にする |

> [!IMPORTANT]
> - 決まりには、名前（「自炊した日」など）・貯める額・アイコンを持たせる。
> - 達成した日に、その額を貯金箱に貯める。
> - 額は電卓のテンキーで入れ、0 円は保存させない。
> - 一覧は 2 列のカードで並べ、アイコン・名前・1 回で貯める額を出す。
> - 右上には、これまで達成した回数と貯めた合計を出し、アイコンの色をうっすら光らせる。
> - 並べ替えと非表示は、スタンプの一覧と同じ操作にする。
> - 貯めた記録がある決まりは、削除できない。確認で「非表示にする」を選ぶと、貯めた分を残したまま一覧から外せる。
> - 記録が無い決まりは削除でき、「取り消す」で戻せる。
> - 非表示の決まりの達成は、その日のシートに表示中の決まりの後に並べ、押すと外せる。非表示の決まりに、新しく達成は付けられない。

## 貯金箱の残高

**決定：貯金箱の残高は、マイナスにしない。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 残高は、貯めた合計から買った目標の合計を引いて毎回求める。決まりと一緒に記録を消せたり、足りない残高で買えたりすると、マイナスになる |
| 却下 | 決まりを消すとき記録を残して決まりだけ消す、マイナスを許す |

> [!IMPORTANT]
> - 残高が目標の額に届かない目標は、「買った」にできない。
> - 貯めた記録がある決まりは削除させず、非表示にする。
> - 達成を外して残高がマイナスになるときは、外させない。

## ごほうびの達成と貯金箱

**決定：達成は、記録の日の見出しの贈り物のボタンか、資産の貯金箱の「今日の達成を付ける」から付ける。**

| 項目 | 内容 |
| --- | --- |
| 理由 | スタンプ（`CalendarStamp`）と同じく、その日を振り返る場所で付けられる。貯金箱を見ている場所からも、今日の分をすぐ付けられる |
| 理由 | 仮想の額を本物の残高と取り違えない |
| 却下 | ホームに付ける場所を置く、自動で判定する、口座（`Wallet`）として扱う |

> [!IMPORTANT]
> - 贈り物のボタンは、今日までの日にだけ出す。
> - 押すとその日の決まりを並べたシートを開き、押すたびに付け外しする。
> - シートは中身の高さに合わせて開く。
> - 決まりが無いときは、シートから決まりを作れる。
> - 決まりがあるときも、右上の「＋」から足せる。
> - 1 つの決まりは 1 日に 1 回だけ付けられる。
> - 貯める額は、付けたときの決まりの額を写し、あとで決まりの額を変えても変わらない。
> - 達成した日は、ボタンを塗る。
> - 資産の画面の下に「ごほうび貯金箱」を出す。
> - 額の下に「我慢できた日に決めた額を貯めていきます」「口座の残高は変わりません」と添える。
> - 下に「今日の達成を付ける」を置く。
> - カードを押すと貯金箱の画面を開く。
> - 貯金箱の画面には、上に残高と、いちばん先の目標までの「あといくら」と割合を出す。
> - 目標が無ければ、残高の下に資産のカードと同じ 2 行の説明を添える。
> - その下に、使い方の 3 つの手順・目標・ごほうびの決まり・買ったもの・月ごとの達成の履歴を並べる。
> - 目標が無いときは、点線の「欲しい物を目標にする」を出す。
> - ごほうびの決まりは額と並べ、「編集」で設定と同じ一覧を画面送りで開く。
> - 決まりが無いときは、点線の「決まりを追加」を出す。
> - 目標には欲しい物の名前と額を決め、届いたら「買った」を押す。
> - 買うと買った日を記録し、その額を貯金箱から引く。
> - 買った直後は「取り消す」を出す。
> - 買ったものは「戻す」で目標に戻せる。
> - 資産の画面の貯金箱には、最近の達成を 3 件まで並べる。

資産の画面の貯金箱は、次のように変わる。

| 状態 | 見た目 | 操作 |
| --- | --- | --- |
| 目標あり | いちばん先の目標まで「あといくら」と進み具合の棒を出す | |
| 目標が無い | 点線の「欲しい物を目標にする」を出す | 押すと目標の編集を開く |
| 目標に届いた | カードの縁を光らせて札を出す | |

## キャラクター

**決定：家計簿の相棒のキャラクターは置かない。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 一言は、ダイヤルや貯金箱で見える予算の残りと達成の数の言い直しになる。素材と画面を持たずに済む |
| 却下 | 用意した動物から選んで名前を付け、場面ごとに一言を出す |

## スタンプの一覧

**決定：カレンダーに押すスタンプは、設定の「楽しみ」にあるスタンプの一覧で作っておく。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 押すたびに作らずに済む。カテゴリ・口座は作る数が少なく、使い回す場面がない |
| 却下 | 押すたびに作る、カテゴリ・口座と共有するアイコンの棚 |

> [!IMPORTANT]
> - カテゴリ・口座のアイコンとは分ける。
> - 非表示にしたスタンプも、押したものはカレンダーに残る。
> - 一覧は、カテゴリと同じ 4 列のマスで並べ、長押しで並べ替える。
> - 下の枠に置くか、編集の画面のボタンで非表示にする。
> - 非表示のスタンプは一覧の下に並べ、長押しで浮かせ、画面の上の端に出る枠に置くと表示に戻す。

## カレンダーのスタンプ

**決定：1 日に 1 つ押せる。**

| 項目 | 内容 |
| --- | --- |
| 理由 | マスが小さく、1 つなら見分けられる。金額を隠さない |
| 却下 | 3 つまで、いくつでも、金額の代わりに出す、日付の丸の後ろに薄く敷く |

> [!IMPORTANT]
> - 記録の日の見出し（一覧でもカレンダーの日のカードでも）の右のボタンから、シートでスタンプの一覧を開いて選んで押す。
> - 選べるのは、非表示にしていないスタンプだけにする。
> - シートは中身の高さに合わせて開き、スタンプが無いときはシートから作れる。
> - 右上の「＋」からも足せる。
> - 押し直すと置き換え、外すこともできる。
> - マスでは、アイコンの色で塗った判子にして日付の右上に重ね、押したときは弾ませる。
> - 金額と支出なしの印はそのまま出す。
