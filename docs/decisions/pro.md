# Pro

> [!NOTE]
> 何を Pro にし、どう売るかの決定と、その理由が分かる。
> 同期と共有の決定は [sync](sync.md) にある。

## Pro の中身と売り方

**決定：Pro は、買い切り（¥600）だけで売る。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 家族との共有と機種をまたぐ同期は、お金を払う理由になりやすい。記録は使う人の iCloud に置き、売った後の費用が無いので、期限を付けずに安く売れる |
| 却下 | 同期と共有を無料にする、サブスクだけ、サブスクと買い切りの両方、リリースの後に足す |
| 関連 | 同期と共有の形は [overview](../overview.md) にある |

> [!IMPORTANT]
> - 端末間の同期と家族との共有を Pro に含め、どちらも最初のリリースから出す。
> - テーマを作ることと、明朝とゴシックのほかの字体も Pro に含める。
> - レシートの読み取りは、無料では 3 回まで保存できる。4 回目からを Pro に含める。
> - Pro の画面は、上に黒と金のカードで買い切りと 3 つの約束を出す。続けて機能ごとのカードを並べ、最後に無料と Pro の比較表を置く。
> - 機能のカードは、訴求の見出し・画面の部品で組んだ絵・3 つの利点を持つ。購入のボタンは下に固定する。
> - 購入と復元の間は、押した方のボタンの幅のまま、中に回る印と「確かめています」（復元は「購入を確かめています」）を出す。もう一方は薄くし、どちらも押せず、シートも下に払って閉じられない。
> - 毎日の入力・予算・振り返り・バックアップは、無料のまま使える。
> - 用意したテーマ・アプリアイコンの色違い・アイコンとスタンプを作ることも、無料のまま使える。
> - Apple のファミリー共有で、家族も Pro を使える。
> - 返金やファミリー共有から抜けて Pro が無くなったら、同期を止める。データは手元に残す。
> - Pro が無くなっても、選んでいる作ったテーマと字体はそのまま使える。新しく作る・選ぶときだけ、Pro のシートを出す。
> - バックアップの読み込みは、Pro が無くても作ったテーマと字体をそのまま読み込む。
> - あとで Pro に足す機能も、買った人に開く。
