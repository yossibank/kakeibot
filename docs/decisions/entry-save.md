# 入力シートの保存のボタン

> [!NOTE]
> 入力シートの下の保存のボタンの見た目と動きが分かる。
> シート全体の形は [entry-sheet](entry-sheet.md) にある。

## 保存のボタン

**決定：保存のボタンには、言葉だけを真ん中に出す。ほかの画面の保存のボタン（`PrimaryButton`）と同じ字体にする。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 金額・カテゴリ・日付・口座は紙のカードに出ていて、ボタンにも出すと 2 重になる |
| 却下 | 言葉の下に「カテゴリ · 日付 · 口座」を添え、右の端に金額を出す。言葉を明朝にする |

> [!IMPORTANT]
> - 新しい記録は「記録する」、振替は「振り替える」、直すときは「変更を保存」と出す。
> - 金額や振替先が無い時は、「金額を入れてください」のような案内を出す。入らなければ字を縮める。
> - 金額のほかの中身を出して金額が空の時に「金額を入れてください」を押すと、金額の中身に替える。
> - 右には、新しい記録では「続けて」、既存の記録の編集では「もう一度」を置く。「もう一度」は内容を変えていなくても押せる。
> - 「もう一度」を押すと、いまの内容を写した新しい記録に切り替え、日付を今日にする。
> - 写すのは種類・金額・カテゴリ・タグ・口座・メモと、振替の元と先。レシートの品目と店名は写さず、元の記録は変えない。
> - 切り替えた後は新しい記録と同じ見出しと保存のボタンにし、知らせで伝える。
