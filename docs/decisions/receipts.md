# レシートと品目

> [!NOTE]
> レシートの読み取りと、記録の品目をどう決めたかと、その理由が分かる。
> 記録のほかの操作は [records](records.md) にある。

## レシートを読む

**決定：入力シートのテンキーの上の端に「レシート」を置き、撮ったレシートから品目・合計・日付・店名を読む。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 今の入力の流れのまま使え、「続けて記録」と合わせて何枚も入れられる |
| 理由 | 書類のカメラ（VisionKit）で撮り、Vision と端末の中のモデルで読む。端末の外には送らない |
| 理由 | 品目の合計とレシートの合計を照らし、合わない所だけを見せれば、手直しが減る |
| 却下 | ＋ボタンの長押し、ホームの専用のボタン、写真のライブラリから読む |
| 却下 | 映しながら読むカメラ、外のサービスで読む |
| 却下 | 店名からカテゴリを推測する、記録に画像を付ける |
| 却下 | Foundation Models の動く端末だけで品目を読む |

> [!IMPORTANT]
> - 「レシート」は、テンキーの上のテンプレートの行の左に置く。振替と、手数料を入れている間は出さない。書類のカメラが使えない端末でも出さない。
> - レシートから 1 回も保存していない間は、撮る前に撮り方（平らな所・明るい所・1 枚ずつ端まで）を絵で出す。
> - 長いレシートは、縦に何枚かに分けて撮れる。
> - Foundation Models の動く端末では、モデルで品目・合計・日付・店名に組み立てる。
> - ほかの端末と、モデルが品目を組み立てられなかった時は、行の並び・「合計」の語・金額の形の決まりで組み立てる。日付は、決まりで読めた方を先に使う。
> - 数量の行と値引の行は、前の品目につなげる。`@` で始まる単価の行だけは、次の品目につなげる。
> - 店名はメモに入れる。カテゴリは、シートで選んでいるものを変えない。
> - 読めなかった項目は、今の値のまま残す。合計が読めず品目が読めた時は、記録の金額を品目の合計にする。
> - 何も読めなかった時は、撮り直しを促す知らせを出す。
> - 品目の合計がレシートの合計と合わなければ、差のある辺りの行に色を付ける。
> - 金額が読めたらテンキーを閉じ、人が確かめてから保存する。
> - 人が直した品名は、店名と読んだ文字の組で覚え、次から同じ店で使う。
> - 画像は保存せず、読んだら捨てる。

## 記録の品目

**決定：記録の下に品目（品名・金額）の一覧を持たせ、カテゴリは記録に 1 つだけ持たせる。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 品目は記録の明細なので、予算・振り返り・絞り込みの数え方を変えずに済む |
| 理由 | 入力シートを 1 画面に収めたまま、品目は別のシートで直せる |
| 却下 | 品目ごとにカテゴリを持たせたまま 1 つの記録にする、品目を 1 件ずつの記録にして束ねる |

> [!IMPORTANT]
> - 品目はタグと同じく、使う人だけが押すものとして置く。入口は、ダイヤルの右上の角に置くレシートの丸いボタンにする。
> - 品目がある時は、ボタンの右上に件数のバッジを出す。差額がある間は、バッジを琥珀色にする。振替では出さない。
> - 品目のシートは、感熱紙のレシートの形にする。上に日付と店名（メモの 1 行目）、下に小計・差額・合計を並べ、合計だけを明朝で大きく出す。
> - シートの上の列は、左に使い方、中央に「品目」、右に完了のボタンを置く。品目の変更は、その場で記録に入る。
> - 品目の行の頭に、記録のカテゴリの印を出す。数量が 2 以上なら、品名の後に「×2」と出す。
> - 品目の行は、左に滑らせて消し、消した後は「取り消す」を出す。
> - 1 枚のレシートでカテゴリがまたがる時は、品目の印でカテゴリを選ぶ。保存する時に、カテゴリごとに記録を分ける。
> - 「＋ 品目を追加」を押すと、上の端がギザギザの伝票がせり上がる。伝票で品名と「単価 × 数量 = 金額」を入れる。
> - 「追加」を押すと、伝票は開いたまま空に戻る。キーボードは出さず、次は品名の欄を押して続ける。
> - 単価と数量は、押した方を入力シートと同じテンキーで入れる。品名だけは端末のキーボードで入れ、キーボードはテンキーの上に重ね、品目の一覧は動かさない。
> - 品目の行を押すと、伝票に品名・単価・数量が入り、「追加」が「変更」になる。「変更」を押すと、伝票を閉じる。
> - 伝票を開く時と追加した時は、最後の品目が上に来るまで一覧を送る。変更する時は、その品目を上に送る。
> - 伝票の文字は縮めず、伝票の高さを保つ。足りない分は、品目の一覧の高さで詰める。
> - テンキーの「値引」はその行を負の金額にし、「半額」は単価を半分にして 1 円未満を切り捨てる。
> - 品目は、レシートを使わずに手でも追加できる。
> - 店名はレシートの上で直せ、メモの 1 行目に入る。
> - 合計の下に、数量を足したお買上点数を出す。
> - 伝票の品名の下に、前に使った品名を新しい順に候補で出す。入れた文字を含む品名に絞る。
> - 記録の金額はレシートの合計にする。
> - 記録の金額が 0 か品目の合計と同じ間は、品目を追加・変更・削除するたびに、記録の金額を品目の合計に合わせる。
> - 調整は記録の金額と品目の合計の差で、保存しない。差がある時だけ「差額」の行を出し、「調整」で記録の金額を品目の合計にそろえる。
> - 記録の一覧では、品目のある記録を開くと、下に品目を並べる。
> - 記録の検索は、品名も探す。

## 品目の税率

**決定：品目ごとに税込・8%・10% を持たせ、8% と 10% の品目は税抜の金額で入れる。消費税は率ごとに足してから 1 回だけ切り捨てる。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 外税のレシートは、率ごとの対象額と消費税を最後にまとめて出すので、同じ順に計算すれば合計が合う |
| 理由 | 軽減税率の食品と 10% の日用品を、1 枚のレシートのまま入れられる |
| 却下 | 品目ごとに税を足して切り捨てる、記録に 1 つだけ税率を持たせる、テンキーの 8%・10% のキーを税率の印にする |

> [!IMPORTANT]
> - 伝票は、「単価 × 数量 = 金額」を 1 行にし、下の行に「税込」「8%」「10%」の切り替えを置く。テンキーの 8%・10% の場所には、「値引」と「半額」を置く。
> - 伝票を開いた時の税率は、一覧の最後の品目に合わせる。品目が無ければ税込にする。
> - レシートでは、外税の品目の金額の右に「8%」「10%」と出す。小計の下に、率ごとの対象額と消費税を 1 行ずつ出す。
> - 品目の合計は、小計と率ごとの消費税の和にする。計算は [fixtures](../../spec/fixtures/entry/entry-item-total.json) にそろえる。

## レシートを読む回数

**決定：無料ではレシートから 3 回まで保存でき、Pro は回数の制限なく使える。**

| 項目 | 内容 |
| --- | --- |
| 理由 | 無料のうちに精度を試せ、使い続ける人に Pro を勧められる |
| 理由 | 読んでも保存しなければ数えないので、読み直しで回数が減らない |
| 却下 | すべて無料にする、初めから Pro だけにする、読んだ回で数える |

> [!IMPORTANT]
> - 回数は setting 表の `receipt_saved_count` に置き、同期中の端末どうしで共有する。
> - 3 回を使い切った後に「レシート」を押すと、Pro の案内を出す。
> - 品目を手で足すのは、無料のまま使える。
> - アプリを消して入れ直すと回数は 0 に戻る。それは許す。
