# レシートと品目

> [!NOTE]
> 記録の品目と、その税率をどう決めたかと、その理由が分かる。
> レシートの読み取りは [receipts-reading](receipts-reading.md)、記録のほかの操作は [records](records.md) にある。

## 記録の品目

**決定：記録の下に品目（品名・金額）の一覧を持たせ、カテゴリは記録に 1 つだけ持たせる。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 品目は記録の明細なので、予算・振り返り・絞り込みの数え方を変えずに済む |
| 💡 理由 | 入力シートを 1 画面に収めたまま、品目は別のシートで直せる |
| ❌ 却下 | ~~品目ごとにカテゴリを持たせたまま 1 つの記録にする~~ 予算・振り返り・絞り込みの数え方が変わる |
| ❌ 却下 | ~~品目を 1 件ずつの記録にして束ねる~~ 予算・振り返り・絞り込みの数え方が変わる |

> [!IMPORTANT]
> - 記録の金額はレシートの合計にする。
> - 記録の金額が 0 か品目の合計と同じ間は、品目を追加・変更・削除するたびに、記録の金額を品目の合計に合わせる。
> - 調整は記録の金額と品目の合計の差で、保存しない。差がある時だけ「差額」の行を出し、「調整」で記録の金額を品目の合計にそろえる。

### 入口とカプセル

| 状態 | 見た目 | 操作 |
| :---: | --- | --- |
| 品目が無い | 金額の中身で、上の端に金のピル「品目に分ける」を置く | 押すと、伝票を開いた状態で品目のシートを出す |
| 品目がある | 紙のカードの金額の横にカプセルを出し、件数と品目の合計を並べる | 押すと品目のシートを開く |
| 差額がある | カプセルに差額を足して琥珀色にする。振替と、手数料を入れている間は出さない | |

品目はタグと同じく、使う人だけが押すものとして置く。品目は、レシートを使わずに手でも追加できる。

### 品目のシート

- 品目のシートは、感熱紙のレシートの形にする。
- 上に日付と店名（メモの 1 行目）、下に小計・差額・合計を並べ、合計だけを明朝で大きく出す。
- 合計の下に、数量を足したお買上点数を出す。
- 記録の金額と品目の合計が違う時は、その差を琥珀色の「差額」の行で出す。
- 店名はレシートの上で直せ、メモの 1 行目に入る。
- シートの上の列は、左に使い方、中央に「品目」、右に完了のボタンを置く。品目の変更は、その場で記録に入る。

レシートの紙は、ダークの色ではカードの上と下の色の間の暗い色を、テーマの強調の色へわずかに寄せる。同じ色寄りの縁の線で紙と分かるようにし、灰色にはしない。

### 品目の行

| 状態 | 見た目 | 操作 |
| :---: | --- | --- |
| 品目 | 品名と金額を点線でつなぎ、行の頭に印を出さない | 左に滑らせて消し、消した後は「取り消す」を出す |
| 数量が 2 以上 | 品名の下に「2 × ¥198」と単価を出す。単価が割り切れなければ「×2」と出す | |
| 値引 | 品名を少し字下げし、品名と金額を薄い赤で出す | |

### 伝票

| 状態 | 見た目 | 操作 |
| :---: | --- | --- |
| 追加 | 「＋ 品目を追加」で伝票がせり上がる。品名と「単価 × 数量 = 金額」を入れる | 「追加」を押すと、伝票は開いたまま空に戻る。キーボードは出さず、次は品名の欄を押して続ける |
| 変更 | 品目の行を押すと、伝票に品名・単価・数量が入り、「追加」が「変更」になる | 「変更」を押すと、伝票を閉じる |

- 単価と数量は、押した方を入力シートと同じテンキーで入れる。
- 品名だけは端末のキーボードで入れ、キーボードはテンキーの上に重ね、品目の一覧は動かさない。
- 伝票の品名の下に、前に使った品名を新しい順に候補で出す。入れた文字を含む品名に絞る。
- テンキーの「値引」はその行を負の金額にし、「半額」は単価を半分にして 1 円未満を切り捨てる。

伝票と一覧の送り方は、次のとおりにする。

- 伝票を閉じて一覧が広がる時は、先に一覧を収まる位置まで滑らかに送ってから閉じる。
- 伝票を開く時と追加した時は、最後の品目が上に来るまで一覧を送る。変更する時は、その品目を上に送る。
- 伝票の文字は縮めず、伝票の高さを保つ。足りない分は、品目の一覧の高さで詰める。

### 一覧の小さなレシート

記録のタブの一覧・カレンダー・検索の結果では、品目のある記録の行の下に「品目 3 件」を出す。

| 状態 | 見た目 | 操作 |
| :---: | --- | --- |
| 開いた時 | 「お買上明細」の見出しの小さなレシートを出し、品目・消費税・合計と点数を並べる | 「品目 3 件」を押すと開く。小さなレシートを押しても閉じる |
| 品目の行が幅に収まらない | 字を一段小さくする。それでも収まらなければ、品名の末尾を省く | |
| 品目の行の数量・税率の印・金額 | 折り返さない | |
| 消費税の内訳が収まらない | 「対象」を省き、「消費税」を「税」と縮める | |

小さなレシートの消費税と税率の出し方は、品目のシートと同じにする。記録の検索は、品名も探す。

## 品目の税率

**決定：品目ごとに税込・8%・10% を持たせ、記録ごとに外税か内税かを持たせる。消費税は率ごとに足してから 1 回だけ丸める。**

| 項目 | 内容 |
| :---: | --- |
| 💡 理由 | 外税のレシートは、率ごとの対象額と消費税を最後にまとめて出すので、同じ順に計算すれば合計が合う |
| 💡 理由 | 軽減税率の食品と 10% の日用品を、1 枚のレシートのまま入れられる |
| 💡 理由 | 内税のレシートは、税込の金額のまま入れても率ごとの消費税を出せる |
| ❌ 却下 | ~~品目ごとに税を足して切り捨てる~~ 外税のレシートは率ごとにまとめて出すので、合計が合わない |
| ❌ 却下 | ~~記録に 1 つだけ税率を持たせる~~ 軽減税率の食品と 10% の日用品を、1 枚のまま入れられない |

> [!IMPORTANT]
> - 計算は [fixtures](../../spec/fixtures/entry/entry-item-total.json) にそろえる。レシートから読んだ時は、読んだ税の計算に合わせる。
> - 外税では、8%・10% の品目の金額を税抜で持ち、率ごとの消費税を切り捨てて足す。品目の合計は、小計と消費税の和にする。
> - 内税では、8%・10% の品目の金額を税込で持ち、率ごとの消費税を四捨五入して「うち消費税」と出す。品目の合計は小計にする。

### 計算

外税は、率ごとに対象額を足してから 1 回だけ切り捨てる。

$$\text{率ごとの消費税} = \left\lfloor \text{対象額} \times \frac{\text{率}}{100} \right\rfloor$$

$$\text{品目の合計} = \text{小計} + \sum \text{率ごとの消費税}$$

内税は、率ごとに対象額を足してから 1 回だけ四捨五入する。品目の合計は小計のままにする。

$$\text{うち消費税} = \operatorname{round}\left(\text{対象額} \times \frac{\text{率}}{100 + \text{率}}\right)$$

### 伝票とレシートの見た目

- 伝票は、「単価 × 数量 = 金額」を 1 行にし、下の行に「税込」「8%」「10%」の切り替えを置く。
- テンキーの 8%・10% の場所には、「値引」と「半額」を置く。
- 伝票を開いた時の税率は、一覧の最後の品目に合わせる。品目が無ければ税込にする。
- レシートでは、品目の税率が 2 種類以上ある時だけ、品名の右に「8%」「10%」の小さな印を出す。
- 8%・10% の品目がある時は、小計の下に「税の計算」の外税・内税の切り替えを出す。
- その下に、率の印・対象額・消費税を率ごとに 1 行ずつ出し、列をそろえる。
