# 用語

> [!NOTE]
> 記録と入力シートについて、画面の言葉・文書の言葉・コードの型の対応と、その意味が分かる。
> 固定費・ごほうび・Pro・同期・お知らせ・振り返りの言葉は [glossary-features](glossary-features.md) にある。

| 画面の言葉 | 文書の言葉 | コード | 意味 |
| --- | --- | --- | --- |
| 記録 | 記録 | `Entry` | 日付・金額・口座を持つ、1 件の支出・収入・振替。表の行（`+Record`）と、同期の行（`SyncRecord`）とは別のもの |
| カテゴリ | カテゴリ | `EntryCategory` | 支出と収入で別に持つ、記録の分類。画面と読み出しの型は、`Category` と略す |
| タグ | タグ | `EntryTag` | カテゴリの下に付ける、細かい分類 |
| 予算 | 予算 | `Budget` | 月ごとに使ってよい額。月全体と、カテゴリごとに持つ |
| 口座 | 財布 | `Wallet` | 現金・銀行・カードなど、お金を置く所。最初に入る現金の口座の名前も「財布」である |
| 手持ち・後で払う・返す・値動きがある | 種類の組 | `WalletEditSheet.KindGroup` | 口座の編集で、種類を分けて並べる 3 つの組。手持ちは使えるお金、後で払う・返すは負債、値動きがあるは評価額で合わせる口座 |
| テーマ | 色の組 | `ThemePalette` | テーマで描く 12 色の組 |
|  | 役割の色 | `Palette` | `accent`・`text` など、描く時に色の組か地の明るさから決まる色の名前 |
|  | 意味の色 | `ThemePalette.Semantic` | 超過・マイナス・エラーの `rose`、注意の `amber`、日曜・祝日の `holiday`、土曜の `saturday`。地に合わせて明度をずらした色で描く |
|  | 監視 | `ValueObservation` | DB の変化を受け取り、画面の値を新しくする仕組み。GRDB の型である |
| 文字 | 文字の設定 | `ThemeStyle` | 文字の大きさと、見出しと金額・本文の字体 |
| 形と動き | 見た目の設定 | `ThemeStyle` | 角の丸み・行の間隔・スタンプの形・タブの名前・背景、振動・飾りの入と切 |
| 背景 | 背景 | `Backdrop`・`ThemeBackdrop` | 画面の地の塗りと、その上に重ねる罫線・方眼の柄 |
|  | 種類の切り替え | `EntryTypeSwitch` | 入力シートの上で、支出・収入・振替を独立したキーで切り替える。選んだ種類は金の面にする |
|  | 紙のカード | `EntrySlip` | 入力シートの上の部分。金額・項目・メモの行と、レシートと声の小さなボタンを出す |
|  | 項目の行 | `EntrySlip` | 紙のカードに縦に並べる金額・カテゴリ・口座・日付の行。値を出し、押すと入力盤の中身を替える |
|  | メモの行 | `EntrySlipMemoRow` | 紙のカードのいちばん下の行。メモと品目のボタンと、レシートと声の小さなボタンを出す |
| よく使う・最近の記録 |  | `EntrySheet.recentRow` | 開いた直後の入力盤の下の 2 段の列。テンプレート、最近の記録の順に、短い方の段へ 1 枚ずつ置く |
|  | 最近の記録 | `EntryModel.Output.recentEntries` | よく使う・最近の記録の列で、テンプレートの後に並べる記録。テンプレートと同じ中身の記録は除く |
|  | 入力盤 | `EntryModel.Deck`（Android は `EntryDeck`） | 入力シートの下半分。押した行やカテゴリの印に合わせて、カテゴリ・テンキー・口座・カレンダーなどに中身を替える |
| テンプレート | テンプレート | `EntryTemplate` | 押すと決まった中身で記録を作る、記録の型 |
| 品目 | 品目 | `EntryItem` | 記録の下に並べる明細の 1 行。品名・数量・金額・税率を持ち、カテゴリは持たない |
| 残高の調整 | 残高の調整 | `Adjustment` | 口座の残高を今の額に合わせるために足す、符号付きの額。支出や収入の合計には入れない |
| 予定の記録 | 予定 | `AssetsModel.Plan` | 日付が明日以降で、手元のお金を変える記録。その日になるまで手元のお金に入れず、資産の「今月これから」に出す |
| 今月これから・月末の見込み | 月末の見込み | `AssetsModel.Outlook` | 今の期間の終わりまでの、予定の記録と固定費のこれからの回の増減と、それを手元のお金に足した額 |
| これから・これまで | 一覧の区切り | `RecordsModel.Output.listCaptions` | 記録の一覧で、明日以降の日と今日までの日を分ける小見出し。明日以降の日が無い月は出さない |
| 固定費あと | 固定費のこれからの回 | `PeriodRecurring.Status.upcoming` | 固定費の、まだ記録を作っていない回。登録した額で見込みに足す |
| 差額 | 調整 | `EntryModel.Output.itemAdjustment` | 記録の金額と品目の合計の差。保存せず、差がある時だけ、品目のシートと記録のタブのレシートに出す |
| お買上点数 | 品目の点数 | `EntryModel.Output.itemCount` | 品目の数量の合計 |
| 8%対象・消費税 | 品目の合計 | `EntryItemTotal` | 品目の小計、率ごとの対象額と消費税、合計 |
| 税込・8%・10% | 品目の税率 | `EntryItem.TaxRate` | 税込は空。8% と 10% の品目は、外税なら税抜、内税なら税込の金額で持つ |
| 外税・内税 | 税の計算 | `Entry.taxIncluded` | 外税は品目の金額に消費税を足し、内税は品目の金額に消費税を含める |
| 店名 | 店名 | `EntryModel.State.store` | メモの 1 行目。品目のシートで直せる |
| もう一度 | 記録し直す | `EntryModel.recordAgain` | 編集中の記録と同じ中身を、今日の新しい記録にする。手数料・品目・テンプレートは外す |
| 取り消す | 記録の知らせ | `EntryNoticeModel`・`EntryChange` | 記録・変更・削除の後に出す、取り消せる知らせ。削除は確かめずに消し、この知らせで戻す |
|  | 知らせの入れ替え | `MainModel.State.notices.round` | 記録の知らせが出た時に進め、タブの失敗の知らせを消す回の数 |
|  | 記録の行のメモ | `EntryMemoText` | 記録の行で、左に線を引いて出すメモ。2 行を超える時は、押して開く |
|  | 読んだ品名 | `EntryItem.Draft.readName` | レシートから読んだままの品名で、保存しない。人が直した品名を覚える時の鍵にする |
|  | 読み違えの候補 | `ReceiptSuspect` | 品目の合計がレシートの合計と合わない時に、琥珀色を付ける品目 |
|  | 覚えた品名 | `ItemName` | レシートで人が直した品名。店名と読んだ文字の組で覚える |
|  | 文字の断片 | `ReceiptFragment` | 端末の中の文字認識が返した、位置の付いた文字。傾きを直した縦の位置が近いものを 1 行にまとめる |
|  | 読んだレシート | `ReceiptReading` | レシートの行から組み立てた店名・日付・合計・品目。読めなかった項目は空にする |
|  | 行の役割 | `ReceiptLabels` | モデルが答えたレシートの行の役割。店名・日付・合計、品目・品名・数量・値引の行の番号と、品目の税率 |
| 声 | 声の入力 | `EntryVoiceFlow` | 入力シートの「声で入れる」から、話した言葉を聞いて記録の入力に入れる流れ。聞く・読む・入れる・取り消すを持つ |
|  | 読んだ声 | `VoiceReading` | 話した文から読んだ金額・日付・カテゴリ・口座・メモ。読めなかった項目は空にする |
|  | 声で入った欄 | `EntryModel.VoiceFilled` | 声で入れた口座・日付・メモの値。紙のカードの口座・日付とメモの行に下線を引き、値を変えると外れる |
