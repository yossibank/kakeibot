# 用語

> [!NOTE]
> 画面の言葉・文書の言葉・コードの型の対応と、その意味が分かる。

| 画面の言葉 | 文書の言葉 | コード | 意味 |
| --- | --- | --- | --- |
| 口座 | 財布 | `Wallet` | 現金・銀行・カードなど、お金を置く所。最初に入る現金の口座の名前も「財布」である |
| 手持ち・後で払う・返す・値動きがある | 種類の組 | `WalletEditSheet.KindGroup` | 口座の編集で、種類を分けて並べる 3 つの組。手持ちは使えるお金、後で払う・返すは負債、値動きがあるは評価額で合わせる口座 |
| テーマ | 色の組 | `ThemePalette` | テーマで描く 12 色の組 |
|  | 役割の色 | `Palette` | `accent`・`text` など、描くときに色の組か地の明るさから決まる色の名前 |
|  | 意味の色 | `ThemePalette.Semantic` | 超過・マイナス・エラーの `rose`、注意の `amber`、日曜・祝日の `holiday`、土曜の `saturday`。地に合わせて明度をずらした色で描く |
|  | 見張り | `ValueObservation` | DB の変化を受け取り、画面の値を新しくする仕組み。GRDB の型である |
| 文字 | 文字の設定 | `ThemeStyle` | 文字の大きさと、見出しと金額・本文の字体 |
| 形と動き | 見た目の設定 | `ThemeStyle` | 角の丸み、行の間隔、スタンプの形、タブの名前、背景、振動・飾りの入と切 |
| 背景 | 背景 | `Backdrop`・`ThemeBackdrop` | 画面の地の塗りと、その上に重ねる罫線・方眼の柄 |
| テンプレート | テンプレート | `EntryTemplate` | 押すと決まった中身で記録を作る、記録の型 |
| 品目 | 品目 | `EntryItem` | 記録の下に並べる明細の 1 行。品名・数量・金額・税率を持ち、カテゴリは持たない |
| 残高の調整 | 残高の調整 | `Adjustment` | 口座の残高を今の額に合わせるために足す、符号付きの額。支出や収入の合計には入れない |
| 予定の記録 | 予定 | `AssetsModel.Plan` | 日付が明日以降で、手元のお金を変える記録。その日になるまで手元のお金に入れず、資産の「今月これから」に出す |
| 今月これから・月末の見込み | 月末の見込み | `AssetsModel.Outlook` | 今の期間の終わりまでの、予定の記録と固定費のこれからの回の増減と、それを手元のお金に足した額 |
| これからの固定費 | 固定費のこれからの回 | `PeriodRecurring.Status.upcoming` | 固定費の、まだ記録を作っていない回。登録した額で見込みに足す |
| 差額 | 調整 | `EntryModel.itemAdjustment` | 記録の金額と品目の合計の差。保存せず、差がある時だけ、品目のシートと記録のタブのレシートに出す |
| お買上点数 | 品目の点数 | `EntryModel.itemCount` | 品目の数量の合計 |
| 8%対象・消費税 | 品目の合計 | `EntryItemTotal` | 品目の小計、率ごとの対象額と消費税、合計 |
| 税込・8%・10% | 品目の税率 | `EntryItem.TaxRate` | 税込は空。8% と 10% の品目は、外税なら税抜、内税なら税込の金額で持つ |
| 外税・内税 | 税の計算 | `Entry.taxIncluded` | 外税は品目の金額に消費税を足し、内税は品目の金額に消費税を含める |
| 店名 | 店名 | `EntryModel.store` | メモの 1 行目。品目のシートで直せる |
|  | 読んだ品名 | `EntryItem.Draft.readName` | レシートから読んだままの品名で、保存しない。人が直した品名を覚える時の鍵にする |
|  | 読み違えの候補 | `ReceiptSuspect` | 品目の合計がレシートの合計と合わない時に、琥珀色を付ける品目 |
|  | 覚えた品名 | `ItemName` | レシートで人が直した品名。店名と読んだ文字の組で覚える |
|  | 文字の断片 | `ReceiptFragment` | 端末の中の文字認識が返した、位置の付いた文字。傾きを直した縦の位置が近いものを 1 行にまとめる |
|  | 読んだレシート | `ReceiptReading` | レシートの行から組み立てた店名・日付・合計・品目。読めなかった項目は空にする |
|  | 行の役割 | `ReceiptLabels` | モデルが答えたレシートの行の役割。店名・日付・合計・品目・品名・数量・値引の行の番号と、品目の税率 |
| 固定費 | 固定費 | `Recurring` | 毎月・毎年に自動で記録する支出・収入・振替 |
| これからの引き落とし | 引き落としの見込み | `CardBill` | 振替先がカードの固定費の、まだ来ない回の引き落とし日・見込みの額・引き落とし元の残高の見込み |
| `11月払い` | 引き落としのページ | `BillPage` | これからの引き落としを、引き落とし日の月でまとめた 1 ページ |
| 見込み | 締め日の前の回 | `CardBill.isOpen` | 締め日が今日か今日より後で、引き落としの額がまだ決まっていない回。締め日を過ぎた回は「確定」と呼ぶ |
| 輪 | 締め日までの進み具合 | `CardBill.progress(on:)` | 利用期間の始まりから締め日までの日数のうち、今日までに進んだ割合 |
| くわしい設定 | くわしい設定 | `SettingsDetails` | 固定費・テンプレート・口座の編集で、あまり変えない項目を行で並べた所 |
| スタンプ | スタンプ | `CalendarStamp` | カレンダーの日に 1 つ押す印。押す前の一覧の印は `ShelfIcon` で持つ |
| ごほうび | ごほうび貯金 | `RewardRule`・`RewardGoal`・`RewardLog` | 決まりの達成で仮想の貯金箱に貯まる額。口座の残高は変えない |
| ごほうびの決まり | 決まり | `RewardRule` | 達成した日に、決めた額を貯金箱に貯める決まり。名前・額・アイコンを持つ |
| 達成 | 達成 | `RewardLog` | 決まりを果たした日の印。付けたときの決まりの額を写して持つ |
| 目標 | 目標 | `RewardGoal` | 貯金箱で貯めて買う欲しい物。額に届くと「買った」にできる |
| ごほうび貯金箱 | 貯金箱 | `RewardBank`・`RewardBalance` | 達成で貯めた合計から、買った目標の額を引いた残り |
| Pro | Pro | `ProStatus`・`ProStore` | 買い切りで開く機能。同期・共有（誘う側）・テーマを作る・明朝とゴシックのほかの字体・4 回目からのレシートの読み取り |
| 「〜は Pro で使えます」のカード | Pro のカード | `ProOfferCard` | Pro の機能を押した場所で、画面の下に出す小さなカード |
| 同期と共有 | 端末間の同期 | `SyncModel`・`SyncEngine` | 自分の iCloud で、記録と設定を端末どうしでそろえること |
| 共有する口座 | ほかの人との共有 | `WalletShare`・`SyncShareSheet` | 口座ごとに、ほかの iCloud の人と記録を分けあうこと |
| 誘われた口座 | 誘われた共有の財布 | `JoinedShare` | ほかの iCloud の人に誘われて入った共有の口座。同期の画面から抜けられる |
| 参加している人 | 共有の参加者 | `SyncParticipant` | 共有の口座に入っている人。自分・参加中・招待中のどれかの状態を持つ |
| お知らせ | お知らせ | `WhatsNewRelease`・`WhatsNewSheet` | 版ごとに足した機能。ホームのベルから開き、未読の版があればベルに点を出す |
|  | 機能の絵 | `FeatureArt` | お知らせと Pro の画面で機能を見せる絵。画面の部品を決まった大きさで組み、幅に合わせて縮める |
|  | 使い方のコマ | `WhatsNewScene` | お知らせのカードで、機能の使い方を 3 つの順で見せる小さな絵 |
|  | アプリの版 | `AppVersion` | 数字を . でつないだ版。お知らせの未読を決める時に比べる |
| | レビューのお願い | `AppReviewRequest` | App Store の評価を頼む OS のダイアログを出すこと。振り返りの `ReviewModel` とは別のもの |
| 休日なら、土日・祝日のとき | 休日のずらし | `HolidayShift` | 固定費の日と月の始まりが休日に当たったら、そのまま・前の平日・次の平日にすること |
