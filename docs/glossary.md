# 用語

> [!NOTE]
> 画面の言葉・文書の言葉・コードの型の対応と、その意味が分かる。

| 画面の言葉 | 文書の言葉 | コード | 意味 |
| --- | --- | --- | --- |
| 口座 | 財布 | `Wallet` | 現金・銀行・カードなど、お金を置く所。最初に入る現金の口座の名前も「財布」である |
| テーマ | 色の組 | `ThemePalette` | テーマで描く 12 色の組 |
|  | 役割の色 | `Palette` | `accent`・`text` など、描くときに色の組か地の明るさから決まる色の名前 |
|  | 意味の色 | `ThemePalette.Semantic` | 超過・マイナス・エラーの `rose`、注意の `amber`、日曜・祝日の `holiday`、土曜の `saturday`。地に合わせて明度をずらした色で描く |
|  | 見張り | `ValueObservation` | DB の変化を受け取り、画面の値を新しくする仕組み。GRDB の型である |
| 文字 | 文字の設定 | `ThemeStyle` | 文字の大きさと、見出しと金額・本文の字体 |
| 形と動き | 見た目の設定 | `ThemeStyle` | 角の丸み、行の間隔、スタンプの形、タブの名前、背景、振動・飾りの入と切 |
| 背景 | 背景 | `Backdrop`・`ThemeBackdrop` | 画面の地の塗りと、その上に重ねる罫線・方眼の柄 |
| テンプレート | テンプレート | `EntryTemplate` | 押すと決まった中身で記録を作る、記録の型 |
| 固定費 | 固定費 | `Recurring` | 毎月・毎年に自動で記録する支出・収入・振替 |
| スタンプ | スタンプ | `CalendarStamp` | カレンダーの日に 1 つ押す印。押す前の一覧の印は `ShelfIcon` で持つ |
| ごほうび | ごほうび貯金 | `RewardRule`・`RewardGoal`・`RewardLog` | 決まりの達成で仮想の貯金箱に貯まる額。口座の残高は変えない |
| ごほうびの決まり | 決まり | `RewardRule` | 達成した日に、決めた額を貯金箱に貯める決まり。名前・額・アイコンを持つ |
| 達成 | 達成 | `RewardLog` | 決まりを果たした日の印。付けたときの決まりの額を写して持つ |
| 目標 | 目標 | `RewardGoal` | 貯金箱で貯めて買う欲しい物。額に届くと「買った」にできる |
| ごほうび貯金箱 | 貯金箱 | `RewardBank`・`RewardBalance` | 達成で貯めた合計から、買った目標の額を引いた残り |
| iCloud 同期 | 端末間の同期 | `SyncModel`・`SyncEngine` | 自分の iCloud で、記録と設定を端末どうしでそろえること |
| 共有する口座 | ほかの人との共有 | `WalletShare`・`SyncShareSheet` | 口座ごとに、ほかの iCloud の人と記録を分けあうこと |
| 誘われた口座 | 誘われた共有の財布 | `JoinedShare` | ほかの iCloud の人に誘われて入った共有の口座。同期の画面から抜けられる |
| 参加している人 | 共有の参加者 | `SyncParticipant` | 共有の口座に入っている人。自分・参加中・招待中のどれかの状態を持つ |
