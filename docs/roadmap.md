# 画面と作る順番

## 画面

### タブ（4 つ）と ＋ ボタン

| タブ | 中身 |
| --- | --- |
| ホーム | 今月あといくら、今日の支出、キャラクターの一言、よく使う組み合わせ、最近の記録 |
| カレンダー | 日ごとの合計、スタンプ、支出なしの印。日をタップするとその日の一覧 |
| 振り返り | 月と週の切り替え、合計、前の期間との比較、カテゴリ別・財布別の内訳、予算の消化、「今月の自分」カード |
| 財布 | 財布ごとの残高、ごほうび貯金箱 |

＋ ボタンはどの画面にも浮かせ、入力シートを開く。

### シートと設定

| 画面 | 中身 |
| --- | --- |
| 入力シート | 支出・収入・振替、テンキー、カテゴリ、財布、日付、メモ。新規と編集を兼ねる |
| 設定の一覧 | 下の画面と、通知・期間・バックアップ |
| アイコン | 絵文字・色・短い文字。その場で見た目を確認 |
| テーマ | その場で見た目を確認。読みにくい組み合わせは保存させない |
| キャラクター | 選んで名前を付ける |
| 予算 / 固定費 / ごほうび / カテゴリ | 一覧と編集 |
| 最初の設定 | 財布、給料日、キャラクター |

## 0 番の中身

| 順 | 作業 | 担当 |
| --- | --- | --- |
| 1 | Xcode プロジェクト（アプリ、`KakeibotWidget`、App Group、Swift 6、iOS 18） | 自分 |
| 2 | KakeibotKit・KakeibotApp の骨組みと、Xcode プロジェクトへのつなぎ | Claude |
| 3 | `spec/fixtures/date` → Core の Date → CoreTests | Claude |
| 4 | DB の最初の形（表 13 個）と Records | Claude |
| 5 | 書き出し V1（Core の Export、Store の Snapshot、往復の fixtures） | Claude |
| 6 | 実機で `0xdead10cc` が起きないか確かめる | 自分 |

### 0 番が終わった状態

| 確認すること | 方法 |
| --- | --- |
| fixtures が全部通る | `swift test` |
| 古い DB から最新の形に移せる | 移行のテスト |
| 書き出し → 読み込み → 書き出しで同じ結果になる | `spec/fixtures/export` |
| 裏に回ってもアプリが止められない | 実機 |

## 実機と Apple Developer Program

| 時期 | 必要なこと |
| --- | --- |
| 0 番 | シミュレーターで進められる。実機での確認（0 番の 6）は、無料のアカウントで App Group が使えれば可能（未検証） |
| 1 番（毎日使い始める） | 無料のアカウントで実機に入れたアプリは 7 日で起動できなくなるため、毎日使うなら加入が要る |
| 11 番 | ストアに出すには加入が要る |
